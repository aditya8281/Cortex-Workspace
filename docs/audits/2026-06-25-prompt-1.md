**Events:** AgentMessage(text), ToolCall(name, args), ToolResult(name, result), ToolDenied(name), Compaction(summary), Thinking(text), Done(summary)

**Flow:**
1. Classify intent (call intent.py — stub first, real later)
2. Build context from providers (placeholder for now)
3. Streaming loop (max 25 iterations)
   - Check stall detection (call stall.py — stub first)
   - LLM call via `llm.stream_chat()`
   - Process chunks: text → yield AgentMessage, tool_call → check policy → execute → yield ToolCall + ToolResult
   - Check compaction need (call compactor.py — placeholder)
   - Check completion signal
4. Verify completion (call verifier.py — stub first)
5. Yield Done
