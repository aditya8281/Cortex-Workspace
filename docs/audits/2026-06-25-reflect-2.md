## Quality

- **Insight:** tools/ package well-modularized — registry.py, schemas.py, policy.py, security.py each own distinct concern. No single module does too much.
- **Insight:** ToolRegistry API is minimal and clean — register, get, list_tools, get_all, schemas_for, remove, clear, count. No dead methods.
- **Insight:** `generate_schema()` correctly resolves `from __future__ import annotations` string annotations via `typing.get_type_hints()` — critical fix for PEP 563.
- **Insight:** Policy system is simple and correct — first-match-wins, fnmatch glob, composable rules, independent copy().
- **Insight:** `has_blocked_command()` patterns correctly use trailing spaces ("exec ", "curl ", "apt ") to prevent false positives on innocent substrings ("execution", "curl_cmd").
- **Suggestion:** `ensure_within_workspace()` in security.py accepts optional `workspace_root` param, but `_ensure_within_workspace()` in tool_defs.py always uses `AGENT_WORKSPACE` env var. The duplicate should be removed in favor of the security.py version once executor.py stops lazy-importing from tool_defs.py.

## Redundancy

- **Action-item:** `_ensure_within_workspace()` in `tool_defs.py` (line 41) is an exact duplicate of `ensure_within_workspace()` in `security.py`. Same for `_is_private_url()` (line 51) duplicating `is_private_url()` (security.py:80), and `BLOCKED_HOSTS` frozenset (line 28) duplicating `BLOCKED_HOSTNAMES` (security.py:67). This is intentional backward compat during transition, but creates drift risk — fixes to one won't apply to the other. Recommend: after Phase 2 streaming loop replaces executor.py, remove all duplicates and redirect executor imports to security.py.

## Test Gaps

- **Action-item:** `security.py` has zero tests — `is_private_url`, `has_blocked_command`, `ensure_within_workspace` are completely untested. These enforce SSRF, command blocklist, and path traversal protection. Should have:
  - SSRF: private IPs (127.0.0.1, 10.x, 172.16-31.x, 192.168.x), metadata endpoints (169.254.169.254), DNS suffixes (.internal, .local)
  - Command blocklist: each blocked pattern, plus safe commands that should NOT match (false positive prevention)
  - Path traversal: valid paths, traversal attempts (../), symlink escapes
- **Insight:** Schema generation tests cover basic types, Optional, Literal, list, docstrings, but miss edge cases: Union with >1 non-None (falls back to string), dict params, nested types, bytes param, var_positional (*args).
- **Insight:** No integration test linking policy + registry + tool decorator end-to-end.

- **Suggestion:** Legacy `TOOL_REGISTRY` dict + `register_tool`/`get_tool`/`list_tools`/`requires_approval` in `tool_defs.py` must be maintained alongside new `ToolRegistry` until Phase 2 streaming loop replaces executor.py. This dual-maintenance is a vector for bugs — tools registered in one but not the other.
