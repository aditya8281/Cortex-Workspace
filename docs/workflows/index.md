# CORTEX Workflows

> **Placeholder — planned for v1.08+.**

CORTEX workflows provide structured, multi-step execution patterns for common operations. They coordinate across subsystems (agents, memory, tools, RAG) to produce a deterministic outcome from a natural-language prompt.

## Planned Workflow Types

- **Research Workflow** — web search → extract → summarize → cite
- **Code Review Workflow** — fetch diff → lint → audit → report
- **Knowledge Sync Workflow** — index → embed → graph → deduplicate
- **Learning Workflow** — capture → consolidate → review (SM-2)
