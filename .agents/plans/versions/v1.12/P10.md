## Implementation Tasks

### Task 1: LSP Management Endpoints

```python
# api/v1/developer/lsp.py
@router.get("/lsp/servers", response_model=list[LspServerResponse])
async def list_lsp_servers(current_user=Depends(get_current_user)):
    """List configured LSP servers."""

@router.post("/lsp/servers", response_model=LspServerResponse)
async def configure_lsp_server(body: LspServerCreate, ...):
    """Configure a new LSP server."""

@router.post("/lsp/sessions/{language}/start")
async def start_lsp_session(language: str, project_path: str, ...):
    """Start an LSP session for a language."""
    manager = LspSessionManager()
    await manager.get_or_start_session(project_path, language)
    return {"status": "started", "language": language}

@router.post("/lsp/sessions/stop-all")
async def stop_all_lsp_sessions():
    """Stop all active LSP sessions."""
    manager = LspSessionManager()
    await manager.stop_all()

@router.get("/lsp/diagnostics", response_model=list)
async def get_diagnostics(file_path: str, ...):
    """Get LSP diagnostics for a file."""
    lsp = LspService(LspSessionManager())
    return await lsp.get_diagnostics(file_path)
```

### Task 2: Coding Session Endpoints

```python
# api/v1/developer/coding.py
@router.post("/coding/session")
async def start_coding_session(body: CodingSessionCreate, ...):
    """Start a new agent-in-the-loop coding session."""
    manager = CodingSessionManager()
    return await manager.start(current_user.id, body.task, body.file_path)

@router.get("/coding/session/{session_id}")
async def get_coding_session(session_id: int, ...):
    """Get coding session state."""

@router.post("/coding/session/{session_id}/step")
async def advance_coding_session(session_id: int, ...):
    """Advance the state machine."""

@router.post("/coding/session/{session_id}/approve")
async def approve_coding_session(session_id: int, approved: bool = True, ...):
    """Approve or reject plan."""

@router.get("/coding/session/{session_id}/log")
async def get_coding_session_log(session_id: int, ...):
    """Get action log for a coding session."""
```

### Task 4: Frontend Developer Dashboard

New tabs in the developer dashboard:

**Existing (from original):**
- Code Analysis (reviews, scores)
- Repository Intelligence (health scores)
- Git Timeline (commits, branches)
- Generation History (docs, tests)
- Skills Registry

**New tabs:**
- **LSP Sessions** — active servers, diagnostics per file, server status
- **Coding Sessions** — active/historical agent-in-the-loop sessions, diffs per iteration
- **Symbol Index** — search symbols, definitions, references with file navigation
- **Code Tools** — inline tool testing (search_code, find_symbol, get_diagnostics)

### Task 5: Skills Runtime (unchanged from original)

Maintain original skills runtime from original P06: SkillRegistry CRUD, skill invocation, composition tracking, usage stats.
