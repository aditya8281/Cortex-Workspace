# P11: Subagent Delegation System — CORTEX

**Document:** Phase 11 of Version 1.12
**Date:** 2026-07-01

---

## Objective

Build a **subagent delegation system** where the main agent can decompose complex tasks into subtasks, dispatch subagents with isolated contexts, run them in parallel, collect status reports, and synthesize results — exactly like Claude Code's agent→subagent→sub-subagent hierarchy.

This enables Cortex to handle large-scale tasks that exceed a single agent's context window or reasoning capacity by farming out work to specialized subagents.

---

## Architecture

```
Main Agent (orchestrator)
    │
    ├── Plan: LLM decomposes task → subtask list with deps
    │
    ├── Dispatch: fan-out subagents (parallel where independent)
    │   ├── Subagent A (code search) ──→ DONE
    │   ├── Subagent B (read files)  ──→ DONE
    │   ├── Subagent C (analyze)     ──→ BLOCKED (needs A's output)
    │   │       └── Sub-subagent C1 ──→ DONE
    │   │       └── Sub-subagent C2 ──→ DONE_WITH_CONCERNS
    │   └── Subagent D (synthesis)   ──→ NEEDS_CONTEXT
    │
    ├── Collect: gather status (DONE / BLOCKED / NEEDS_CONTEXT / DONE_WITH_CONCERNS)
    │
    ├── Resolve: handle blocked/needs-context subagents (re-dispatch with more context)
    │
    └── Synthesize: combine subagent results → final answer
```

### Core Concepts

| Concept | Description |
|---------|-------------|
| **Task Decomposition** | LLM breaks complex task into subtasks with dependency graph |
| **Subagent** | Fresh agent instance with isolated context, scoped tools, no parent history |
| **Parallel Fan-Out** | Independent subtasks run concurrently |
| **Hierarchical Delegation** | Subagents spawn sub-subagents (N-level tree) |
| **Status Reporting** | Each subagent returns DONE / BLOCKED / NEEDS_CONTEXT / DONE_WITH_CONCERNS |
| **Scoped Tool Access** | Each subagent gets only tools it needs |
| **Context Isolation** | Parent context never polluted by subagent internals |
| **Result Synthesis** | Parent collects results → merges → produces coherent output |

### Task 2: Task Decomposition Service

```python
"""Task decomposition — LLM breaks complex tasks into subtasks."""
from __future__ import annotations
import json
import logging
from typing import Any

from backend.app.schemas.developer.subagent import SubtaskDefinition, DecompositionResponse

logger = logging.getLogger(__name__)

DECOMPOSITION_PROMPT = """You are a task decomposition specialist. Break the following complex task into
discrete, independently executable subtasks. Each subtask should:
1. Be small enough for a single subagent to complete in one context window
2. Have clear inputs and outputs
3. Be independently testable where possible
4. List any dependencies on other subtasks

Available tools for subagents: {available_tools}

Complex task: {task}

Return a JSON object with:
- "subtasks": array of {{"title": str, "description": str, "context": dict or null, "tool_allow_list": list[str] or null, "dependencies": list[int] or null}}
- "rationale": str explaining the decomposition strategy

IMPORTANT: Each subtask's "description" must be fully self-contained — the subagent will see ONLY this description, not the original task. Include all context, file paths, and specifics the subagent needs."""


class TaskDecomposer:
    """Decompose complex tasks into subtasks via LLM."""

    def __init__(self, llm_manager=None):
        self._llm = llm_manager

    async def decompose(
        self,
        task: str,
        available_tools: list[str] | None = None,
        max_subtasks: int = 10,
    ) -> DecompositionResponse:
        """Break a complex task into subtasks."""
        prompt = DECOMPOSITION_PROMPT.format(
            task=task,
            available_tools=json.dumps(available_tools or []),
        )

        if self._llm:
            response = await self._llm.generate(prompt, max_tokens=4096)
            return self._parse_response(response)
        else:
            return self._fallback_decomposition(task, max_subtasks)

    def _parse_response(self, response: str) -> DecompositionResponse:
        """Parse LLM response into structured decomposition."""
        try:
            # Try to extract JSON from response
            import re
            json_match = re.search(r'\{.*\}', response, re.DOTALL)
            if json_match:
                data = json.loads(json_match.group())
            else:
                data = json.loads(response)

            subtasks = [SubtaskDefinition(**s) for s in data.get("subtasks", [])]
            return DecompositionResponse(
                subtasks=subtasks,
                rationale=data.get("rationale", ""),
            )
        except (json.JSONDecodeError, Exception) as e:
            logger.warning(f"Failed to parse decomposition: {e}")
            return self._fallback_decomposition("Parse error, using fallback", 5)

    def _fallback_decomposition(self, task: str, max_subtasks: int) -> DecompositionResponse:
        """Fallback: single flat task when LLM unavailable."""
        return DecompositionResponse(
            subtasks=[SubtaskDefinition(
                title="Execute task",
                description=task,
                context=None,
                tool_allow_list=None,
                dependencies=None,
            )],
            rationale="Fallback: single task (LLM unavailable for decomposition)",
        )

    async def validate_decomposition(self, subtasks: list[SubtaskDefinition]) -> list[str]:
        """Validate a decomposition for common issues."""
        warnings = []
        titles = set()

        for i, st in enumerate(subtasks):
            if st.title in titles:
                warnings.append(f"Duplicate title: '{st.title}'")
            titles.add(st.title)

            if not st.description or len(st.description) < 20:
                warnings.append(f"Task {i} ('{st.title}'): description too short")

            # Check for dangling dependencies
            if st.dependencies:
                for dep in st.dependencies:
                    if dep < 0 or dep >= len(subtasks):
                        warnings.append(f"Task {i} ('{st.title}'): dependency {dep} out of range")

        # Check for cycles (simplified — could use topological sort)
        visited = set()

        def has_cycle(task_idx: int, path: set) -> bool:
            if task_idx in path:
                return True
            if task_idx in visited:
                return False
            path.add(task_idx)
            deps = subtasks[task_idx].dependencies or []
            for dep in deps:
                if has_cycle(dep, path):
                    return True
            path.remove(task_idx)
            visited.add(task_idx)
            return False

        for i in range(len(subtasks)):
            if has_cycle(i, set()):
                warnings.append(f"Cycle detected involving task {i}")

        return warnings
```

### Task 3: Subagent Dispatcher

```python
"""Subagent dispatcher — creates, runs, and monitors subagents with isolated contexts."""
from __future__ import annotations
import asyncio
import json
import logging
import time
import uuid
from datetime import datetime
from typing import Any

from backend.app.models.developer.subagent import (
    SubagentTask,
    SubagentStatus,
    SubagentLog,
)
from backend.app.schemas.developer.subagent import SubtaskDefinition, SubagentTaskResponse

logger = logging.getLogger(__name__)

MAX_CONCURRENT_SUBAGENTS = 8
SUBAGENT_TIMEOUT_SECONDS = 300  # 5 minutes per subagent


class SubagentDispatcher:
    """Dispatch and manage subagent execution with context isolation."""

    def __init__(self, db_session=None, llm_manager=None, agent_run_manager=None):
        self._db = db_session
        self._llm = llm_manager
        self._run_manager = agent_run_manager
        self._running: dict[int, asyncio.Task] = {}

    async def create_tasks(
        self,
        root_run_id: int,
        owner_id: int,
        subtasks: list[SubtaskDefinition],
        parent_task_id: int | None = None,
    ) -> list[SubagentTask]:
        """Persist subtask definitions to DB."""
        if not self._db:
            return []

        db_tasks = []
        for st in subtasks:
            task = SubagentTask(
                parent_task_id=parent_task_id,
                root_agent_run_id=root_run_id,
                owner_id=owner_id,
                title=st.title,
                description=st.description,
                context_snapshot=st.context,
                tool_allow_list=st.tool_allow_list,
                dependency_ids=st.dependencies,
                status=SubagentStatus.PENDING,
            )
            self._db.add(task)
            db_tasks.append(task)

        self._db.commit()
        for t in db_tasks:
            self._db.refresh(t)
        return db_tasks

    async def dispatch(
        self,
        task_ids: list[int],
        parallel: bool = True,
    ) -> list[SubagentTaskResponse]:
        """Dispatch subtasks to subagents. If parallel, run independent tasks concurrently."""
        if not self._db:
            return []

        # Load tasks
        tasks = (
            self._db.query(SubagentTask)
            .filter(SubagentTask.id.in_(task_ids))
            .all()
        )

        # Topological sort respecting dependencies
        ready, blocked = self._topological_sort(tasks)

        results = []

        if parallel:
            # Run ready tasks concurrently
            async def run_task(task: SubagentTask) -> SubagentTaskResponse:
                return await self._run_subagent(task)

            concurrent_tasks = []
            for task in ready:
                concurrent_tasks.append(run_task(task))

            # Execute concurrently with semaphore
            semaphore = asyncio.Semaphore(MAX_CONCURRENT_SUBAGENTS)

            async def throttled_run(task: SubagentTask) -> SubagentTaskResponse:
                async with semaphore:
                    return await self._run_subagent(task)

            throttled_tasks = [throttled_run(t) for t in ready]
            task_results = await asyncio.gather(*throttled_tasks, return_exceptions=True)

            for i, result in enumerate(task_results):
                if isinstance(result, Exception):
                    logger.error(f"Subagent {ready[i].id} failed: {result}")
                    results.append(SubagentTaskResponse(
                        id=ready[i].id,
                        title=ready[i].title,
                        status=SubagentStatus.FAILED,
                        result_summary=f"Exception: {result}",
                    ))
                else:
                    results.append(result)

            # Handle blocked tasks (dependencies not met)
            for task in blocked:
                results.append(SubagentTaskResponse(
                    id=task.id,
                    title=task.title,
                    status=SubagentStatus.PENDING,
                    result_summary="Awaiting dependencies",
                ))
        else:
            # Sequential execution
            for task in ready:
                result = await self._run_subagent(task)
                results.append(result)

        return results

    async def _run_subagent(self, task: SubagentTask) -> SubagentTaskResponse:
        """Execute a single subagent task with isolated context."""
        start_time = time.time()

        # Mark as running
        task.status = SubagentStatus.RUNNING
        task.started_at = datetime.utcnow()
        if self._db:
            self._db.add(SubagentLog(
                task_id=task.id,
                owner_id=task.owner_id,
                event_type="started",
                message=f"Subagent '{task.title}' started",
            ))
            self._db.commit()

        try:
            # Build isolated context for the subagent
            context = self._build_subagent_context(task)

            # Execute via agent run manager (fresh agent instance)
            if self._run_manager:
                run = await self._run_manager.create_run(
                    user_id=task.owner_id,
                    task=task.description,
                    context=context,
                    tool_allow_list=task.tool_allow_list,
                    parent_run_id=task.root_agent_run_id,
                )
                result = await self._run_manager.run_agent(
                    run_id=run.id,
                    timeout=SUBAGENT_TIMEOUT_SECONDS,
                )
            else:
                # Fallback: simulate subagent execution
                result = {
                    "status": "done",
                    "summary": f"Simulated execution of: {task.title}",
                    "detail": {"note": "LLM not available, using simulation"},
                }

            duration = int((time.time() - start_time) * 1000)

            # Determine status from result
            status, concerns = self._evaluate_result(result)

            task.status = status
            task.completed_at = datetime.utcnow()
            task.duration_ms = duration
            task.result_summary = result.get("summary", str(result)[:500])
            task.result_detail = result.get("detail", result)
            task.concerns = concerns or None

            if self._db:
                self._db.add(SubagentLog(
                    task_id=task.id,
                    owner_id=task.owner_id,
                    event_type="completed",
                    message=f"Subagent '{task.title}' completed as {status.value}",
                    metadata_json={"duration_ms": duration, "status": status.value},
                ))
                self._db.commit()

            return SubagentTaskResponse(
                id=task.id,
                title=task.title,
                status=status,
                result_summary=task.result_summary,
                result_detail=task.result_detail,
                concerns=concerns,
                duration_ms=duration,
            )

        except asyncio.TimeoutError:
            task.status = SubagentStatus.FAILED
            task.blocker_reason = "Timeout exceeded"
            if self._db:
                self._db.commit()
            return SubagentTaskResponse(
                id=task.id,
                title=task.title,
                status=SubagentStatus.FAILED,
                result_summary="Timeout: subagent did not complete in time",
                duration_ms=SUBAGENT_TIMEOUT_SECONDS * 1000,
            )

        except Exception as e:
            task.status = SubagentStatus.FAILED
            task.blocker_reason = str(e)[:500]
            if self._db:
                self._db.commit()
            logger.exception(f"Subagent {task.id} failed: {e}")
            return SubagentTaskResponse(
                id=task.id,
                title=task.title,
                status=SubagentStatus.FAILED,
                result_summary=f"Error: {e}",
            )

    def _build_subagent_context(self, task: SubagentTask) -> dict[str, Any]:
        """Build an isolated context for the subagent.

        The subagent gets:
        - Its task description (NOT the parent's full context)
        - A focused context snapshot (relevant files, search results)
        - Only the tools it's allowed to use
        - No parent conversation history
        """
        context = {
            "task": task.description,
            "subagent_id": task.id,
            "parent_task_id": task.parent_task_id,
            "tool_allow_list": task.tool_allow_list or [],
        }

        if task.context_snapshot:
            context.update(task.context_snapshot)

        return context

    def _evaluate_result(self, result: dict) -> tuple[SubagentStatus, list[str] | None]:
        """Evaluate subagent result and determine status."""
        status_str = result.get("status", "done")
        concerns = result.get("concerns")

        if status_str == "blocked":
            return SubagentStatus.BLOCKED, None
        elif status_str == "needs_context":
            return SubagentStatus.NEEDS_CONTEXT, None
        elif concerns:
            return SubagentStatus.DONE_WITH_CONCERNS, concerns if isinstance(concerns, list) else [str(concerns)]
        else:
            return SubagentStatus.DONE, None

    def _topological_sort(
        self,
        tasks: list[SubagentTask],
    ) -> tuple[list[SubagentTask], list[SubagentTask]]:
        """Sort tasks topologically. Returns (ready, blocked)."""
        task_map = {t.id: t for t in tasks}
        ready = []
        blocked = []

        # Build in-degree count
        in_degree = {t.id: 0 for t in tasks}
        for t in tasks:
            deps = t.dependency_ids or []
            for dep_id in deps:
                if dep_id in task_map:
                    in_degree[t.id] = in_degree.get(t.id, 0) + 1

        # Queue tasks with no deps
        queue = [t for t in tasks if in_degree.get(t.id, 0) == 0]
        ready.extend(queue)

        for t in tasks:
            if t not in queue:
                blocked.append(t)

        return ready, blocked

    async def check_status(self, task_id: int) -> SubagentTaskResponse | None:
        """Check current status of a subagent task."""
        if not self._db:
            return None
        task = self._db.query(SubagentTask).filter(SubagentTask.id == task_id).first()
        if not task:
            return None

        return SubagentTaskResponse(
            id=task.id,
            title=task.title,
            status=task.status,
            result_summary=task.result_summary,
            result_detail=task.result_detail,
            concerns=[str(c) for c in task.concerns] if task.concerns else None,
            duration_ms=task.duration_ms,
        )

    async def retry_blocked(self, task_id: int, additional_context: str | None = None) -> SubagentTaskResponse:
        """Retry a blocked or needs-context task with additional context."""
        if not self._db:
            raise ValueError("No DB session")

        task = self._db.query(SubagentTask).filter(SubagentTask.id == task_id).first()
        if not task:
            raise ValueError(f"Task {task_id} not found")

        if task.status not in (SubagentStatus.BLOCKED, SubagentStatus.NEEDS_CONTEXT):
            raise ValueError(f"Task {task_id} is {task.status.value}, not blocked/needs_context")

        # Append additional context
        if additional_context:
            enhanced_desc = f"{task.description}\n\nAdditional context:\n{additional_context}"
            task.description = enhanced_desc

        task.status = SubagentStatus.PENDING
        task.blocker_reason = None
        if self._db:
            self._db.commit()

        return await self._run_subagent(task)
```

### Task 4: Result Synthesis Service

```python
"""Synthesize results from multiple subagents into a coherent answer."""
from __future__ import annotations
import json
import logging
from typing import Any

from backend.app.models.developer.subagent import SubagentTask, SubagentStatus
from backend.app.schemas.developer.subagent import SynthesisRequest, SynthesisResponse

logger = logging.getLogger(__name__)

SYNTHESIS_PROMPT = """You are a result synthesis specialist. Multiple subagents have completed
parts of a complex task. Synthesize their results into a coherent, complete answer.

Original task: {original_task}

Subagent results:
{subagent_results}

Return a JSON object with:
- "summary": str (concise overall summary)
- "details": dict (structured findings merged from all subagents)
- "unresolved_items": list[str] (anything not covered)
- "warnings": list[str] (contradictions, gaps, or concerns)

Rules:
1. Deduplicate redundant information across subagents
2. Flag contradictions between subagent findings
3. Identify gaps where no subagent addressed an aspect of the task
4. Preserve important details — don't over-summarize
5. Note confidence levels where subagents expressed concerns"""


class ResultSynthesizer:
    """Merge subagent results into a coherent final answer."""

    def __init__(self, llm_manager=None, db_session=None):
        self._llm = llm_manager
        self._db = db_session

    async def synthesize(
        self,
        request: SynthesisRequest,
        subtask_results: list[dict[str, Any]],
    ) -> SynthesisResponse:
        """Synthesize subagent results into final answer."""
        if self._llm:
            return await self._llm_synthesize(request, subtask_results)
        else:
            return self._merge_synthesize(subtask_results)

    async def _llm_synthesize(
        self,
        request: SynthesisRequest,
        subtask_results: list[dict[str, Any]],
    ) -> SynthesisResponse:
        """Use LLM to synthesize results."""
        results_text = json.dumps(subtask_results, indent=2, default=str)
        prompt = SYNTHESIS_PROMPT.format(
            original_task=request.original_task,
            subagent_results=results_text,
        )

        response = await self._llm.generate(prompt, max_tokens=4096)

        try:
            import re
            json_match = re.search(r'\{.*\}', response, re.DOTALL)
            if json_match:
                data = json.loads(json_match.group())
            else:
                data = json.loads(response)

            return SynthesisResponse(
                summary=data.get("summary", ""),
                details=data.get("details", {}),
                unresolved_items=data.get("unresolved_items", []),
                warnings=data.get("warnings", []),
            )
        except (json.JSONDecodeError, Exception) as e:
            logger.warning(f"Synthesis parse failed: {e}")
            return SynthesisResponse(
                summary=response[:500],
                details={"raw_response": response},
                unresolved_items=["Could not parse synthesis"],
                warnings=[f"Parse error: {e}"],
            )

    def _merge_synthesize(
        self,
        subtask_results: list[dict[str, Any]],
    ) -> SynthesisResponse:
        """Fallback: simple merge without LLM."""
        all_summaries = []
        all_details = {}
        all_warnings = []
        all_unresolved = []

        for r in subtask_results:
            if r.get("status") == "done":
                all_summaries.append(r.get("result_summary", ""))
                detail = r.get("result_detail", {})
                if isinstance(detail, dict):
                    all_details.update(detail)

            if r.get("status") == "done_with_concerns":
                all_summaries.append(r.get("result_summary", ""))
                concerns = r.get("concerns", [])
                if concerns:
                    all_warnings.append(f"Concerns from '{r.get('title', '')}': {'; '.join(concerns)}")

            if r.get("status") == "blocked":
                all_unresolved.append(f"Blocked: {r.get('title', '')}")

            if r.get("status") in ("failed",):
                all_unresolved.append(f"Failed: {r.get('title', '')} — {r.get('result_summary', '')}")

        return SynthesisResponse(
            summary="\n".join(filter(None, all_summaries)),
            details=all_details,
            unresolved_items=all_unresolved,
            warnings=all_warnings,
        )

    def get_summary_table(self, tasks: list[SubagentTask]) -> list[dict[str, Any]]:
        """Build a summary table of all subagent results."""
        return [
            {
                "id": t.id,
                "title": t.title,
                "status": t.status.value if isinstance(t.status, SubagentStatus) else str(t.status),
                "summary": t.result_summary,
                "duration_ms": t.duration_ms,
                "has_concerns": bool(t.concerns),
                "blocker": t.blocker_reason,
            }
            for t in tasks
        ]
```

```python
    category="subagent",
    params={
        "task": "The complex task to execute via subagent delegation",
        "max_subtasks": "Maximum subtasks to create (default 10)",
    },
)
async def orchestrate_with_subagents(task: str, max_subtasks: int = 10) -> dict:
    """End-to-end subagent orchestration.

    1. Decompose task into subtasks
    2. Dispatch subagents in parallel
    3. Collect results
    4. Synthesize final answer
    """
    from backend.app.api.deps import get_db, get_llm_manager, get_run_manager
    db = next(get_db())
    llm = get_llm_manager()
    run_manager = get_run_manager()

    # Step 1: Decompose
    decomposer = TaskDecomposer(llm)
    decomposition = await decomposer.decompose(task, max_subtasks=max_subtasks)
    subtask_defs = decomposition.subtasks

    # Step 2: Create & persist tasks
    dispatcher = SubagentDispatcher(db, llm, run_manager)
    root_run_id = 0  # resolved from context
    owner_id = 0  # resolved from auth
    db_tasks = await dispatcher.create_tasks(root_run_id, owner_id, subtask_defs)

    # Step 3: Dispatch (parallel)
    task_ids = [t.id for t in db_tasks]
    dispatch_results = await dispatcher.dispatch(task_ids, parallel=True)

    # Step 4: Synthesize
    synthesizer = ResultSynthesizer(llm)
    synthesis = await synthesizer.synthesize(
        SynthesisRequest(task_id=0, original_task=task),
        [r.dict() for r in dispatch_results],
    )

    # Build status summary
    done_count = sum(1 for r in dispatch_results if r.status == "done")
    blocked_count = sum(1 for r in dispatch_results if r.status == "blocked")
    needs_ctx = sum(1 for r in dispatch_results if r.status == "needs_context")
    concerns = sum(1 for r in dispatch_results if r.status == "done_with_concerns")
    failed = sum(1 for r in dispatch_results if r.status == "failed")

    return {
        "task": task,
        "decomposition": {
            "subtask_count": len(subtask_defs),
            "rationale": decomposition.rationale,
        },
        "execution": {
            "total": len(dispatch_results),
            "done": done_count,
            "blocked": blocked_count,
            "needs_context": needs_ctx,
            "with_concerns": concerns,
            "failed": failed,
        },
        "synthesis": synthesis.dict(),
        "subtask_details": [r.dict() for r in dispatch_results],
    }
```

## Status Protocol

Subagents report one of four statuses:

| Status | Meaning | Parent Action |
|--------|---------|---------------|
| `DONE` | Task completed successfully, result available | Proceed to synthesis |
| `BLOCKED` | Missing dependency or prerequisite | Provide context and retry |
| `NEEDS_CONTEXT` | Task description insufficient or ambiguous | Provide clarifying context and retry |
| `DONE_WITH_CONCERNS` | Completed but subagent flagged doubts | Review concerns, proceed or re-dispatch |
| `FAILED` | Unrecoverable error | Log failure, continue with remaining results |

### Handling Rules

- **DONE**: Collect result, move to synthesis
- **BLOCKED**: Check if parent can unblock (provide file content, search results, etc.) → retry. If parent cannot unblock → escalate to user
- **NEEDS_CONTEXT**: Parent should provide more specific context → retry once. If still needs context → escalate to user
- **DONE_WITH_CONCERNS**: Log concerns, proceed with synthesis but include concerns in the output warnings
- **FAILED**: Log error, continue with partial results (don't fail the entire orchestration for one subagent failure)

## Comparison to Claude Code's Subagent System

| Feature | Claude Code | Cortex P11 |
|---------|-------------|------------|
| Task decomposition | LLM-based | LLM-based with fallback |
| Context isolation | Fresh subagent per task | Fresh agent run per subagent |
| Parallel fan-out | Yes (independent tasks) | Yes (async semaphore, max 8 concurrent) |
| Hierarchical | N-level tree | N-level via parent_task_id |
| Status reporting | 4 statuses | 5 statuses (incl. FAILED) |
| Tool scoping | Per-subagent allow list | Per-subagent tool_allow_list |
| Result synthesis | Parent merges results | LLM synthesis + fallback merge |
| User escalation | Via checkpoint | Via BLOCKED/NEEDS_CONTEXT → user |
| Audit trail | No | SubagentLog table |
| Timeout handling | Per-subagent | Per-subagent (5 min default) |
| Dependency ordering | Implicit | Explicit topological sort |
