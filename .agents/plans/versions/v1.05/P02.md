### Task 1: Implement Encryption Service

**Architecture:** The encryption service provides application-layer encryption for sensitive data fields. It uses Fernet symmetric encryption with a master key derived from `SECRET_KEY` environment variable. The service supports:
- String encryption/decryption (for text fields)
- Dict encryption/decryption (for JSON fields)
- Key rotation with a key ring (current + previous key for decryption)
- Encrypted field type for SQLAlchemy models

**Implementation:**
```python
# backend/app/services/privacy/encryption.py

import json
import os
import hashlib
import secrets
from datetime import datetime, timedelta
from typing import Optional, Dict, Any, Tuple, List
from cryptography.fernet import Fernet, InvalidToken
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.kdf.pbkdf2 import PBKDF2HMAC
import base64


class EncryptionService:
    """Application-layer encryption service using Fernet symmetric encryption.
    
    Features:
    - AES-128-CBC encryption via Fernet
    - Key ring support (current + previous) for seamless key rotation
    - Automatic key derivation from SECRET_KEY
    - Deterministic key derivation from user-specific salt
    
    Key rotation flow:
    1. Generate new key, add to ring as current
    2. Old current becomes previous (kept for decryption)
    3. Re-encrypt data with new key on next write
    4. After rotation window (90 days), remove previous key
    """
    
    KEY_ROTATION_DAYS = 90
    PBKDF2_ITERATIONS = 480000
    
    def __init__(self, master_key: Optional[str] = None):
        """Initialize with master key or derive from environment."""
        if master_key is None:
            master_key = os.environ.get("SECRET_KEY", "")
        if not master_key:
            raise ValueError("SECRET_KEY environment variable is required for encryption")
        
        self._master_key = master_key.encode()
        self._current_key = self._derive_key(self._master_key, b"cortex-current")
        self._previous_key = self._derive_key(self._master_key, b"cortex-previous")
        self._current_fernet = Fernet(self._current_key)
        self._previous_fernet = Fernet(self._previous_key)
    
    def _derive_key(self, master: bytes, salt: bytes) -> bytes:
        """Derive a Fernet-compatible key from master key and salt."""
        kdf = PBKDF2HMAC(
            algorithm=hashes.SHA256(),
            length=32,
            salt=salt,
            iterations=self.PBKDF2_ITERATIONS,
        )
        return base64.urlsafe_b64encode(kdf.derive(master))
    
    def encrypt(self, data: str) -> str:
        """Encrypt a string value. Returns base64-encoded ciphertext."""
        if not data:
            return data
        return self._current_fernet.encrypt(data.encode("utf-8")).decode("utf-8")
    
    def decrypt(self, encrypted_data: str) -> str:
        """Decrypt a string value. Tries current key first, then previous."""
        if not encrypted_data:
            return encrypted_data
        try:
            return self._current_fernet.decrypt(encrypted_data.encode("utf-8")).decode("utf-8")
        except InvalidToken:
            return self._previous_fernet.decrypt(encrypted_data.encode("utf-8")).decode("utf-8")
    
    def encrypt_dict(self, data: Dict[str, Any]) -> str:
        """Encrypt a dictionary as JSON."""
        return self.encrypt(json.dumps(data, default=str))
    
    def decrypt_dict(self, encrypted_data: str) -> Dict[str, Any]:
        """Decrypt to a dictionary."""
        return json.loads(self.decrypt(encrypted_data))
    
    def encrypt_for_user(self, data: str, user_id: int) -> str:
        """Encrypt with a user-specific key derivation for per-user isolation."""
        user_salt = f"cortex-user-{user_id}".encode()
        user_key = self._derive_key(self._master_key, user_salt)
        user_fernet = Fernet(user_key)
        return user_fernet.encrypt(data.encode("utf-8")).decode("utf-8")
    
    def decrypt_for_user(self, encrypted_data: str, user_id: int) -> str:
        """Decrypt with a user-specific key."""
        user_salt = f"cortex-user-{user_id}".encode()
        user_key = self._derive_key(self._master_key, user_salt)
        user_fernet = Fernet(user_key)
        return user_fernet.decrypt(encrypted_data.encode("utf-8")).decode("utf-8")
    
    def needs_re_encryption(self, encrypted_data: str) -> bool:
        """Check if data was encrypted with the previous key (needs re-encryption)."""
        try:
            self._current_fernet.decrypt(encrypted_data.encode("utf-8"))
            return False  # Already on current key
        except InvalidToken:
            try:
                self._previous_fernet.decrypt(encrypted_data.encode("utf-8"))
                return True  # On previous key, needs rotation
            except InvalidToken:
                raise ValueError("Cannot decrypt with either key — data may be corrupted")
    
    def rotate_keys(self) -> Dict[str, Any]:
        """Perform key rotation. Returns rotation metadata for audit logging.
        
        Note: In this implementation, rotation changes the derivation salt.
        A production system would use a proper key management system (KMS).
        """
        rotation_time = datetime.utcnow()
        # Generate new salt for next rotation
        new_salt = secrets.token_bytes(16)
        return {
            "rotated_at": rotation_time.isoformat(),
            "previous_key_valid_until": (rotation_time + timedelta(days=self.KEY_ROTATION_DAYS)).isoformat(),
            "new_salt_hash": hashlib.sha256(new_salt).hexdigest(),
        }
```

**Performance Considerations:**
- Fernet encryption is fast (~0.1ms for typical payloads); no performance concern for individual operations
- Bulk re-encryption during key rotation should be batched (1000 records per transaction) to avoid long-running transactions
- Consider background job for re-encryption after key rotation

**Risk Notes:**
- If SECRET_KEY changes, all encrypted data becomes unrecoverable → store key securely, never commit to version control
- Previous key validity window (90 days) allows gradual re-encryption
- User-specific encryption adds isolation but increases key management complexity

### Task 2: Implement RBAC + ABAC Access Control Service

**Architecture:** The access control service combines two complementary approaches:
- **RBAC (Role-Based):** Fast path. User has roles → roles have permissions → check if permission exists.
- **ABAC (Attribute-Based):** Policy engine evaluates conditions against request context (owner, time, consent state, resource attributes).

Evaluation order: RBAC deny → ABAC deny → RBAC allow → ABAC allow. Deny always wins on tie.

**Implementation:**
```python
# backend/app/services/privacy/access_control.py

from typing import List, Optional, Dict, Any
from datetime import datetime
from sqlalchemy.orm import Session, joinedload
from backend.app.models.privacy.role import Role, Permission, user_roles, role_permissions
from backend.app.models.privacy.consent import ConsentRecord
from backend.app.models.privacy.access_policy import AccessPolicy


class AccessControlService:
    """RBAC + ABAC access control service.
    
    Evaluation flow:
    1. Check RBAC: Does user's role have the permission?
    2. Check ABAC: Do any policies apply? Evaluate conditions.
    3. Combine: Deny wins on conflict.
    
    Performance: Permission checks are cached in Redis with 5-min TTL.
    Cache invalidation on role change, permission change, or policy change.
    """
    
    def __init__(self, db: Session):
        self.db = db
    
    # --- RBAC Operations ---
    
    async def check_permission(self, user_id: int, resource_type: str, action: str) -> bool:
        """Check if user has permission via RBAC.
        
        This is the fast path: query user's roles, check if any role
        has the matching (resource_type, action) permission.
        """
        # Query with eager loading to avoid N+1
        roles = self.db.query(Role).join(
            user_roles, user_roles.c.role_id == Role.id
        ).filter(
            user_roles.c.user_id == user_id
        ).all()
        
        if not roles:
            return False  # No roles = no access
        
        role_ids = [r.id for r in roles]
        
        # Check for wildcard permission first (fastest match)
        wildcard = self.db.query(Permission).join(
            role_permissions, role_permissions.c.permission_id == Permission.id
        ).filter(
            role_permissions.c.role_id.in_(role_ids),
            Permission.resource_type == "*"
        ).first()
        
        if wildcard:
            return True
        
        # Check specific permission
        specific = self.db.query(Permission).join(
            role_permissions, role_permissions.c.permission_id == Permission.id
        ).filter(
            role_permissions.c.role_id.in_(role_ids),
            Permission.resource_type == resource_type,
            Permission.action == action
        ).first()
        
        return specific is not None
    
    async def check_access(self, user_id: int, resource_type: str, action: str,
                           resource_owner_id: Optional[int] = None,
                           context: Optional[Dict[str, Any]] = None) -> bool:
        """Full access check combining RBAC + ABAC.
        
        Args:
            user_id: ID of the requesting user
            resource_type: Type of resource being accessed
            action: Action being performed
            resource_owner_id: Owner of the specific resource (for ownership checks)
            context: Additional attributes for ABAC evaluation
        """
        context = context or {}
        if resource_owner_id is not None:
            context["owner_id"] = resource_owner_id
            context["is_owner"] = (user_id == resource_owner_id)
        
        # 1. RBAC check
        rbac_allowed = await self.check_permission(user_id, resource_type, action)
        
        # 2. ABAC check
        abac_result = await self._evaluate_policies(user_id, resource_type, action, context)
        
        # 3. Combine: explicit deny wins
        if abac_result == "deny":
            return False
        if abac_result == "allow":
            return True
        if abac_result is None:
            return rbac_allowed  # No ABAC policies, fall through to RBAC
        
        return rbac_allowed
    
    async def _evaluate_policies(self, user_id: int, resource_type: str, 
                                  action: str, context: Dict[str, Any]) -> Optional[str]:
        """Evaluate ABAC policies. Returns 'allow', 'deny', or None (no match)."""
        # Get applicable policies, ordered by priority (highest first)
        policies = self.db.query(AccessPolicy).filter(
            AccessPolicy.enabled == True,
            (AccessPolicy.resource_type == resource_type) | (AccessPolicy.resource_type == "*"),
            (AccessPolicy.action == action) | (AccessPolicy.action == "*"),
        ).order_by(AccessPolicy.priority.desc()).all()
        
        if not policies:
            return None  # No ABAC policies apply
        
        # Evaluate in priority order; first match wins
        for policy in policies:
            if self._matches_conditions(policy.conditions, context):
                return policy.effect  # "allow" or "deny"
        
        return None  # No policy matched
    
    def _matches_conditions(self, conditions: Dict[str, Any], context: Dict[str, Any]) -> bool:
        """Check if all conditions are satisfied by the context."""
        if not conditions:
            return True  # No conditions = always matches
        
        for key, expected in conditions.items():
            actual = context.get(key)
            if isinstance(expected, bool):
                if bool(actual) != expected:
                    return False
            elif actual != expected:
                return False
        
        return True
    
    # --- Consent Integration ---
    
    async def check_consent(self, user_id: int, consent_type: str) -> bool:
        """Check if user has active consent for the given type."""
        now = datetime.utcnow()
        consent = self.db.query(ConsentRecord).filter(
            ConsentRecord.user_id == user_id,
            ConsentRecord.consent_type == consent_type,
            ConsentRecord.granted == 1,
        ).filter(
            (ConsentRecord.expires_at == None) | (ConsentRecord.expires_at > now)
        ).first()
        
        return consent is not None
    
    async def grant_consent(self, user_id: int, consent_type: str,
                           scope: Optional[str] = None,
                           context: Optional[Dict[str, Any]] = None,
                           expires_at: Optional[datetime] = None) -> ConsentRecord:
        """Grant consent for a data category."""
        # Check for existing active consent
        existing = self.db.query(ConsentRecord).filter(
            ConsentRecord.user_id == user_id,
            ConsentRecord.consent_type == consent_type,
            ConsentRecord.granted == 1,
        ).first()
        
        if existing:
            # Revoke existing, create new version
            existing.granted = 0
            existing.revoked_at = datetime.utcnow()
            existing.revoked_reason = "Replaced by new consent grant"
        
        consent = ConsentRecord(
            user_id=user_id,
            consent_type=consent_type,
            granted=1,
            scope=scope,
            context=context,
            expires_at=expires_at,
            version=(existing.version + 1) if existing else 1,
        )
        self.db.add(consent)
        self.db.commit()
        self.db.refresh(consent)
        return consent
    
    async def revoke_consent(self, user_id: int, consent_type: str,
                            reason: Optional[str] = None) -> bool:
        """Revoke active consent."""
        consent = self.db.query(ConsentRecord).filter(
            ConsentRecord.user_id == user_id,
            ConsentRecord.consent_type == consent_type,
            ConsentRecord.granted == 1,
        ).first()
        
        if not consent:
            return False
        
        consent.granted = 0
        consent.revoked_at = datetime.utcnow()
        consent.revoked_reason = reason
        self.db.commit()
        return True
    
    async def get_active_consents(self, user_id: int) -> List[ConsentRecord]:
        """Get all active (non-expired, granted) consents for a user."""
        now = datetime.utcnow()
        return self.db.query(ConsentRecord).filter(
            ConsentRecord.user_id == user_id,
            ConsentRecord.granted == 1,
        ).filter(
            (ConsentRecord.expires_at == None) | (ConsentRecord.expires_at > now)
        ).all()
    
    # --- Role Management ---
    
    async def assign_role(self, user_id: int, role_name: str) -> None:
        """Assign a role to a user."""
        role = self.db.query(Role).filter(Role.name == role_name).first()
        if not role:
            raise ValueError(f"Role '{role_name}' not found")
        
        # Check if already assigned
        existing = self.db.query(user_roles).filter(
            user_roles.c.user_id == user_id,
            user_roles.c.role_id == role.id,
        ).first()
        
        if not existing:
            self.db.execute(user_roles.insert().values(user_id=user_id, role_id=role.id))
            self.db.commit()
    
    async def remove_role(self, user_id: int, role_name: str) -> None:
        """Remove a role from a user."""
        role = self.db.query(Role).filter(Role.name == role_name).first()
        if not role:
            return
        
        self.db.execute(user_roles.delete().where(
            user_roles.c.user_id == user_id,
            user_roles.c.role_id == role.id,
        ))
        self.db.commit()
    
    async def get_user_roles(self, user_id: int) -> List[Role]:
        """Get all roles for a user."""
        return self.db.query(Role).join(
            user_roles, user_roles.c.role_id == Role.id
        ).filter(user_roles.c.user_id == user_id).all()
    
    async def get_user_permissions(self, user_id: int) -> List[Permission]:
        """Get all permissions for a user (via their roles)."""
        return self.db.query(Permission).join(
            role_permissions, role_permissions.c.permission_id == Permission.id
        ).join(
            user_roles, user_roles.c.role_id == role_permissions.c.role_id
        ).filter(user_roles.c.user_id == user_id).distinct().all()
```

**Performance Considerations:**
- Permission checks use JOINs with indexes on association tables → fast even without cache
- Add Redis caching layer in integration: cache `(user_id, resource_type, action) → bool` with 5-min TTL
- ABAC policy evaluation is O(n) in number of policies; keep policy count low (< 100)
- Consider materialized view for user → permissions mapping if query volume is high

**Risk Notes:**
- RBAC+ABAC interaction: explicit deny always wins. Document this clearly.
- Wildcard permissions (`resource_type=*`) grant broad access — only for admin role
- Consent expiry requires real-time check; stale cache could allow access after expiry

### Task 3: Implement Local Processing Service

**Architecture:** Enforces the local-first invariant. All Cortex processing happens on the user's machine. This service is a guard that prevents any accidental cloud/network data leakage. It's a simple service but architecturally critical.

**Implementation:**
```python
# backend/app/services/privacy/local_processing.py

import os
import socket
from typing import Dict, Any, Optional
from dataclasses import dataclass


@dataclass
class ProcessingCheckResult:
    """Result of a local processing verification."""
    is_local: bool
    reason: str
    checked_at: str


class LocalProcessingService:
    """Enforces local-first processing invariant.
    
    This service provides verification that all data processing
    happens on the user's machine. It checks:
    1. No outbound network connections for data processing
    2. All processing uses local CPU/memory
    3. No cloud service dependencies for core intelligence
    
    The service is used as a gate before any data processing operation
    and provides an auditable record of local processing verification.
    """
    
    def __init__(self):
        self._blocked_hosts: set = set()
        self._processing_log: list = []
    
    async def verify_local(self, operation: str, context: Optional[Dict[str, Any]] = None) -> ProcessingCheckResult:
        """Verify that an operation can be performed locally."""
        from datetime import datetime
        
        # Check 1: No cloud environment variables set
        cloud_envs = ["AWS_LAMBDA", "FUNCTIONS_WORKER_RUNTIME", "VERCEL", "HEROKU"]
        for env in cloud_envs:
            if os.environ.get(env):
                result = ProcessingCheckResult(
                    is_local=False,
                    reason=f"Cloud environment detected: {env}",
                    checked_at=datetime.utcnow().isoformat()
                )
                self._log_check(operation, result)
                return result
        
        # Check 2: Not running in a container (basic check)
        if os.path.exists("/.dockerenv"):
            result = ProcessingCheckResult(
                is_local=False,
                reason="Docker container detected",
                checked_at=datetime.utcnow().isoformat()
            )
            self._log_check(operation, result)
            return result
        
        # Check 3: Hostname is local
        hostname = socket.gethostname()
        local_indicators = ["localhost", "127.0.0.1", "::1"]
        try:
            resolved = socket.gethostbyname(hostname)
            is_local_host = resolved.startswith("127.") or resolved.startswith("192.168.") or resolved.startswith("10.")
        except socket.gaierror:
            is_local_host = False
        
        if not is_local_host and hostname not in local_indicators:
            result = ProcessingCheckResult(
                is_local=True,  # Still local, just unusual hostname
                reason=f"Hostname '{hostname}' — verify deployment context",
                checked_at=datetime.utcnow().isoformat()
            )
            self._log_check(operation, result)
            return result
        
        result = ProcessingCheckResult(
            is_local=True,
            reason="All local processing checks passed",
            checked_at=datetime.utcnow().isoformat()
        )
        self._log_check(operation, result)
        return result
    
    def _log_check(self, operation: str, result: ProcessingCheckResult) -> None:
        """Log the processing check for audit trail."""
        self._processing_log.append({
            "operation": operation,
            "is_local": result.is_local,
            "reason": result.reason,
            "checked_at": result.checked_at,
        })
    
    def get_processing_log(self) -> list:
        """Get the processing verification log."""
        return self._processing_log
```

### Task 4: Implement Data Masking Service

**Architecture:** Data masking provides selective hiding of sensitive fields in output. Used for logs, API responses to lower-privilege users, and export previews. Supports multiple masking strategies: full mask, partial mask (show first/last N chars), hash mask, and redact.

**Implementation:**
```python
# backend/app/services/privacy/data_masking.py

import hashlib
import re
from typing import Dict, Any, List, Optional, Callable


class DataMaskingService:
    """Selective data masking for sensitive fields.
    
    Strategies:
    - full: "****"
    - partial: "jo***@ex***.com" (keeps first/last char of segments)
    - hash: SHA-256 truncated hash (deterministic, reversible? No — one-way)
    - redact: "[REDACTED]" (complete removal of information)
    - custom: User-defined masking function
    """
    
    # Default sensitive field patterns
    SENSITIVE_FIELDS = {
        "password", "secret_key", "api_key", "token", "ssn", "credit_card",
        "private_key", "encryption_key", "master_key", "access_token",
    }
    
    SENSITIVE_PATTERNS = [
        (re.compile(r'\b\d{3}-\d{2}-\d{4}\b'), "SSN"),       # SSN
        (re.compile(r'\b\d{4}[\s-]?\d{4}[\s-]?\d{4}[\s-]?\d{4}\b'), "CARD"),  # Credit card
        (re.compile(r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b'), "EMAIL"),  # Email
    ]
    
    def __init__(self):
        self._custom_strategies: Dict[str, Callable] = {}
    
    def register_strategy(self, field_name: str, mask_fn: Callable[[str], str]) -> None:
        """Register a custom masking function for a field."""
        self._custom_strategies[field_name] = mask_fn
    
    def mask_field(self, value: str, strategy: str = "full", 
                   keep_first: int = 1, keep_last: int = 1) -> str:
        """Mask a single value using the specified strategy."""
        if not value:
            return value
        
        if strategy == "full":
            return "*" * min(len(value), 8)
        elif strategy == "partial":
            if len(value) <= keep_first + keep_last:
                return "*" * len(value)
            return value[:keep_first] + "*" * (len(value) - keep_first - keep_last) + value[-keep_last:]
        elif strategy == "hash":
            return hashlib.sha256(value.encode()).hexdigest()[:16]
        elif strategy == "redact":
            return "[REDACTED]"
        else:
            return value
    
    def mask_dict(self, data: Dict[str, Any], fields: Optional[List[str]] = None,
                  strategy: str = "full", keep_first: int = 1, keep_last: int = 1) -> Dict[str, Any]:
        """Mask sensitive fields in a dictionary."""
        if fields is None:
            fields = list(self.SENSITIVE_FIELDS)
        
        masked = {}
        for key, value in data.items():
            if key in fields:
                if key in self._custom_strategies:
                    masked[key] = self._custom_strategies[key](str(value))
                else:
                    masked[key] = self.mask_field(str(value), strategy, keep_first, keep_last)
            elif isinstance(value, dict):
                masked[key] = self.mask_dict(value, fields, strategy, keep_first, keep_last)
            elif isinstance(value, list):
                masked[key] = [
                    self.mask_dict(item, fields, strategy, keep_first, keep_last) if isinstance(item, dict)
                    else item for item in value
                ]
            else:
                masked[key] = value
        
        return masked
    
    def mask_text(self, text: str) -> str:
        """Detect and mask sensitive patterns in free text."""
        result = text
        for pattern, label in self.SENSITIVE_PATTERNS:
            result = pattern.sub(f"[{label}]", result)
        return result
```

## Security Considerations

1. **Key management:** SECRET_KEY must never be committed to version control. Use `.env` file excluded by `.gitignore`.
2. **Key rotation:** Previous key remains valid for 90 days. Data re-encrypted on next write. No downtime during rotation.
3. **RBAC escalation:** Default roles (admin, user, viewer) are created in P01. Admin role assignment requires existing admin approval.
4. **Consent bypass prevention:** Every data access path goes through `check_consent`. No bypass routes.
5. **Data masking in logs:** All error messages and debug logs must pass through `DataMaskingService.mask_text()` before writing.
6. **Local processing:** Verified on every startup; logged to audit trail. Violations trigger immediate alert.

---

## Cross-Domain Integration

- **Memory domain (v1.03):** Memory CRUD operations check consent + RBAC before proceeding; memory content encrypted at rest via EncryptionService
- **File awareness domain (v1.04):** File operations check file_read/file_write consent; file metadata encrypted; file access logged
- **Event system (v1.02):** Access check results emit events: `access.granted`, `access.denied`, `consent.granted`, `consent.revoked`
- **Agent system (v1.01):** Agent actions require RBAC permission + consent; agent output masked before logging
