## Implementation Tasks

### Task 1: Implement Graph Construction Service

**File:** `backend/app/services/memory/graph_builder.py`
**Purpose:** Populate the graph from existing memories. Runs once on first use, then incrementally as new memories are created. Uses Jaccard similarity for initial edge creation, with LLM-based entity extraction for higher-quality edges in future iterations.

```python
# backend/app/services/memory/graph_builder.py

import json
from typing import List, Dict, Tuple
from sqlalchemy.orm import Session
from backend.app.models.memory.memory_node import MemoryNode
from backend.app.models.memory.memory_edge import MemoryEdge
from backend.app.models.memory.episodic_memory import EpisodicMemory
from backend.app.models.memory.semantic_memory import SemanticMemory


class GraphBuilderService:
    """Constructs and maintains the memory graph.
    
    Populates graph nodes from existing episodic/semantic/working memories.
    Creates edges based on content similarity (Jaccard) and temporal proximity.
    
    Architecture ref: 4.4 (Graph Architecture) — LLM-based entity extraction
    is the target; Jaccard similarity is the v1.07 initial implementation.
    """
    
    SIMILARITY_THRESHOLD = 0.3   # Minimum Jaccard similarity for edge creation
    MAX_EDGES_PER_NODE = 20      # Prevent graph explosion
    TEMPORAL_WINDOW_HOURS = 24   # Memories within 24h get temporal edges
    
    def __init__(self, db: Session):
        self.db = db
    
    async def build_full_graph(self, user_id: int) -> Dict:
        """Build graph from all existing memories. Idempotent."""
        # Step 1: Create nodes for all memories
        node_count = await self._create_nodes_from_episodic(user_id)
        node_count += await self._create_nodes_from_semantic(user_id)
        
        # Step 2: Create edges based on similarity
        edge_count = await self._create_similarity_edges(user_id)
        
        # Step 3: Create temporal edges for nearby memories
        edge_count += await self._create_temporal_edges(user_id)
        
        return {"nodes_created": node_count, "edges_created": edge_count}
    
    async def add_memory_to_graph(self, user_id: int, memory_type: str, 
                                   memory_id: int, content: str) -> MemoryNode:
        """Add a single new memory to the graph. Called on memory creation."""
        # Create node
        node = MemoryNode(
            user_id=user_id, memory_type=memory_type, memory_id=memory_id,
            label=content[:200], confidence=0.8
        )
        self.db.add(node)
        self.db.commit()
        
        # Find similar existing nodes and create edges
        existing_nodes = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id,
            MemoryNode.id != node.id
        ).all()
        
        edge_count = 0
        for existing in existing_nodes:
            existing_content = existing.label or ""
            similarity = self._jaccard_similarity(content, existing_content)
            if similarity >= self.SIMILARITY_THRESHOLD:
                edge = MemoryEdge(
                    source_node_id=node.id, target_node_id=existing.id,
                    relationship="related_to", weight=similarity,
                    confidence=similarity
                )
                self.db.add(edge)
                edge_count += 1
                if edge_count >= self.MAX_EDGES_PER_NODE:
                    break
        
        self.db.commit()
        return node
    
    async def _create_nodes_from_episodic(self, user_id: int) -> int:
        """Create graph nodes for all episodic memories."""
        existing_refs = {
            (n.memory_type, n.memory_id) 
            for n in self.db.query(MemoryNode).filter(
                MemoryNode.user_id == user_id,
                MemoryNode.memory_type == "episodic"
            ).all()
        }
        
        episodic = self.db.query(EpisodicMemory).filter(
            EpisodicMemory.user_id == user_id
        ).all()
        
        count = 0
        for mem in episodic:
            if ("episodic", mem.id) not in existing_refs:
                node = MemoryNode(
                    user_id=user_id, memory_type="episodic", memory_id=mem.id,
                    label=mem.content[:200] if hasattr(mem, 'content') else f"episodic:{mem.id}",
                    confidence=mem.importance if hasattr(mem, 'importance') else 0.5
                )
                self.db.add(node)
                count += 1
        
        self.db.commit()
        return count
    
    async def _create_nodes_from_semantic(self, user_id: int) -> int:
        """Create graph nodes for all semantic memories."""
        existing_refs = {
            (n.memory_type, n.memory_id)
            for n in self.db.query(MemoryNode).filter(
                MemoryNode.user_id == user_id,
                MemoryNode.memory_type == "semantic"
            ).all()
        }
        
        semantic = self.db.query(SemanticMemory).filter(
            SemanticMemory.user_id == user_id
        ).all()
        
        count = 0
        for mem in semantic:
            if ("semantic", mem.id) not in existing_refs:
                node = MemoryNode(
                    user_id=user_id, memory_type="semantic", memory_id=mem.id,
                    label=mem.topic[:200] if hasattr(mem, 'topic') else f"semantic:{mem.id}",
                    confidence=mem.confidence if hasattr(mem, 'confidence') else 0.5
                )
                self.db.add(node)
                count += 1
        
        self.db.commit()
        return count
    
    async def _create_similarity_edges(self, user_id: int) -> int:
        """Create edges between similar nodes using Jaccard similarity."""
        nodes = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id
        ).all()
        
        edge_count = 0
        for i, node_a in enumerate(nodes):
            edges_for_node = 0
            for node_b in nodes[i+1:]:
                similarity = self._jaccard_similarity(
                    node_a.label or "", node_b.label or ""
                )
                if similarity >= self.SIMILARITY_THRESHOLD:
                    # Check if edge already exists
                    existing = self.db.query(MemoryEdge).filter(
                        MemoryEdge.source_node_id == node_a.id,
                        MemoryEdge.target_node_id == node_b.id
                    ).first()
                    if not existing:
                        edge = MemoryEdge(
                            source_node_id=node_a.id, target_node_id=node_b.id,
                            relationship="related_to", weight=similarity,
                            confidence=similarity
                        )
                        self.db.add(edge)
                        edge_count += 1
                        edges_for_node += 1
                        if edges_for_node >= self.MAX_EDGES_PER_NODE:
                            break
        
        self.db.commit()
        return edge_count
    
    async def _create_temporal_edges(self, user_id: int) -> int:
        """Create 'followed_by' edges for memories within temporal window."""
        nodes = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id
        ).order_by(MemoryNode.created_at).all()
        
        edge_count = 0
        for i in range(len(nodes) - 1):
            time_diff = (nodes[i+1].created_at - nodes[i].created_at).total_seconds() / 3600
            if time_diff <= self.TEMPORAL_WINDOW_HOURS:
                existing = self.db.query(MemoryEdge).filter(
                    MemoryEdge.source_node_id == nodes[i].id,
                    MemoryEdge.target_node_id == nodes[i+1].id,
                    MemoryEdge.relationship == "followed_by"
                ).first()
                if not existing:
                    weight = max(0.1, 1.0 - (time_diff / self.TEMPORAL_WINDOW_HOURS))
                    edge = MemoryEdge(
                        source_node_id=nodes[i].id, target_node_id=nodes[i+1].id,
                        relationship="followed_by", weight=weight
                    )
                    self.db.add(edge)
                    edge_count += 1
        
        self.db.commit()
        return edge_count
    
    def _jaccard_similarity(self, text1: str, text2: str) -> float:
        """Calculate Jaccard similarity between two text strings."""
        if not text1 or not text2:
            return 0.0
        words1 = set(text1.lower().split())
        words2 = set(text2.lower().split())
        if not words1 or not words2:
            return 0.0
        intersection = words1 & words2
        union = words1 | words2
        return len(intersection) / len(union) if union else 0.0
```

### Task 2: Implement Consolidation Service

**File:** `backend/app/services/memory/consolidation.py`
**Purpose:** Merge similar episodic memories into consolidated semantic knowledge. Uses two-phase approach: (1) find similar memory pairs, (2) merge into new semantic memory. This is the "sleep consolidation" equivalent — background task that runs periodically via arq job.

```python
# backend/app/services/memory/consolidation.py

import json
from typing import List, Dict, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from backend.app.models.memory.memory_node import MemoryNode
from backend.app.models.memory.memory_edge import MemoryEdge
from backend.app.models.memory.episodic_memory import EpisodicMemory
from backend.app.models.memory.semantic_memory import SemanticMemory


class MemoryConsolidationService:
    """Merges similar episodic memories into semantic knowledge.
    
    Implements two-phase consolidation:
    1. Find similar episodic memory pairs (Jaccard > 0.8)
    2. Merge into semantic memory with combined content
    
    Runs as background job via arq (Architecture Principle 4.7).
    Conservative threshold (0.8) to prevent false merges.
    
    Architecture ref: 4.3 (Memory Architecture) — LLM-based two-phase extraction.
    v1.07 uses Jaccard; LLM extraction added in future version.
    """
    
    SIMILARITY_THRESHOLD = 0.8    # Conservative — only merge very similar
    MAX_CONSOLIDATIONS_PER_RUN = 50  # Prevent runaway consolidation
    
    def __init__(self, db: Session):
        self.db = db
    
    async def consolidate(self, user_id: int) -> Dict:
        """Consolidate similar episodic memories into semantic knowledge.
        
        Returns: {"consolidated": int, "semantic_created": int, "pairs_found": int}
        """
        # Get recent episodic memories (last 100)
        episodic = self.db.query(EpisodicMemory).filter(
            EpisodicMemory.user_id == user_id
        ).order_by(EpisodicMemory.created_at.desc()).limit(100).all()
        
        if len(episodic) < 2:
            return {"consolidated": 0, "semantic_created": 0, "pairs_found": 0}
        
        # Find similar pairs
        similar_pairs = []
        for i, mem1 in enumerate(episodic):
            for mem2 in episodic[i+1:]:
                content1 = getattr(mem1, 'content', '') or ''
                content2 = getattr(mem2, 'content', '') or ''
                similarity = self._calculate_similarity(content1, content2)
                if similarity > self.SIMILARITY_THRESHOLD:
                    similar_pairs.append((mem1, mem2, similarity))
        
        # Sort by similarity (highest first) and limit
        similar_pairs.sort(key=lambda x: x[2], reverse=True)
        similar_pairs = similar_pairs[:self.MAX_CONSOLIDATIONS_PER_RUN]
        
        # Merge pairs into semantic memories
        semantic_count = 0
        for mem1, mem2, sim in similar_pairs:
            semantic = await self._merge_to_semantic(user_id, mem1, mem2)
            if semantic:
                # Create graph nodes for the new semantic memory
                await self._create_consolidation_graph(user_id, mem1, mem2, semantic)
                semantic_count += 1
        
        return {
            "consolidated": len(similar_pairs),
            "semantic_created": semantic_count,
            "pairs_found": len(similar_pairs)
        }
    
    async def _merge_to_semantic(self, user_id: int, mem1, mem2) -> Optional[SemanticMemory]:
        """Merge two episodic memories into a single semantic memory."""
        content1 = getattr(mem1, 'content', '') or ''
        content2 = getattr(mem2, 'content', '') or ''
        importance1 = getattr(mem1, 'importance', 0.5) or 0.5
        importance2 = getattr(mem2, 'importance', 0.5) or 0.5
        
        # Extract topic from combined content (simple keyword extraction)
        topic = self._extract_topic(content1, content2)
        
        semantic = SemanticMemory(
            user_id=user_id,
            topic=f"Consolidated: {topic}",
            content=f"{content1}\n\n---\n\n{content2}",
            confidence=max(importance1, importance2)
        )
        self.db.add(semantic)
        self.db.commit()
        return semantic
    
    async def _create_consolidation_graph(self, user_id: int, mem1, mem2, semantic) -> None:
        """Create graph structure for consolidation event."""
        # Get or create nodes for source memories
        node1 = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id,
            MemoryNode.memory_type == "episodic",
            MemoryNode.memory_id == mem1.id
        ).first()
        
        node2 = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id,
            MemoryNode.memory_type == "episodic",
            MemoryNode.memory_id == mem2.id
        ).first()
        
        # Create node for consolidated semantic memory
        semantic_node = MemoryNode(
            user_id=user_id, memory_type="semantic", memory_id=semantic.id,
            label=f"Consolidated: {semantic.topic[:200]}",
            confidence=semantic.confidence
        )
        self.db.add(semantic_node)
        self.db.commit()
        
        # Create 'derived_from' edges
        if node1:
            edge1 = MemoryEdge(
                source_node_id=semantic_node.id, target_node_id=node1.id,
                relationship="derived_from", weight=0.9
            )
            self.db.add(edge1)
        if node2:
            edge2 = MemoryEdge(
                source_node_id=semantic_node.id, target_node_id=node2.id,
                relationship="derived_from", weight=0.9
            )
            self.db.add(edge2)
        
        self.db.commit()
    
    def _extract_topic(self, content1: str, content2: str) -> str:
        """Extract common topic from two content strings."""
        words1 = set(content1.lower().split())
        words2 = set(content2.lower().split())
        common = words1 & words2
        # Filter out stop words
        stop_words = {"the", "a", "an", "is", "are", "was", "were", "in", "on", "at", "to", "for", "of", "and", "or", "but"}
        meaningful = common - stop_words
        return " ".join(list(meaningful)[:5]) if meaningful else "mixed topics"
    
    def _calculate_similarity(self, text1: str, text2: str) -> float:
        """Calculate Jaccard similarity."""
        if not text1 or not text2:
            return 0.0
        words1 = set(text1.lower().split())
        words2 = set(text2.lower().split())
        if not words1 or not words2:
            return 0.0
        return len(words1 & words2) / len(words1 | words2)
```

### Task 3: Implement Evolution Service

**File:** `backend/app/services/memory/evolution.py`
**Purpose:** Apply memory lifecycle — strengthen on access, decay over time, invalidate on contradiction. Implements the confidence decay (0.95x per 30 days) and access-count reinforcement from Architecture Principle 4.3.

```python
# backend/app/services/memory/evolution.py

from datetime import datetime, timedelta
from typing import Dict, List
from sqlalchemy.orm import Session
from backend.app.models.memory.memory_node import MemoryNode
from backend.app.models.memory.memory_edge import MemoryEdge


class MemoryEvolutionService:
    """Evolves memory graph over time — strengthen, decay, invalidate.
    
    Implements three evolution mechanisms:
    1. Reinforcement: accessed memories gain confidence (+0.1 per access)
    2. Decay: unused memories lose confidence (0.95x per 30 days)
    3. Invalidation: contradicted memories get invalid_at timestamp
    
    Architecture ref: 4.3 (Memory Architecture):
    - Confidence decay (0.95x/30d)
    - Access-count reinforcement
    - Graphiti-pattern contradiction detection
    """
    
    DECAY_RATE = 0.01          # Confidence lost per day since last access
    MIN_CONFIDENCE = 0.1       # Floor — never fully forget
    REINFORCEMENT_AMOUNT = 0.1  # Confidence gained per access
    MAX_EDGE_WEIGHT = 2.0       # Cap on edge weight
    
    def __init__(self, db: Session):
        self.db = db
    
    async def reinforce_memory(self, memory_type: str, memory_id: int) -> Dict:
        """Strengthen a memory on access (access-count reinforcement)."""
        node = self.db.query(MemoryNode).filter(
            MemoryNode.memory_type == memory_type,
            MemoryNode.memory_id == memory_id
        ).first()
        
        if not node:
            return {"reinforced": False, "reason": "node not found"}
        
        node.reinforce(self.REINFORCEMENT_AMOUNT)
        
        # Also reinforce connected edges
        edges = self.db.query(MemoryEdge).filter(
            (MemoryEdge.source_node_id == node.id) |
            (MemoryEdge.target_node_id == node.id),
            MemoryEdge.invalid_at.is_(None)
        ).all()
        
        for edge in edges:
            edge.reinforce(0.05)  # Smaller reinforcement for edges
        
        self.db.commit()
        
        return {
            "reinforced": True,
            "new_confidence": node.confidence,
            "edges_reinforced": len(edges)
        }
    
    async def decay_memories(self, user_id: int) -> Dict:
        """Apply time-based decay to all memories. Run daily via arq job."""
        nodes = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id
        ).all()
        
        decayed_nodes = 0
        for node in nodes:
            if node.confidence and node.confidence > self.MIN_CONFIDENCE:
                last_activity = node.last_accessed or node.created_at
                days_since = (datetime.utcnow() - last_activity).days
                decay = self.DECAY_RATE * days_since
                node.confidence = max(self.MIN_CONFIDENCE, node.confidence - decay)
                decayed_nodes += 1
        
        # Also decay edge weights
        edges = self.db.query(MemoryEdge).join(
            MemoryNode, MemoryEdge.source_node_id == MemoryNode.id
        ).filter(
            MemoryNode.user_id == user_id,
            MemoryEdge.invalid_at.is_(None)
        ).all()
        
        decayed_edges = 0
        for edge in edges:
            last_activity = edge.last_reinforced or edge.created_at
            days_since = (datetime.utcnow() - last_activity).days
            decay = self.DECAY_RATE * days_since
            edge.weight = max(0.1, edge.weight - decay)
            decayed_edges += 1
        
        self.db.commit()
        
        return {"decayed_nodes": decayed_nodes, "decayed_edges": decayed_edges}
    
    async def invalidate_memory(self, memory_type: str, memory_id: int, 
                                 reason: str = "contradicted") -> Dict:
        """Invalidate a memory (Graphiti-pattern contradiction detection)."""
        node = self.db.query(MemoryNode).filter(
            MemoryNode.memory_type == memory_type,
            MemoryNode.memory_id == memory_id
        ).first()
        
        if not node:
            return {"invalidated": False, "reason": "node not found"}
        
        # Reduce confidence dramatically
        node.confidence = 0.1
        
        # Invalidate all connected edges
        edges = self.db.query(MemoryEdge).filter(
            (MemoryEdge.source_node_id == node.id) |
            (MemoryEdge.target_node_id == node.id),
            MemoryEdge.invalid_at.is_(None)
        ).all()
        
        for edge in edges:
            edge.invalidate()
        
        self.db.commit()
        
        return {
            "invalidated": True,
            "edges_invalidated": len(edges),
            "reason": reason
        }
    
    async def get_evolution_stats(self, user_id: int) -> Dict:
        """Get evolution statistics for monitoring."""
        nodes = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id
        ).all()
        
        if not nodes:
            return {"total_nodes": 0, "avg_confidence": 0, "stale_count": 0}
        
        confidences = [n.confidence for n in nodes if n.confidence is not None]
        stale_count = sum(1 for n in nodes if n.is_stale)
        
        return {
            "total_nodes": len(nodes),
            "avg_confidence": sum(confidences) / len(confidences) if confidences else 0,
            "stale_count": stale_count,
            "high_confidence": sum(1 for c in confidences if c > 0.8),
            "low_confidence": sum(1 for c in confidences if c < 0.3)
        }
```

### Task 4: Implement Reflection Service

**File:** `backend/app/services/memory/reflection.py`
**Purpose:** Meta-analysis of memory state. Identifies most-connected nodes, orphan memories, high-centrality knowledge hubs. Generates insights about what Cortex knows well vs. poorly.

```python
# backend/app/services/memory/reflection.py

from typing import List, Dict
from sqlalchemy.orm import Session
from sqlalchemy import func
from backend.app.models.memory.memory_node import MemoryNode
from backend.app.models.memory.memory_edge import MemoryEdge


class MemoryReflectionService:
    """Reflects on memory graph state and generates meta-insights.
    
    Provides:
    - Graph health metrics (orphan count, avg connectivity)
    - Most-connected nodes (knowledge hubs)
    - Orphan detection (isolated memories)
    - Knowledge coverage assessment
    
    Architecture ref: 3.7 (Incremental Safety) — meta-cognition for self-assessment
    """
    
    def __init__(self, db: Session):
        self.db = db
    
    async def reflect(self, user_id: int) -> Dict:
        """Full reflection on memory graph state."""
        nodes = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id
        ).all()
        
        edges = self.db.query(MemoryEdge).join(
            MemoryNode, MemoryEdge.source_node_id == MemoryNode.id
        ).filter(
            MemoryNode.user_id == user_id,
            MemoryEdge.invalid_at.is_(None)
        ).all()
        
        if not nodes:
            return {"insights": ["No memories to reflect on"], "health_score": 0.0}
        
        # Calculate metrics
        node_ids = {n.id for n in nodes}
        connected_nodes = set()
        for edge in edges:
            connected_nodes.add(edge.source_node_id)
            connected_nodes.add(edge.target_node_id)
        
        orphan_count = len(node_ids - connected_nodes)
        avg_degree = (len(edges) * 2) / len(nodes) if nodes else 0
        
        # Find knowledge hubs (nodes with most connections)
        degree_count = {}
        for edge in edges:
            degree_count[edge.source_node_id] = degree_count.get(edge.source_node_id, 0) + 1
            degree_count[edge.target_node_id] = degree_count.get(edge.target_node_id, 0) + 1
        
        hubs = sorted(degree_count.items(), key=lambda x: x[1], reverse=True)[:5]
        
        # Generate insights
        insights = []
        if orphan_count > len(nodes) * 0.3:
            insights.append(f"Warning: {orphan_count} orphan memories ({orphan_count/len(nodes)*100:.0f}%) — consider consolidation")
        if avg_degree < 1.0:
            insights.append("Low connectivity — memories may need more cross-links")
        if avg_degree > 5.0:
            insights.append("High connectivity — graph is well-connected")
        
        health_score = min(1.0, (avg_degree / 3.0) * (1 - orphan_count / len(nodes)))
        
        return {
            "total_nodes": len(nodes),
            "total_edges": len(edges),
            "orphan_count": orphan_count,
            "avg_degree": round(avg_degree, 2),
            "health_score": round(health_score, 3),
            "knowledge_hubs": [
                {"node_id": nid, "degree": deg} for nid, deg in hubs
            ],
            "insights": insights,
            "nodes_by_type": self._count_by_type(nodes)
        }
    
    async def get_orphan_memories(self, user_id: int) -> List[Dict]:
        """Find memories with no connections."""
        connected_node_ids = set()
        edges = self.db.query(MemoryEdge).join(
            MemoryNode, MemoryEdge.source_node_id == MemoryNode.id
        ).filter(MemoryNode.user_id == user_id).all()
        
        for edge in edges:
            connected_node_ids.add(edge.source_node_id)
            connected_node_ids.add(edge.target_node_id)
        
        orphans = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id
        ).all()
        
        return [
            {"id": n.id, "type": n.memory_type, "ref": n.memory_id, "label": n.label}
            for n in orphans if n.id not in connected_node_ids
        ]
    
    async def get_knowledge_hubs(self, user_id: int, top_n: int = 10) -> List[Dict]:
        """Find most-connected nodes (knowledge hubs)."""
        edges = self.db.query(MemoryEdge).join(
            MemoryNode, MemoryEdge.source_node_id == MemoryNode.id
        ).filter(
            MemoryNode.user_id == user_id,
            MemoryEdge.invalid_at.is_(None)
        ).all()
        
        degree_count = {}
        for edge in edges:
            degree_count[edge.source_node_id] = degree_count.get(edge.source_node_id, 0) + 1
            degree_count[edge.target_node_id] = degree_count.get(edge.target_node_id, 0) + 1
        
        top_nodes = sorted(degree_count.items(), key=lambda x: x[1], reverse=True)[:top_n]
        
        result = []
        for node_id, degree in top_nodes:
            node = self.db.query(MemoryNode).filter(MemoryNode.id == node_id).first()
            if node:
                result.append({
                    "node_id": node_id,
                    "degree": degree,
                    "type": node.memory_type,
                    "label": node.label,
                    "confidence": node.confidence
                })
        
        return result
    
    def _count_by_type(self, nodes: List[MemoryNode]) -> Dict:
        """Count nodes by memory type."""
        counts = {}
        for node in nodes:
            counts[node.memory_type] = counts.get(node.memory_type, 0) + 1
        return counts
```

## Cross-Domain Integration Notes

- **v1.03 (Memory Foundation)** — Consolidation reads from existing episodic/semantic memory tables. Creates new semantic memories via the same model. No changes to v1.03 services.
- **v1.02 (Backend Architecture)** — Services use constructor injection. Background jobs use arq + Redis. Event bus dispatches consolidation triggers.
- **v1.04 (Awareness Foundation)** — Future integration: awareness events trigger consolidation of related memories.

---

## Security Considerations

1. **User isolation** — All services filter by `user_id`. Never consolidate across users.
2. **Content safety** — Consolidation preserves original content in combined semantic memory. No data loss.
3. **Rate limiting** — `MAX_CONSOLIDATIONS_PER_RUN = 50` prevents runaway consolidation.
4. **Background job safety** — Consolidation runs as arq job with timeout. If it crashes, it restarts from last commit point.
5. **Decay floor** — `MIN_CONFIDENCE = 0.1` ensures memories are never fully forgotten (user can always recover).

---

## Performance Considerations

1. **Consolidation batch size** — Max 100 episodic memories per consolidation run. Process in batches.
2. **Similarity computation** — O(n²) pairwise comparison. For >1000 memories, use vector similarity (future optimization).
3. **Decay job frequency** — Run daily via arq cron. Process all users in batches of 100.
4. **Reflection query** — Uses JOIN + GROUP BY. Add index on `(source_node_id, invalid_at)` if slow.
5. **Graph construction** — One-time cost. Incremental addition is O(n) per new memory (compare against existing).
