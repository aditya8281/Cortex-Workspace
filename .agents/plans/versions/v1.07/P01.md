## Implementation Tasks

### Task 1: Create Memory Node Model

**File:** `backend/app/models/memory/memory_node.py`
**Purpose:** Represent a memory as a graph node. Each node references an existing memory (episodic, semantic, or working) via a polymorphic `(memory_type, memory_id)` pair. This avoids multiple FK columns or a content-type system while allowing graph nodes to reference any memory type without schema changes.

**Database Schema:**
```sql
CREATE TABLE memory_nodes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    memory_type VARCHAR(50) NOT NULL,     -- 'episodic', 'semantic', 'working'
    memory_id INTEGER NOT NULL,            -- FK to source memory table (polymorphic)
    label VARCHAR(500),                    -- Human-readable label for visualization
    embedding JSON,                        -- 768-dim vector for similarity search
    confidence FLOAT DEFAULT 1.0,          -- 0.0 to 1.0, decays over time
    metadata JSON,                         -- Extensible properties (LLM extraction, provenance)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_accessed TIMESTAMP,               -- Updated on recall (access-count reinforcement)
    UNIQUE(user_id, memory_type, memory_id)
);
CREATE INDEX idx_memory_nodes_user ON memory_nodes(user_id);
CREATE INDEX idx_memory_nodes_type ON memory_nodes(user_id, memory_type);
CREATE INDEX idx_memory_nodes_confidence ON memory_nodes(user_id, confidence);
```

**Implementation:**
```python
# backend/app/models/memory/memory_node.py

from sqlalchemy import Column, Integer, String, DateTime, JSON, Float, UniqueConstraint, Index
from sqlalchemy.orm import relationship
from datetime import datetime
from backend.app.db.base import Base


class MemoryNode(Base):
    """Graph node representing a memory in the knowledge graph.
    
    Each node references an existing memory (episodic, semantic, working)
    via polymorphic (memory_type, memory_id) pair. This allows the graph
    to connect any memory type without schema changes.
    
    Architecture refs:
    - 4.4 (Graph Architecture): explicit service boundary
    - 4.3 (Memory Architecture): confidence scoring, bi-temporal
    """
    __tablename__ = "memory_nodes"
    __table_args__ = (
        UniqueConstraint("user_id", "memory_type", "memory_id", name="uq_memory_node_ref"),
        Index("idx_memory_nodes_user", "user_id"),
        Index("idx_memory_nodes_type", "user_id", "memory_type"),
        Index("idx_memory_nodes_confidence", "user_id", "confidence"),
    )

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, nullable=False, index=True)
    memory_type = Column(String(50), nullable=False)  # "episodic", "semantic", "working"
    memory_id = Column(Integer, nullable=False)         # FK to source memory table
    label = Column(String(500), nullable=True)          # Human-readable label
    embedding = Column(JSON, nullable=True)             # 768-dim vector (JSON serialized)
    confidence = Column(Float, nullable=False, default=1.0)  # 0.0 to 1.0
    metadata = Column(JSON, nullable=True)              # Extensible properties
    created_at = Column(DateTime, nullable=False, default=datetime.utcnow)
    last_accessed = Column(DateTime, nullable=True)     # Updated on recall

    # Relationships
    source_edges = relationship("MemoryEdge", foreign_keys="MemoryEdge.source_node_id", back_populates="source_node")
    target_edges = relationship("MemoryEdge", foreign_keys="MemoryEdge.target_node_id", back_populates="target_node")

    def __repr__(self) -> str:
        return f"<MemoryNode(id={self.id}, type={self.memory_type}, ref={self.memory_id})>"

    @property
    def is_stale(self) -> bool:
        """Check if node confidence has decayed below useful threshold."""
        return (self.confidence or 0.0) < 0.3

    def reinforce(self, amount: float = 0.1) -> None:
        """Strengthen node confidence on access (access-count reinforcement)."""
        self.confidence = min(1.0, (self.confidence or 0.5) + amount)
        self.last_accessed = datetime.utcnow()
```

### Task 2: Create Memory Edge Model

**File:** `backend/app/models/memory/memory_edge.py`
**Purpose:** Represent relationships between memories as typed, weighted, bi-temporal edges. Edges support the Graphiti-pattern contradiction detection (Architecture Principle 4.3) via `valid_at`/`invalid_at` timestamps. When a contradiction is found, the old edge gets `invalid_at` and a new edge with corrected relationship is created.

**Database Schema:**
```sql
CREATE TABLE memory_edges (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    source_node_id INTEGER NOT NULL,
    target_node_id INTEGER NOT NULL,
    relationship VARCHAR(100) NOT NULL,   -- 'related_to', 'caused_by', 'part_of', 'contradicts', 'supports'
    weight FLOAT DEFAULT 1.0,             -- Strength of connection (0.0 to 2.0, capped)
    confidence FLOAT DEFAULT 1.0,         -- How sure we are about this edge
    metadata JSON,                        -- Extensible properties
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_reinforced TIMESTAMP,            -- Updated when edge is traversed
    valid_at TIMESTAMP,                   -- Bi-temporal: when edge became true
    invalid_at TIMESTAMP,                 -- Bi-temporal: when edge stopped being true
    FOREIGN KEY (source_node_id) REFERENCES memory_nodes(id),
    FOREIGN KEY (target_node_id) REFERENCES memory_nodes(id)
);
CREATE INDEX idx_memory_edges_source ON memory_edges(source_node_id);
CREATE INDEX idx_memory_edges_target ON memory_edges(target_node_id);
CREATE INDEX idx_memory_edges_rel ON memory_edges(relationship);
CREATE INDEX idx_memory_edges_valid ON memory_edges(valid_at, invalid_at);
```

**Implementation:**
```python
# backend/app/models/memory/memory_edge.py

from sqlalchemy import Column, Integer, String, DateTime, JSON, Float, ForeignKey, Index
from sqlalchemy.orm import relationship
from datetime import datetime
from backend.app.db.base import Base


class MemoryEdge(Base):
    """Graph edge representing a relationship between two memory nodes.
    
    Supports bi-temporal tracking (valid_at/invalid_at) for contradiction
    detection per Architecture Principle 4.3 (Graphiti-pattern).
    
    Relationship types:
    - 'related_to': general semantic similarity
    - 'caused_by': causal relationship (event B caused event A)
    - 'part_of': hierarchical containment
    - 'contradicts': conflicting information (old edge gets invalid_at)
    - 'supports': corroborating evidence
    - 'followed_by': temporal sequence
    - 'depends_on': dependency relationship
    - 'derived_from': lineage/provenance
    
    Architecture refs:
    - 4.4 (Graph Architecture): temporal valid/invalid timestamps on edges
    - 4.5 (Retrieval Architecture): graph results feed into RRF
    """
    __tablename__ = "memory_edges"
    __table_args__ = (
        Index("idx_memory_edges_source", "source_node_id"),
        Index("idx_memory_edges_target", "target_node_id"),
        Index("idx_memory_edges_rel", "relationship"),
        Index("idx_memory_edges_valid", "valid_at", "invalid_at"),
    )

    id = Column(Integer, primary_key=True, autoincrement=True)
    source_node_id = Column(Integer, ForeignKey("memory_nodes.id"), nullable=False)
    target_node_id = Column(Integer, ForeignKey("memory_nodes.id"), nullable=False)
    relationship = Column(String(100), nullable=False)
    weight = Column(Float, nullable=False, default=1.0)         # 0.0 to 2.0
    confidence = Column(Float, nullable=False, default=1.0)     # 0.0 to 1.0
    metadata = Column(JSON, nullable=True)
    created_at = Column(DateTime, nullable=False, default=datetime.utcnow)
    last_reinforced = Column(DateTime, nullable=True)
    valid_at = Column(DateTime, nullable=True)   # When edge became true
    invalid_at = Column(DateTime, nullable=True)  # When edge stopped being true

    # Relationships
    source_node = relationship("MemoryEdge", foreign_keys=[source_node_id], back_populates="source_edges")
    target_node = relationship("MemoryEdge", foreign_keys=[target_node_id], back_populates="target_edges")

    def __repr__(self) -> str:
        return f"<MemoryEdge(id={self.id}, rel={self.relationship}, w={self.weight})>"

    @property
    def is_active(self) -> bool:
        """Check if edge is currently valid (not invalidated)."""
        return self.invalid_at is None

    @property
    def is_stale(self) -> bool:
        """Check if edge weight has decayed below useful threshold."""
        return (self.weight or 0.0) < 0.2

    def reinforce(self, amount: float = 0.1) -> None:
        """Strengthen edge weight on traversal (reinforcement)."""
        self.weight = min(2.0, (self.weight or 1.0) + amount)
        self.last_reinforced = datetime.utcnow()

    def invalidate(self) -> None:
        """Mark edge as invalid (contradiction detected)."""
        self.invalid_at = datetime.utcnow()
```

### Task 3: Create Pydantic Schemas

**File:** `backend/app/schemas/memory/graph.py`
**Purpose:** Request/response schemas for graph API endpoints. Follow the pattern of `response_model=` on all API decorators (Architecture Principle 1.10).

**Implementation:**
```python
# backend/app/schemas/memory/graph.py

from pydantic import BaseModel, Field
from datetime import datetime
from typing import Optional, List
from enum import Enum


class MemoryTypeEnum(str, Enum):
    episodic = "episodic"
    semantic = "semantic"
    working = "working"


class RelationshipEnum(str, Enum):
    related_to = "related_to"
    caused_by = "caused_by"
    part_of = "part_of"
    contradicts = "contradicts"
    supports = "supports"
    followed_by = "followed_by"
    depends_on = "depends_on"
    derived_from = "derived_from"


class MemoryNodeResponse(BaseModel):
    """Response schema for a memory graph node."""
    id: int
    user_id: int
    memory_type: MemoryTypeEnum
    memory_id: int
    label: Optional[str] = None
    confidence: float = Field(ge=0.0, le=1.0)
    created_at: datetime
    last_accessed: Optional[datetime] = None

    class Config:
        from_attributes = True


class MemoryEdgeResponse(BaseModel):
    """Response schema for a memory graph edge."""
    id: int
    source_node_id: int
    target_node_id: int
    relationship: RelationshipEnum
    weight: float = Field(ge=0.0, le=2.0)
    confidence: float = Field(ge=0.0, le=1.0)
    created_at: datetime
    last_reinforced: Optional[datetime] = None
    valid_at: Optional[datetime] = None
    invalid_at: Optional[datetime] = None

    class Config:
        from_attributes = True


class GraphResponse(BaseModel):
    """Complete graph response with nodes and edges."""
    nodes: List[MemoryNodeResponse]
    edges: List[MemoryEdgeResponse]
    node_count: int = 0
    edge_count: int = 0


class GraphStatsResponse(BaseModel):
    """Graph statistics for a user."""
    total_nodes: int
    total_edges: int
    active_edges: int
    nodes_by_type: dict  # {"episodic": 50, "semantic": 20, "working": 5}
    edges_by_relationship: dict  # {"related_to": 30, "caused_by": 10}
    avg_confidence: float
    avg_edge_weight: float


class CreateEdgeRequest(BaseModel):
    """Request schema for creating a new edge."""
    source_node_id: int
    target_node_id: int
    relationship: RelationshipEnum
    weight: float = Field(ge=0.0, le=2.0, default=1.0)
    confidence: float = Field(ge=0.0, le=1.0, default=1.0)


class ShortestPathResponse(BaseModel):
    """Response schema for shortest path query."""
    path: List[int]  # List of node IDs
    path_length: int
    total_weight: float
```

import pytest
from datetime import datetime
from backend.app.models.memory.memory_node import MemoryNode
from backend.app.models.memory.memory_edge import MemoryEdge


class TestMemoryNode:
    """Tests for MemoryNode model."""

    def test_create_node(self, db_session):
        """Test basic node creation."""
        node = MemoryNode(
            user_id=1, memory_type="episodic", memory_id=42,
            label="Test memory", confidence=0.9

        assert node.id is not None
        assert node.memory_type == "episodic"

    def test_node_unique_constraint(self, db_session):
        """Test that duplicate (user_id, memory_type, memory_id) raises."""
        node1 = MemoryNode(user_id=1, memory_type="episodic", memory_id=42)
        node2 = MemoryNode(user_id=1, memory_type="episodic", memory_id=42)
        db_session.add(node1)
        db_session.commit()
        db_session.add(node2)
        with pytest.raises(Exception):  # IntegrityError
            db_session.commit()

    def test_node_reinforce(self, db_session):
        """Test confidence reinforcement on access."""
        node = MemoryNode(user_id=1, memory_type="semantic", memory_id=1, confidence=0.5)
        db_session.add(node)
        db_session.commit()
        node.reinforce(0.1)
        assert node.confidence == 0.6
        assert node.last_accessed is not None

    def test_node_reinforce_cap(self, db_session):
        """Test confidence capped at 1.0."""
        node = MemoryNode(user_id=1, memory_type="semantic", memory_id=1, confidence=0.95)
        db_session.add(node)
        db_session.commit()
        node.reinforce(0.1)
        assert node.confidence == 1.0

    def test_node_is_stale(self, db_session):
        """Test stale detection at low confidence."""
        node = MemoryNode(user_id=1, memory_type="semantic", memory_id=1, confidence=0.2)
        assert node.is_stale is True
        node2 = MemoryNode(user_id=1, memory_type="semantic", memory_id=2, confidence=0.5)
        assert node2.is_stale is False


class TestMemoryEdge:
    """Tests for MemoryEdge model."""

    def _create_two_nodes(self, db_session):

        n2 = MemoryNode(user_id=1, memory_type="semantic", memory_id=1)
        db_session.add_all([n1, n2])
        db_session.commit()
        return n1, n2

    def test_create_edge(self, db_session):

        n1, n2 = self._create_two_nodes(db_session)
        edge = MemoryEdge(
            source_node_id=n1.id, target_node_id=n2.id,
            relationship="related_to", weight=1.0

        db_session.add(edge)
        db_session.commit()
        assert edge.id is not None
        assert edge.relationship == "related_to"

    def test_edge_is_active(self, db_session):
        """Test active edge detection."""
        n1, n2 = self._create_two_nodes(db_session)
        edge = MemoryEdge(source_node_id=n1.id, target_node_id=n2.id, relationship="supports")
        db_session.add(edge)
        db_session.commit()
        assert edge.is_active is True
        edge.invalidate()
        assert edge.is_active is False
        assert edge.invalid_at is not None

    def test_edge_reinforce(self, db_session):
        """Test edge weight reinforcement."""
        n1, n2 = self._create_two_nodes(db_session)
        edge = MemoryEdge(source_node_id=n1.id, target_node_id=n2.id, relationship="caused_by", weight=0.5)
        db_session.add(edge)
        db_session.commit()
        edge.reinforce(0.3)
        assert edge.weight == 0.8
        assert edge.last_reinforced is not None

    def test_edge_weight_cap(self, db_session):

        n1, n2 = self._create_two_nodes(db_session)
        edge = MemoryEdge(source_node_id=n1.id, target_node_id=n2.id, relationship="caused_by", weight=1.9)

## Cross-Domain Integration Notes

- **v1.03 (Memory Foundation)** — Graph models reference existing episodic/semantic/working memory tables via `(memory_type, memory_id)`. No foreign keys to those tables (polymorphic reference). Services in v1.03 are unaware of graph models.
- **v1.04 (Awareness Foundation)** — Awareness events will eventually become graph nodes (in v1.08 integration). The `memory_type` field can be extended to include `"awareness"` without schema changes.
- **v1.02 (Backend Architecture)** — Uses established Base model, session patterns, migration conventions.

---

## Security Considerations

1. **SQL injection prevention** — All queries use SQLAlchemy ORM parameterized queries. No raw SQL with user input.
2. **Ownership validation** — All graph queries must filter by `user_id`. Never return cross-user graph data.
3. **Data size limits** — Max 10,000 nodes and 50,000 edges per user. Enforced in service layer.
4. **Embedding storage** — Embeddings stored as JSON arrays in PostgreSQL. Consider compression for >1000 nodes.
5. **Migration safety** — Downgrade drops only graph tables. Never touches existing memory tables.

---

## Performance Considerations

1. **Index strategy** — Composite index on `(user_id, memory_type)` for type-filtered queries. Separate index on `(user_id, confidence)` for decay queries.
2. **Query limits** — Default limit of 100 nodes per query. Pagination support via `offset` parameter.
3. **Embedding loading** — Embeddings loaded lazily (not in default queries) to save memory for graph traversal.
4. **FK cascade** — Edges cascade-delete when either node is deleted. Prevents orphan edges.
