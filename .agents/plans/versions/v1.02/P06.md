### Task 4: Schema Validation

**Objective:** Add CHECK constraints and NOT NULL constraints to ensure data integrity.

```python
# Additional validation constraints (added as a separate migration or inline)

# MCP servers: transport must be valid
op.execute("""
    ALTER TABLE mcp_servers 
    ADD CONSTRAINT chk_mcp_transport 
    CHECK (transport IN ('stdio', 'sse'))
""")

# Agent runs: status must be valid
op.execute("""
    ALTER TABLE agent_runs 
    ADD CONSTRAINT chk_run_status 
    CHECK (status IN ('pending', 'running', 'paused', 'completed', 'failed', 'abandoned'))
""")

# Agent runs: iterations must be non-negative
op.execute("""
    ALTER TABLE agent_runs 
    ADD CONSTRAINT chk_run_iterations 
    CHECK (iterations >= 0)
""")

# Token usage: tokens must be non-negative
op.execute("""
    ALTER TABLE token_usage 
    ADD CONSTRAINT chk_token_non_negative 
    CHECK (input_tokens >= 0 AND output_tokens >= 0 AND total_tokens >= 0)
""")

# Tool metrics: duration must be positive
op.execute("""
    ALTER TABLE tool_execution_metrics 
    ADD CONSTRAINT chk_duration_positive 
    CHECK (duration_ms > 0)
""")
```

### Task 5: Performance Indexes

**Objective:** Add indexes for common query patterns used by the agent system and observability.

```sql
-- Composite indexes for common queries

-- Agent runs: find active runs for a user
CREATE INDEX ix_agent_runs_user_status 
    ON agent_runs (user_id, status) 
    WHERE status IN ('running', 'paused');

-- Agent runs: cleanup old runs
CREATE INDEX ix_agent_runs_old_paused 
    ON agent_runs (last_event_at) 
    WHERE status = 'paused';

-- Token usage: aggregate by user and date
CREATE INDEX ix_token_usage_user_date 
    ON token_usage (user_id, created_at);

-- Tool metrics: aggregate by tool and date
CREATE INDEX ix_tool_metrics_tool_date 
    ON tool_execution_metrics (tool_name, created_at);

-- Tool metrics: find slow tools
CREATE INDEX ix_tool_metrics_slow 
    ON tool_execution_metrics (duration_ms DESC) 
    WHERE success = true;

-- MCP tools: find tools by server
CREATE INDEX ix_mcp_tools_server 
    ON mcp_server_tools (server_id, tool_name);
```

## Migration Rollback Validation

Every migration must have a tested rollback:

```bash
# Test rollback for each migration:
alembic downgrade -1
# Verify tables dropped
alembic upgrade +1
# Verify tables recreated
alembic downgrade -1
# Final verification
make test
```

**Rollback test script:**


## Risks

| Risk | Impact | Probability | Mitigation |
|------|--------|-------------|------------|
| Migration breaks existing data | **High** | Low | Rollback scripts for every migration. Test on copy of production data. |
| Performance indexes slow writes | Low | Low | Indexes only on query patterns, not write-heavy columns. |
| Schema validation too strict | Medium | Low | Use ALTER TABLE ADD CONSTRAINT (not CREATE TABLE) so it can be dropped. |
| JSONB columns in SQLite test env | Medium | High | conftest.py already compiles JSONB → JSON for SQLite. |
