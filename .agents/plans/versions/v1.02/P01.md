# P01: API Domain Reorganization — CORTEX

**Document:** Phase 01 of Version 1.02
**Authority:** Stage 6 — Master Versioned Implementation Roadmap
**Date:** 2026-06-27

---

## Objective

Move all API endpoints from flat `api/v1/` files into domain-organized subdirectories with domain routers, establishing clear ownership and enabling domain-specific API evolution.

---

## Purpose

The current API has 22 flat endpoint files in `backend/app/api/v1/`. This creates unclear ownership, makes it difficult to reason about domain boundaries, and prevents domain-specific API versioning. Reorganizing into domain routers establishes clear ownership and enables the service boundary enforcement that P02 depends on.

**Constitution Alignment:** Section 3.4 (Separation of Concerns) — each domain owns its API surface. Section 4.6 (Agent Architecture) — agent endpoints must be in their own domain for the agent system hardening in P03.

### Task 3: Create Domain Router Files

Each domain gets a `router.py` that aggregates its endpoints. Here are the exact router implementations:

**Memory Domain Router** (`api/v1/memory/router.py`):

```python
from fastapi import APIRouter
from .knowledge import router as knowledge_router
from .long_term_memory import router as ltm_router

router = APIRouter()
router.include_router(knowledge_router, prefix="/knowledge", tags=["memory"])

router.include_router(search_router, prefix="/search", tags=["memory"])
```

## Migration Rollback Validation

Every move must be reversible. Validation steps:

```bash
# After each git mv, verify the move is clean:
git status  # Should show renames, not delete+create

# If rollback is needed at any point:
git checkout -- backend/app/api/v1/
# Then undo the master router and main.py changes

# Full rollback command:
git log --oneline -1  # Note the pre-P01 commit hash
git reset --hard <pre-P01-hash>
```

**Rollback test:** After completing P01, verify rollback works by:
1. Stashing all changes: `git stash`
2. Verifying the old structure works: `make test`
3. Restoring: `git stash pop`
4. Verifying the new structure works: `make test`

## Testing Strategy

### Test Cases (Specific)

1. **Route completeness test:** Import the master router, walk all routes, assert count matches expected (22+ endpoints)
2. **No duplicate routes test:** Walk all routes, assert no path+method duplicates
3. **Swagger completeness test:** Fetch `/openapi.json`, assert all expected paths exist
4. **Domain isolation test:** For each domain router, import it independently, assert it loads without errors
5. **Import resolution test:** For each moved module, import it from new path, assert it resolves
6. **Backward compatibility test:** Assert old import paths raise `ImportError` (not silent failures)

```python
# tests/test_p01_api_domain_reorg.py

import pytest
from fastapi.testclient import TestClient
from app.main import app

client = TestClient(app)

def test_master_router_loads():
    """Master router should load all domain routers."""
    routes = [r for r in app.routes if hasattr(r, "path")]
    assert len(routes) >= 22, f"Expected >= 22 routes, got {len(routes)}"

def test_no_duplicate_routes():
    """No path+method combination should appear twice."""
    seen = set()
    for route in app.routes:
        if hasattr(route, "methods") and hasattr(route, "path"):
            for method in route.methods:
                key = (route.path, method)
                assert key not in seen, f"Duplicate route: {key}"
                seen.add(key)

def test_all_endpoints_accessible():
    """Every known endpoint should respond (200 or 401/403)."""
    endpoints = [
        "/api/v1/memory/knowledge/",
        "/api/v1/memory/search/",
        "/api/v1/cognition/agents/",
        "/api/v1/system/health/",
        # ... all endpoints
    ]
    for endpoint in endpoints:
        response = client.get(endpoint)
        assert response.status_code in (200, 401, 403, 422), \
            f"Endpoint {endpoint} returned {response.status_code}"

def test_domain_routers_independent():
    """Each domain router should load without cross-domain dependencies."""
    from app.api.v1.memory.router import router as memory_router
    from app.api.v1.awareness.router import router as awareness_router
    from app.api.v1.cognition.router import router as cognition_router
    from app.api.v1.system.router import router as system_router
    assert memory_router is not None
    assert awareness_router is not None
    assert cognition_router is not None
    assert system_router is not None
```
