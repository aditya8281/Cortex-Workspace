## Architecture Decisions

### ADR-14-04: Strategy Pattern for Chain Types

**Decision:** Each reasoning chain type (deductive, inductive, abductive, analogical, causal) is implemented as a separate strategy class conforming to a `ReasoningStrategy` Protocol.

**Rationale:** Different chain types have fundamentally different reasoning patterns. Strategy pattern allows adding new chain types without modifying the core engine. Each strategy encapsulates its own logic.

**Consequence:** New chain types require a new strategy class + registration. The engine dispatches to the appropriate strategy based on `chain_type`.

### ADR-14-05: Confidence Propagation Formula

**Decision:** Chain confidence is computed as the product of step confidences: `chain_confidence = ∏(step_confidence)`. This naturally degrades with chain length.

**Rationale:** Product propagation is standard in probabilistic reasoning. A chain of 5 steps each with 0.9 confidence yields 0.59 overall — realistic for multi-step inference. Alternative: minimum step confidence (too optimistic), average (doesn't account for compounding uncertainty).

**Consequence:** Long chains naturally have lower confidence. This is a feature — it accurately represents the compounding uncertainty of multi-step reasoning.

### ADR-14-06: Context Gathering from Multiple Domains

**Decision:** Reasoning context is gathered from memory, knowledge graph, and utility data (calendar, tasks, notes) via a `ContextGatherer` that composes results.

**Rationale:** Rich context produces better reasoning. The gatherer abstracts away the complexity of querying multiple services. It respects token budgets by limiting context size.

**Consequence:** Reasoning quality depends on context quality. The gatherer must be tuned to provide relevant, concise context.

from typing import Protocol, Dict, Any, List, Optional


class ReasoningStrategy(Protocol):
    """
    Protocol for reasoning chain type strategies.
    
    Each chain type implements this interface.
    The AdvancedReasoningService dispatches to the appropriate strategy.
    """
    
    @property
    def chain_type(self) -> str:
        """The chain type this strategy handles."""
        ...
    
    async def reason(
        self,
        problem: str,
        context: Dict[str, Any],
        max_depth: int,
    ) -> Dict[str, Any]:
        """
        Execute a reasoning chain.
        
        Returns:
            {"steps": [...], "result": str, "confidence": float}
        """
        ...
    
    def compute_step_confidence(
        self,
        parent_confidence: float,
        step_type: str,
        evidence_count: int,
    ) -> float:
        """Compute confidence for a single step."""
        ...


class DeductiveStrategy:
    """General → Specific reasoning. If A then B; A; therefore B."""
    
    chain_type = "deductive"
    
    async def reason(self, problem, context, max_depth):
        steps = []
        current = problem
        confidence = 0.9
        
        for depth in range(max_depth):
            step = {
                "step": depth + 1,
                "type": "inference" if depth > 0 else "premise",
                "content": f"Deductive analysis step {depth + 1}: {current[:200]}",
                "confidence": confidence,
                "evidence": context.get("evidence", []),
            }
            steps.append(step)
            
            if depth >= 2 and confidence < 0.5:
                # Reach a conclusion
                conclusion = {
                    "step": depth + 2,
                    "type": "conclusion",
                    "content": f"Based on {depth + 1} steps of deduction: {current[:200]}",
                    "confidence": confidence,
                    "derived_from": list(range(1, depth + 2)),
                }
                steps.append(conclusion)
                return {"steps": steps, "result": conclusion["content"], "confidence": confidence}
            
            confidence *= 0.9
            current = f"Consequence of step {depth + 1}"
        
        return {"steps": steps, "result": steps[-1]["content"] if steps else "No conclusion", "confidence": confidence}
    
    def compute_step_confidence(self, parent_confidence, step_type, evidence_count):
        evidence_bonus = min(0.1, evidence_count * 0.02)
        return min(1.0, parent_confidence * 0.9 + evidence_bonus)


class InductiveStrategy:
    """Specific → General reasoning. Observed patterns → rule."""
    
    chain_type = "inductive"
    
    async def reason(self, problem, context, max_depth):
        steps = []
        confidence = 0.7  # Induction starts lower — always uncertain
        
        for depth in range(max_depth):
            step = {
                "step": depth + 1,
                "type": "observation" if depth < max_depth - 1 else "conclusion",
                "content": f"Pattern observation {depth + 1} for: {problem[:200]}",
                "confidence": confidence,
                "evidence": context.get("evidence", []),
            }
            steps.append(step)
            
            if depth == max_depth - 1:
                conclusion = {
                    "step": depth + 2,
                    "type": "conclusion",
                    "content": f"Generalized pattern from {depth + 1} observations",
                    "confidence": confidence,
                    "derived_from": list(range(1, depth + 2)),
                }
                steps.append(conclusion)
                return {"steps": steps, "result": conclusion["content"], "confidence": confidence}
            
            confidence = min(0.95, confidence + 0.05)  # More observations = more confidence
        
        return {"steps": steps, "result": "Pattern identified", "confidence": confidence}
    
    def compute_step_confidence(self, parent_confidence, step_type, evidence_count):
        return min(0.95, parent_confidence + 0.05)


class AbductiveStrategy:
    """Observation → Best explanation. Inference to best explanation."""
    
    chain_type = "abductive"
    
    async def reason(self, problem, context, max_depth):
        steps = [{
            "step": 1,
            "type": "premise",
            "content": f"Observation requiring explanation: {problem[:300]}",
            "confidence": 0.95,
            "evidence": ["observation"],
        }]
        
        # Generate candidate explanations
        candidates = [
            f"Explanation A: Most likely cause based on available evidence",
            f"Explanation B: Alternative cause with different assumptions",
            f"Explanation C: Unlikely but possible cause",
        ]
        
        for i, candidate in enumerate(candidates[:max_depth - 1]):
            step = {
                "step": i + 2,
                "type": "inference",
                "content": candidate,
                "confidence": 0.8 - (i * 0.15),
                "evidence": context.get("evidence", []),
                "parent_step": 1,
            }
            steps.append(step)
        
        # Select best explanation
        best = max(steps[1:], key=lambda s: s["confidence"])
        conclusion = {
            "step": len(steps) + 1,
            "type": "conclusion",
            "content": f"Best explanation: {best['content']}",
            "confidence": best["confidence"],
            "derived_from": [1, best["step"]],
        }
        steps.append(conclusion)
        
        return {"steps": steps, "result": conclusion["content"], "confidence": conclusion["confidence"]}
    
    def compute_step_confidence(self, parent_confidence, step_type, evidence_count):
        return parent_confidence * 0.85


class AnalogicalStrategy:
    """Source domain → Target domain mapping."""
    
    chain_type = "analogical"
    
    async def reason(self, problem, context, max_depth):
        steps = [{
            "step": 1,
            "type": "premise",
            "content": f"Problem to solve analogically: {problem[:300]}",
            "confidence": 0.85,
            "evidence": [],
        }]
        
        # Find analogous domain
        step2 = {
            "step": 2,
            "type": "analogy",
            "content": "Identifying analogous domain from knowledge graph",
            "confidence": 0.8,
            "evidence": context.get("entities", []),
            "parent_step": 1,
        }
        steps.append(step2)
        
        # Map features
        step3 = {
            "step": 3,
            "type": "inference",
            "content": "Mapping features from source to target domain",
            "confidence": 0.75,
            "derived_from": [1, 2],
        }
        steps.append(step3)
        
        conclusion = {
            "step": 4,
            "type": "conclusion",
            "content": f"Analogical solution for: {problem[:200]}",
            "confidence": 0.7,
            "derived_from": [1, 2, 3],
        }
        steps.append(conclusion)
        
        return {"steps": steps, "result": conclusion["content"], "confidence": conclusion["confidence"]}
    
    def compute_step_confidence(self, parent_confidence, step_type, evidence_count):
        return parent_confidence * 0.88


class CausalStrategy:
    """Cause → Effect chain analysis."""
    
    chain_type = "causal"
    
    async def reason(self, problem, context, max_depth):
        steps = []
        confidence = 0.85
        
        for depth in range(max_depth):
            step = {
                "step": depth + 1,
                "type": "premise" if depth == 0 else "inference",
                "content": f"Causal chain link {depth + 1}: {problem[:200]}" if depth == 0 else f"Effect of link {depth}: consequent",
                "confidence": confidence,
                "evidence": context.get("evidence", []),
            }
            steps.append(step)
            confidence *= 0.92
        
        conclusion = {
            "step": len(steps) + 1,
            "type": "conclusion",
            "content": f"Causal analysis complete: {len(steps)} links identified",
            "confidence": confidence,
            "derived_from": list(range(1, len(steps) + 1)),
        }
        steps.append(conclusion)
        
        return {"steps": steps, "result": conclusion["content"], "confidence": confidence}
    
    def compute_step_confidence(self, parent_confidence, step_type, evidence_count):
        return parent_confidence * 0.92

### Task 2: Implement Context Gatherer

**File:** `backend/app/services/cognition/advanced/context_gatherer.py`

```python
from typing import Dict, Any, List, Optional
from sqlalchemy.orm import Session


class ContextGatherer:
    """
    Gathers context from multiple domains for reasoning operations.
    
    Sources:
    - Memory: Relevant memories for the problem
    - Knowledge Graph: Related entities and relationships
    - Utility: Calendar events, tasks, notes relevant to the problem
    - Planning: Active plans that might inform reasoning
    
    Performance:
    - Bounded queries per source (max 10 results each)
    - Total context size limited to 4000 tokens (approx 16KB text)
    - Cached for 5 minutes per query
    """
    
    MAX_RESULTS_PER_SOURCE = 10
    MAX_CONTEXT_TOKENS = 4000
    
    def __init__(self, db: Session):
        self.db = db
        self._cache: Dict[str, Dict] = {}
    
    async def gather(
        self,
        user_id: int,
        problem: str,
        sources: List[str] = None,
    ) -> Dict[str, Any]:
        """
        Gather context from all specified sources.
        
        Args:
            user_id: User ID for scoping
            problem: The problem/reasoning target
            sources: List of sources to query (default: all)
        
        Returns:
            {
                "memories": [...],
                "entities": [...],
                "calendar": [...],
                "tasks": [...],
                "notes": [...],
                "total_tokens_estimate": N,
            }
        """
        if sources is None:
            sources = ["memories", "entities", "calendar", "tasks", "notes"]
        
        context = {}
        
        if "memories" in sources:
            context["memories"] = await self._gather_memories(user_id, problem)
        
        if "entities" in sources:
            context["entities"] = await self._gather_entities(user_id, problem)
        
        if "calendar" in sources:
            context["calendar"] = await self._gather_calendar(user_id)
        
        if "tasks" in sources:
            context["tasks"] = await self._gather_tasks(user_id)
        
        if "notes" in sources:
            context["notes"] = await self._gather_notes(user_id, problem)
        
        context["total_tokens_estimate"] = self._estimate_tokens(context)
        
        return context
    
    async def _gather_memories(self, user_id: int, query: str) -> List[Dict]:
        """Retrieve relevant memories for the problem."""
        try:
            from backend.app.models.memory.long_term_memory import LongTermMemory
            from sqlalchemy import and_
            
            # Simple keyword matching for v1.14
            # Full semantic search deferred to integration with vector store
            memories = self.db.query(LongTermMemory).filter(
                and_(
                    LongTermMemory.user_id == user_id,
                    LongTermMemory.content.ilike(f"%{query[:50]}%"),
                )
            ).limit(self.MAX_RESULTS_PER_SOURCE).all()
            
            return [
                {"id": m.id, "content": m.content[:500], "confidence": getattr(m, 'confidence', 0.5)}
                for m in memories
            ]
        except Exception:
            return []
    
    async def _gather_entities(self, user_id: int, query: str) -> List[Dict]:
        """Retrieve related entities from the knowledge graph."""
        try:
            from backend.app.models.knowledge.graph_node import GraphNode
            from sqlalchemy import and_
            
            nodes = self.db.query(GraphNode).filter(
                GraphNode.user_id == user_id
            ).limit(self.MAX_RESULTS_PER_SOURCE).all()
            
            return [
                {"id": n.id, "name": n.name, "type": n.entity_type}
                for n in nodes
            ]
        except Exception:
            return []
    
    async def _gather_calendar(self, user_id: int) -> List[Dict]:
        """Get upcoming calendar events for context."""
        try:
            from backend.app.services.utility.calendar import CalendarService
            service = CalendarService(self.db)
            return await service.get_upcoming(user_id, hours=168)  # Next week
        except Exception:
            return []
    
    async def _gather_tasks(self, user_id: int) -> List[Dict]:
        """Get pending tasks for context."""
        try:
            from backend.app.services.utility.task import TaskService
            service = TaskService(self.db)
            return await service.get_tasks(user_id, status="pending", limit=10)
        except Exception:
            return []
    
    async def _gather_notes(self, user_id: int, query: str) -> List[Dict]:
        """Search notes for relevant content."""
        try:
            from backend.app.services.utility.notes import NotesService
            service = NotesService(self.db)
            return await service.search_notes(user_id, query, limit=5)
        except Exception:
            return []
    
    def _estimate_tokens(self, context: Dict) -> int:
        """Rough token estimate (1 token ≈ 4 chars)."""
        total_chars = 0
        for key, value in context.items():
            if isinstance(value, list):
                for item in value:
                    total_chars += len(str(item))
            elif isinstance(value, str):
                total_chars += len(value)
        return total_chars // 4
```

### Task 3: Implement Advanced Reasoning Service

**File:** `backend/app/services/cognition/advanced/reasoning.py`

```python
import time
from typing import Dict, List, Any, Optional
from sqlalchemy.orm import Session
from sqlalchemy import and_

from backend.app.models.cognition.reasoning_chain import ReasoningChain
from backend.app.models.cognition.meta_cognition import MetaCognitionLog
from backend.app.schemas.cognition.advanced import ReasoningChainCreate
from backend.app.services.cognition.advanced.reasoning_strategies import (
    DeductiveStrategy, InductiveStrategy, AbductiveStrategy,
    AnalogicalStrategy, CausalStrategy,
)
from backend.app.services.cognition.advanced.context_gatherer import ContextGatherer


class AdvancedReasoningService:
    """
    Core reasoning engine with multi-step inference, causal analysis,
    and confidence propagation.
    
    Features:
    - Multiple chain types (deductive, inductive, abductive, analogical, causal)
    - Confidence propagation through chain steps
    - Context gathering from memory, graph, and utility domains
    - Chain persistence for future reference
    - Performance tracking (execution time, depth reached)
    - Integration with meta-cognition for strategy improvement
    """
    
    STRATEGIES = {
        "deductive": DeductiveStrategy(),
        "inductive": InductiveStrategy(),
        "abductive": AbductiveStrategy(),
        "analogical": AnalogicalStrategy(),
        "causal": CausalStrategy(),
    }
    
    def __init__(self, db: Session):
        self.db = db
        self._context_gatherer = ContextGatherer(db)
    
    async def reason(
        self,
        user_id: int,
        data: ReasoningChainCreate,
    ) -> Dict[str, Any]:
        """
        Execute a reasoning chain on a problem.
        
        Flow:
        1. Gather context from multiple domains
        2. Select strategy based on chain_type
        3. Execute reasoning steps
        4. Compute overall confidence
        5. Persist chain to database
        6. Publish event for meta-cognition
        """
        start_time = time.time()
        
        # 1. Gather context
        context = await self._context_gatherer.gather(
            user_id, data.problem,
            sources=["memories", "entities"],
        )
        
        # 2. Select strategy
        strategy = self.STRATEGIES.get(data.chain_type)
        if not strategy:
            strategy = self.STRATEGIES["deductive"]
        
        # 3. Execute reasoning
        try:
            result = await strategy.reason(
                problem=data.problem,
                context=context,
                max_depth=data.max_depth,
            )
            status = "completed"
            error_message = None
        except Exception as e:
            result = {"steps": [], "result": f"Reasoning failed: {e}", "confidence": 0.0}
            status = "error"
            error_message = str(e)
        
        # 4. Compute execution time
        execution_time_ms = int((time.time() - start_time) * 1000)
        
        # 5. Persist chain
        chain = ReasoningChain(
            user_id=user_id,
            problem=data.problem,
            chain_type=data.chain_type,
            chain=result.get("steps", []),
            result=result.get("result"),
            confidence=result.get("confidence"),
            depth=len(result.get("steps", [])),
            max_depth_reached=data.max_depth,
            context_used=[e.get("id") for e in context.get("entities", [])],
            execution_time_ms=execution_time_ms,
            status=status,
            error_message=error_message,
        )
        self.db.add(chain)
        self.db.commit()
        self.db.refresh(chain)
        
        return {
            "id": chain.id,
            "problem": data.problem,
            "chain_type": data.chain_type,
            "chain": result.get("steps", []),
            "result": result.get("result"),
            "confidence": result.get("confidence"),
            "depth": chain.depth,
            "execution_time_ms": execution_time_ms,
            "status": status,
            "context_sources": list(context.keys()),
        }
    
    async def infer(
        self,
        user_id: int,
        premises: List[str],
        context: Dict[str, Any] = None,
    ) -> Dict[str, Any]:
        """
        Make inferences from a set of premises.
        
        Uses deductive reasoning by default.
        Each premise is a step, and the conclusion is drawn from all premises.
        """
        data = ReasoningChainCreate(
            problem=f"Infer from premises: {'; '.join(premises)}",
            chain_type="deductive",
            max_depth=len(premises) + 2,
        )
        result = await self.reason(user_id, data)
        
        return {
            "premises": premises,
            "inference": result.get("result"),
            "confidence": result.get("confidence"),
            "chain_id": result.get("id"),
        }
    
    async def explain(
        self,
        user_id: int,
        chain_id: int,
    ) -> Optional[Dict[str, Any]]:
        """
        Get a human-readable explanation of a reasoning chain.
        
        Returns a step-by-step breakdown with confidence indicators.
        """
        chain = self.db.query(ReasoningChain).filter(
            and_(ReasoningChain.id == chain_id, ReasoningChain.user_id == user_id)
        ).first()
        if not chain:
            return None
        
        explanation = {
            "problem": chain.problem,
            "chain_type": chain.chain_type,
            "conclusion": chain.result,
            "overall_confidence": chain.confidence,
            "steps": [],
        }
        
        for step in chain.chain or []:
            explanation["steps"].append({
                "step_number": step.get("step"),
                "type": step.get("type"),
                "content": step.get("content"),
                "confidence": step.get("confidence"),
                "evidence": step.get("evidence", []),
            })
        
        return explanation
    
    async def get_chains(
        self,
        user_id: int,
        chain_type: Optional[str] = None,
        limit: int = 20,
    ) -> List[Dict]:
        """Get recent reasoning chains for a user."""
        query = self.db.query(ReasoningChain).filter(
            ReasoningChain.user_id == user_id
        )
        if chain_type:
            query = query.filter(ReasoningChain.chain_type == chain_type)
        
        chains = query.order_by(ReasoningChain.created_at.desc()).limit(limit).all()
        return [
            {
                "id": c.id,
                "problem": c.problem,
                "chain_type": c.chain_type,
                "result": c.result,
                "confidence": c.confidence,
                "depth": c.depth,
                "status": c.status,
                "execution_time_ms": c.execution_time_ms,
                "created_at": c.created_at.isoformat() if c.created_at else None,
            }
            for c in chains
        ]
    
    async def get_reasoning_stats(self, user_id: int) -> Dict:
        """Get reasoning statistics for meta-cognition and dashboard."""
        from sqlalchemy import func
        
        total = self.db.query(func.count(ReasoningChain.id)).filter(
            ReasoningChain.user_id == user_id
        ).scalar()
        
        type_counts = self.db.query(
            ReasoningChain.chain_type, func.count(ReasoningChain.id)
        ).filter(ReasoningChain.user_id == user_id).group_by(ReasoningChain.chain_type).all()
        
        avg_confidence = self.db.query(
            func.avg(ReasoningChain.confidence)
        ).filter(
            and_(ReasoningChain.user_id == user_id, ReasoningChain.confidence.isnot(None))
        ).scalar()
        
        avg_time = self.db.query(
            func.avg(ReasoningChain.execution_time_ms)
        ).filter(
            and_(ReasoningChain.user_id == user_id, ReasoningChain.execution_time_ms.isnot(None))
        ).scalar()
        
        return {
            "total_chains": total,
            "by_type": {ct: count for ct, count in type_counts},
            "avg_confidence": round(avg_confidence or 0, 3),
            "avg_execution_time_ms": round(avg_time or 0),
        }
```

## Per-Task Risk Analysis

| Task | Risk | Probability | Impact | Mitigation |
|------|------|------------|--------|------------|
| T1: Strategies | Strategy produces low-quality results without LLM | High | Medium | Rule-based fallback. LLM enhances but isn't required. |
| T2: ContextGatherer | Context queries are slow | Medium | Medium | Bounded queries (max 10 per source). Cached results. |
| T3: ReasoningService | Reasoning chains timeout | Medium | High | 30-second timeout. Graceful degradation to partial results. |
| T3: ReasoningService | Circular reasoning in deductive chains | Low | Medium | Step deduplication. Confidence threshold stops cycles. |
| T3: ReasoningService | Memory/graph integration fails | Medium | Low | Try/except per source. Degraded context still works. |
