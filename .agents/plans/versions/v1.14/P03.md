## Architecture Decisions

### ADR-14-07: Creative Process as Diverge-then-Converge

**Decision:** Creative thinking follows a two-phase process: (1) Divergent phase generates many diverse ideas, (2) Convergent phase evaluates and ranks them by novelty and feasibility.

**Rationale:** This mirrors established creativity research (Guilford's divergent/convergent thinking). Separating the phases prevents premature filtering of ideas.

**Consequence:** The `count` parameter controls how many ideas survive the divergent phase. The convergent phase always produces the same number of ranked results.

### ADR-14-08: Meta-Cognition as Feedback Loop

**Decision:** Meta-cognition operates as a continuous feedback loop: Act → Reflect → Adjust → Act (improved). Each reflection is logged, and patterns are analyzed to suggest strategy adjustments.

**Rationale:** Self-improvement requires data. Logging reflections enables quantitative analysis of which strategies work best. Over time, the system learns to prefer more effective strategies.

**Consequence:** The feedback loop requires at least 5-10 reflection entries before meaningful patterns emerge. Early usage provides limited meta-cognitive value.

### ADR-14-09: Consciousness as Awareness Metrics

**Decision:** "Consciousness simulation" is implemented as practical awareness metrics (focus, energy, attention breadth) rather than philosophical consciousness. The system tracks what it's attending to and how alert it is.

**Rationale:** Practical awareness metrics have immediate utility for adaptive behavior. Philosophical consciousness is speculative and doesn't provide actionable intelligence.

**Consequence:** The "consciousness" terminology may confuse users. Rebrand as "Awareness State" in the UI. Keep internal naming for API consistency.

```python
import random
from typing import Dict, List, Any, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from sqlalchemy import and_

from backend.app.models.cognition.creative_idea import CreativeIdea
from backend.app.schemas.cognition.advanced import CreativeIdeaCreate


class CreativeThinkingService:
    """
    Generates creative ideas through divergent and convergent thinking.
    
    Process:
    1. DIVERGE: Generate multiple diverse ideas from the prompt
    2. CONSTRAIN: Apply constraints to filter impractical ideas
    3. CONVERGE: Score and rank by novelty + feasibility
    4. SELECT: Return top N ideas
    
    Features:
    - Domain-aware generation (general, technical, artistic, business)
    - Constraint-based filtering
    - Inspiration sourcing from memory and knowledge graph
    - Idea saving and rating
    - Brainstorm mode with topic exploration
    """
    
    # Domain-specific creativity templates
    DOMAIN_TEMPLATES = {
        "general": [
            "Combine existing concepts in a new way",
            "Reverse the typical approach",
            "Apply a principle from another domain",
            "Simplify to the essential elements",
            "Add an unexpected constraint",
        ],
        "technical": [
            "Apply a design pattern differently",
            "Use a constraint as a feature",
            "Merge two existing tools into one",
            "Automate the manual step",
            "Build on an open-source foundation",
        ],
        "artistic": [
            "Blend two contrasting styles",
            "Use negative space creatively",
            "Tell the story from a different perspective",
            "Apply a medium in an unexpected way",
            "Create a series with progressive transformation",
        ],
        "business": [
            "Find a new revenue model for existing value",
            "Partner with an unexpected complementary service",
            "Turn a cost center into a profit center",
            "Create a marketplace for the byproduct",
            "Apply a subscription model to a one-time service",
        ],
    }
    
    def __init__(self, db: Session):
        self.db = db
    
    async def generate_ideas(
        self,
        user_id: int,
        data: CreativeIdeaCreate,
    ) -> List[Dict]:
        """
        Generate creative ideas for a prompt.
        
        Phase 1 (Diverge): Generate count * 2 candidate ideas
        Phase 2 (Converge): Score and select top count ideas
        """
        # Phase 1: Diverge
        candidates = await self._diverge(
            user_id, data.prompt, data.domain,
            count=data.count * 2,
            context_ids=data.context_ids,
        )
        
        # Phase 2: Converge
        ranked = await self._converge(candidates, data.constraints)
        
        # Select top N
        selected = ranked[:data.count]
        
        # Persist
        saved_ideas = []
        for idea_data in selected:
            idea = CreativeIdea(
                user_id=user_id,
                prompt=data.prompt,
                idea=idea_data["idea"],
                novelty_score=idea_data["novelty_score"],
                feasibility_score=idea_data["feasibility_score"],
                domain=data.domain,
                inspiration_sources=idea_data.get("inspiration_sources", []),
                constraints_applied=data.constraints,
            )
            self.db.add(idea)
            self.db.flush()  # Get ID without committing
            saved_ideas.append({
                "id": idea.id,
                "idea": idea.idea,
                "novelty_score": idea.novelty_score,
                "feasibility_score": idea.feasibility_score,
                "domain": idea.domain,
                "composite_score": (
                    idea.novelty_score * 0.5 + idea.feasibility_score * 0.5
                ) if idea.novelty_score and idea.feasibility_score else 0,
            })
        
        self.db.commit()
        
        # Sort by composite score
        saved_ideas.sort(key=lambda x: x.get("composite_score", 0), reverse=True)
        
        return saved_ideas
    
    async def brainstorm(
        self,
        user_id: int,
        topic: str,
        constraints: List[str] = None,
        exploration_depth: int = 3,
    ) -> Dict:
        """
        Brainstorm mode: explore a topic from multiple angles.
        
        Generates ideas from different perspectives:
        - Direct approach
        - Opposite approach
        - Adjacent domain approach
        - Random combination
        """
        perspectives = [
            ("direct", "Direct approach"),
            ("opposite", "Opposite approach"),
            ("adjacent", "Adjacent domain"),
            ("combined", "Random combination"),
        ]
        
        all_ideas = []
        for perspective_key, perspective_name in perspectives[:exploration_depth]:
            data = CreativeIdeaCreate(
                prompt=f"{topic} (perspective: {perspective_name})",
                domain="general",
                count=2,
                constraints=constraints or [],
            )
            ideas = await self.generate_ideas(user_id, data)
            for idea in ideas:
                idea["perspective"] = perspective_name
            all_ideas.extend(ideas)
        
        return {
            "topic": topic,
            "constraints": constraints or [],
            "perspectives_explored": exploration_depth,
            "ideas": all_ideas,
            "total_generated": len(all_ideas),
        }
    
    async def rate_idea(
        self, idea_id: int, user_id: int, rating: float
    ) -> Optional[Dict]:
        """Rate a creative idea (0.0-1.0)."""
        idea = self.db.query(CreativeIdea).filter(
            and_(CreativeIdea.id == idea_id, CreativeIdea.user_id == user_id)
        ).first()
        if not idea:
            return None
        
        idea.rating = max(0.0, min(1.0, rating))
        self.db.commit()
        self.db.refresh(idea)
        
        return {
            "id": idea.id,
            "rating": idea.rating,
            "idea": idea.idea,
        }
    
    async def save_idea(self, idea_id: int, user_id: int) -> Optional[bool]:
        """Toggle save status on an idea."""
        idea = self.db.query(CreativeIdea).filter(
            and_(CreativeIdea.id == idea_id, CreativeIdea.user_id == user_id)
        ).first()
        if not idea:
            return None
        idea.is_saved = not idea.is_saved
        self.db.commit()
        return idea.is_saved
    
    async def get_saved_ideas(self, user_id: int) -> List[Dict]:
        """Get all saved creative ideas."""
        ideas = self.db.query(CreativeIdea).filter(
            and_(CreativeIdea.user_id == user_id, CreativeIdea.is_saved == True)
        ).order_by(CreativeIdea.created_at.desc()).all()
        return [self._idea_to_dict(i) for i in ideas]
    
    async def get_idea_stats(self, user_id: int) -> Dict:
        """Get creative statistics for dashboard."""
        from sqlalchemy import func
        
        total = self.db.query(func.count(CreativeIdea.id)).filter(
            CreativeIdea.user_id == user_id
        ).scalar()
        
        saved = self.db.query(func.count(CreativeIdea.id)).filter(
            and_(CreativeIdea.user_id == user_id, CreativeIdea.is_saved == True)
        ).scalar()
        
        avg_novelty = self.db.query(func.avg(CreativeIdea.novelty_score)).filter(
            and_(CreativeIdea.user_id == user_id, CreativeIdea.novelty_score.isnot(None))
        ).scalar()
        
        avg_feasibility = self.db.query(func.avg(CreativeIdea.feasibility_score)).filter(
            and_(CreativeIdea.user_id == user_id, CreativeIdea.feasibility_score.isnot(None))
        ).scalar()
        
        domain_counts = self.db.query(
            CreativeIdea.domain, func.count(CreativeIdea.id)
        ).filter(CreativeIdea.user_id == user_id).group_by(CreativeIdea.domain).all()
        
        return {
            "total_ideas": total,
            "saved_ideas": saved,
            "avg_novelty": round(avg_novelty or 0, 3),
            "avg_feasibility": round(avg_feasibility or 0, 3),
            "by_domain": {d: c for d, c in domain_counts},
        }
    
    async def _diverge(
        self, user_id: int, prompt: str, domain: str,
        count: int, context_ids: List[int] = None,
    ) -> List[Dict]:
        """
        Phase 1: Generate diverse candidate ideas.
        
        Uses templates + randomization for diversity.
        In production, this would use LLM generation.
        """
        templates = self.DOMAIN_TEMPLATES.get(domain, self.DOMAIN_TEMPLATES["general"])
        candidates = []
        
        for i in range(count):
            template = templates[i % len(templates)]
            idea_text = f"{template}: {prompt[:200]}"
            
            # Score with some randomness for diversity
            novelty = random.uniform(0.4, 0.95)
            feasibility = random.uniform(0.3, 0.95)
            
            candidates.append({
                "idea": idea_text,
                "novelty_score": round(novelty, 3),
                "feasibility_score": round(feasibility, 3),
                "domain": domain,
                "inspiration_sources": [
                    {"type": "template", "id": i}
                ] + ([{"type": "context", "id": cid} for cid in (context_ids or [])]),
            })
        
        return candidates
    
    async def _converge(
        self, candidates: List[Dict], constraints: List[str]
    ) -> List[Dict]:
        """
        Phase 2: Evaluate and rank candidates.
        
        Scoring formula:
        composite = (novelty * 0.5) + (feasibility * 0.5)
        Constraint penalty: -0.1 per unmet constraint (simplified)
        """
        for candidate in candidates:
            composite = (
                candidate["novelty_score"] * 0.5 +
                candidate["feasibility_score"] * 0.5
            )
            # Simple constraint penalty (in reality, evaluate each constraint)
            constraint_penalty = len(constraints) * 0.02
            candidate["composite_score"] = max(0, composite - constraint_penalty)
        
        # Sort by composite score
        candidates.sort(key=lambda x: x.get("composite_score", 0), reverse=True)
        
        return candidates
    
    def _idea_to_dict(self, idea: CreativeIdea) -> Dict:
        return {
            "id": idea.id,
            "user_id": idea.user_id,
            "prompt": idea.prompt,
            "idea": idea.idea,
            "novelty_score": idea.novelty_score,
            "feasibility_score": idea.feasibility_score,
            "domain": idea.domain,
            "inspiration_sources": idea.inspiration_sources or [],
            "constraints_applied": idea.constraints_applied or [],
            "rating": idea.rating,
            "is_saved": idea.is_saved,
            "tags": idea.tags or [],
            "created_at": idea.created_at.isoformat() if idea.created_at else None,
        }

from typing import Dict, List, Any, Optional
from datetime import datetime, timedelta
from sqlalchemy.orm import Session
from sqlalchemy import and_, func

from backend.app.models.cognition.meta_cognition import MetaCognitionLog
from backend.app.schemas.cognition.advanced import MetaCognitionReflect


class MetaCognitionService:
    """
    Self-reflective thinking about thinking processes.
    
    Features:
    - Record reflections on cognitive processes
    - Analyze strategy effectiveness over time
    - Detect patterns in thinking approaches
    - Suggest strategy adjustments
    - Track improvement trends
    - Integration with reasoning and creative services
    """
    
    MAX_LOGS_PER_USER = 1000  # Prevent unbounded growth
    
    def __init__(self, db: Session):
        self.db = db
    
    async def reflect(
        self, user_id: int, data: MetaCognitionReflect
    ) -> Dict:
        """
        Record a meta-cognitive reflection.
        
        This is the core operation: thinking about thinking.
        Each reflection captures what was being processed, what strategy
        was used, how effective it was, and what should change.
        """
        log = MetaCognitionLog(
            user_id=user_id,
            thinking_about=data.thinking_about,
            strategy_used=data.strategy_used,
            strategy_effectiveness=data.strategy_effectiveness,
            insight=data.insight,
            adjustment=data.adjustment,
            context=data.context,
            linked_chain_id=data.linked_chain_id,
            linked_idea_id=data.linked_idea_id,
        )
        self.db.add(log)
        self.db.commit()
        self.db.refresh(log)
        
        return {
            "id": log.id,
            "thinking_about": log.thinking_about,
            "strategy_used": log.strategy_used,
            "strategy_effectiveness": log.strategy_effectiveness,
            "insight": log.insight,
            "adjustment": log.adjustment,
            "created_at": log.created_at.isoformat() if log.created_at else None,
        }
    
    async def get_patterns(self, user_id: int, days: int = 30) -> Dict:
        """
        Analyze meta-cognitive patterns over the last N days.
        
        Returns:
            - Strategy effectiveness rankings
            - Improvement trend (improving/stable/declining)
            - Most/least effective strategies
            - Common thinking domains
        """
        since = datetime.utcnow() - timedelta(days=days)
        
        logs = self.db.query(MetaCognitionLog).filter(
            and_(
                MetaCognitionLog.user_id == user_id,
                MetaCognitionLog.created_at >= since,
            )
        ).order_by(MetaCognitionLog.created_at.desc()).all()
        
        if not logs:
            return {
                "total_logs": 0,
                "strategies": {},
                "best_strategy": None,
                "worst_strategy": None,
                "improvement_trend": "insufficient_data",
            }
        
        # Aggregate by strategy
        strategies = {}
        for log in logs:
            s = log.strategy_used or "unspecified"
            if s not in strategies:
                strategies[s] = {
                    "count": 0,
                    "total_effectiveness": 0,
                    "effectiveness_history": [],
                }
            strategies[s]["count"] += 1
            strategies[s]["total_effectiveness"] += log.strategy_effectiveness
            strategies[s]["effectiveness_history"].append(log.strategy_effectiveness)
        
        # Compute averages and trends
        for s_name, s_data in strategies.items():
            s_data["avg_effectiveness"] = s_data["total_effectiveness"] / s_data["count"]
            s_data["avg_effectiveness"] = round(s_data["avg_effectiveness"], 3)
            
            # Simple trend: compare first half to second half
            history = s_data["effectiveness_history"]
            if len(history) >= 4:
                mid = len(history) // 2
                first_half = sum(history[:mid]) / mid
                second_half = sum(history[mid:]) / (len(history) - mid)
                if second_half > first_half + 0.05:
                    s_data["trend"] = "improving"
                elif second_half < first_half - 0.05:
                    s_data["trend"] = "declining"
                else:
                    s_data["trend"] = "stable"
            else:
                s_data["trend"] = "insufficient_data"
            
            del s_data["effectiveness_history"]  # Don't return raw history
        
        # Find best/worst
        valid_strategies = {k: v for k, v in strategies.items() if v["count"] >= 2}
        best = max(valid_strategies.items(), key=lambda x: x[1]["avg_effectiveness"]) if valid_strategies else None
        worst = min(valid_strategies.items(), key=lambda x: x[1]["avg_effectiveness"]) if valid_strategies else None
        
        # Overall trend
        if len(logs) >= 4:
            recent = [l.strategy_effectiveness for l in logs[:len(logs)//2]]
            older = [l.strategy_effectiveness for l in logs[len(logs)//2:]]
            recent_avg = sum(recent) / len(recent)
            older_avg = sum(older) / len(older)
            if recent_avg > older_avg + 0.05:
                overall_trend = "improving"
            elif recent_avg < older_avg - 0.05:
                overall_trend = "declining"
            else:
                overall_trend = "stable"
        else:
            overall_trend = "insufficient_data"
        
        return {
            "total_logs": len(logs),
            "strategies": strategies,
            "best_strategy": best[0] if best else None,
            "worst_strategy": worst[0] if worst else None,
            "improvement_trend": overall_trend,
        }
    
    async def suggest_adjustment(self, user_id: int) -> Dict:
        """
        Suggest strategy adjustments based on patterns.
        
        Analysis:
        1. Find strategies with effectiveness < 0.5 (needs improvement)
        2. Find strategies with effectiveness > 0.7 (prefer these)
        3. Generate actionable suggestions
        """
        patterns = await self.get_patterns(user_id)
        strategies = patterns.get("strategies", {})
        
        if not strategies:
            return {
                "suggestion": "No reflection data yet. Start reflecting on your thinking processes!",
                "strategies_to_prefer": [],
                "strategies_to_avoid": [],
            }
        
        strategies_to_prefer = [
            name for name, data in strategies.items()
            if data["avg_effectiveness"] > 0.7 and data["count"] >= 2
        ]
        
        strategies_to_avoid = [
            name for name, data in strategies.items()
            if data["avg_effectiveness"] < 0.5 and data["count"] >= 2
        ]
        
        suggestion_parts = []
        if strategies_to_prefer:
            suggestion_parts.append(
                f"Prefer these strategies: {', '.join(strategies_to_prefer)}"
            )
        if strategies_to_avoid:
            suggestion_parts.append(
                f"Consider alternatives to: {', '.join(strategies_to_avoid)}"
            )
        
        return {
            "suggestion": "; ".join(suggestion_parts) if suggestion_parts else "Continue current approach — no strong signals yet.",
            "strategies_to_prefer": strategies_to_prefer,
            "strategies_to_avoid": strategies_to_avoid,
            "overall_trend": patterns.get("improvement_trend"),
        }
    
    async def get_recent_reflections(
        self, user_id: int, limit: int = 20
    ) -> List[Dict]:
        """Get recent meta-cognition reflections."""
        logs = self.db.query(MetaCognitionLog).filter(
            MetaCognitionLog.user_id == user_id
        ).order_by(MetaCognitionLog.created_at.desc()).limit(limit).all()
        
        return [
            {
                "id": l.id,
                "thinking_about": l.thinking_about,
                "strategy_used": l.strategy_used,
                "strategy_effectiveness": l.strategy_effectiveness,
                "insight": l.insight,
                "adjustment": l.adjustment,
                "created_at": l.created_at.isoformat() if l.created_at else None,
            }
            for l in logs
        ]

from typing import Dict, List, Any, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from sqlalchemy import and_

from backend.app.models.cognition.consciousness_state import ConsciousnessState
from backend.app.schemas.cognition.advanced import ConsciousnessUpdate, ThinkRequest


class ConsciousnessSimulationService:
    """
    Tracks awareness state: focus, energy, attention, and self-model.
    
    This is NOT philosophical consciousness — it's practical awareness tracking
    that enables adaptive behavior in the CORTEX system.
    
    Features:
    - Focus management (what the system is attending to)
    - Energy simulation (cognitive resource tracking)
    - Attention breadth (narrow vs broad focus)
    - Active thought queue (working memory)
    - Context buffer (recent context items)
    - Self-model (system's assessment of capabilities)
    - Thought management (add/remove thoughts)
    
    Usage:
    - Dashboard shows current awareness state
    - Reasoning service checks energy before heavy operations
    - Focus management informs task prioritization
    - Self-model enables capability-aware decision making
    """
    
    MAX_ACTIVE_THOUGHTS = 10
    MAX_CONTEXT_BUFFER = 20
    
    EMOTIONAL_STATES = [
        "neutral", "curious", "focused", "creative",
        "analytical", "resting", "alert",
    ]
    
    def __init__(self, db: Session):
        self.db = db
    
    async def get_state(self, user_id: int) -> Dict:
        """
        Get current consciousness state.
        Creates a default state if none exists.
        """
        state = self.db.query(ConsciousnessState).filter(
            ConsciousnessState.user_id == user_id
        ).first()
        
        if not state:
            state = ConsciousnessState(user_id=user_id)
            self.db.add(state)
            self.db.commit()
            self.db.refresh(state)
        
        return self._state_to_dict(state)
    
    async def update_state(
        self, user_id: int, data: ConsciousnessUpdate
    ) -> Dict:
        """
        Update consciousness state fields.
        Only updates fields that are explicitly provided.
        """
        state = self.db.query(ConsciousnessState).filter(
            ConsciousnessState.user_id == user_id
        ).first()
        
        if not state:
            state = ConsciousnessState(user_id=user_id)
            self.db.add(state)
        
        update_data = data.model_dump(exclude_unset=True)
        for field, value in update_data.items():
            if value is not None and hasattr(state, field):
                setattr(state, field, value)
        
        self.db.commit()
        self.db.refresh(state)
        return self._state_to_dict(state)
    
    async def think(self, user_id: int, data: ThinkRequest) -> Dict:
        """
        Add a thought to active thinking.
        
        Thoughts are a bounded queue (max 10). When full, lowest-priority
        thought is evicted. This simulates working memory constraints.
        """
        state = self.db.query(ConsciousnessState).filter(
            ConsciousnessState.user_id == user_id
        ).first()
        
        if not state:
            state = ConsciousnessState(user_id=user_id)
            self.db.add(state)
        
        thoughts = state.active_thoughts or []
        
        # Add new thought
        new_thought = {
            "thought": data.thought,
            "priority": data.priority,
            "added_at": datetime.utcnow().isoformat(),
        }
        thoughts.append(new_thought)
        
        # Evict lowest priority if over limit
        if len(thoughts) > self.MAX_ACTIVE_THOUGHTS:
            thoughts.sort(key=lambda t: t.get("priority", 0), reverse=True)
            thoughts = thoughts[:self.MAX_ACTIVE_THOUGHTS]
        
        state.active_thoughts = thoughts
        self.db.commit()
        
        return {
            "added": data.thought,
            "active_thoughts": len(thoughts),
            "thoughts": thoughts,
        }
    
    async def clear_thoughts(self, user_id: int) -> Dict:
        """Clear all active thoughts."""
        state = self.db.query(ConsciousnessState).filter(
            ConsciousnessState.user_id == user_id
        ).first()
        
        if state:
            state.active_thoughts = []
            self.db.commit()
        
        return {"cleared": True, "active_thoughts": 0}
    
    async def add_to_context_buffer(
        self, user_id: int, item_type: str, item_id: int, summary: str
    ) -> Dict:
        """
        Add an item to the context buffer (working memory).
        
        The context buffer holds recent context items that inform
        current thinking. Items expire after a time or when buffer is full.
        """
        state = self.db.query(ConsciousnessState).filter(
            ConsciousnessState.user_id == user_id
        ).first()
        
        if not state:
            state = ConsciousnessState(user_id=user_id)
            self.db.add(state)
        
        buffer = state.context_buffer or []
        
        new_item = {
            "type": item_type,
            "id": item_id,
            "summary": summary[:500],
            "added_at": datetime.utcnow().isoformat(),
        }
        buffer.append(new_item)
        
        # Evict oldest if over limit
        if len(buffer) > self.MAX_CONTEXT_BUFFER:
            buffer = buffer[-self.MAX_CONTEXT_BUFFER:]
        
        state.context_buffer = buffer
        self.db.commit()
        
        return {
            "buffer_size": len(buffer),
            "item_added": new_item,
        }
    
    async def get_awareness(self, user_id: int) -> Dict:
        """Get a summary of current awareness for dashboard display."""
        state = await self.get_state(user_id)
        
        return {
            "level": state["awareness_level"],
            "focus": state["focus"],
            "energy": state["energy_level"],
            "emotional_state": state["emotional_state"],
            "attention_breadth": state["attention_breadth"],
            "active_thoughts": len(state.get("active_thoughts", [])),
            "context_items": len(state.get("context_buffer", [])),
            "total_reasoning_chains": state.get("total_reasoning_chains", 0),
            "total_creative_ideas": state.get("total_creative_ideas", 0),
            "total_reflections": state.get("total_reflections", 0),
        }
    
    async def update_counters(
        self, user_id: int,
        reasoning_chains: int = 0,
        creative_ideas: int = 0,
        reflections: int = 0,
    ) -> Dict:
        """
        Increment lifetime counters.
        Called by reasoning, creative, and meta-cognition services
        after successful operations.
        """
        state = self.db.query(ConsciousnessState).filter(
            ConsciousnessState.user_id == user_id
        ).first()
        
        if not state:
            state = ConsciousnessState(user_id=user_id)
            self.db.add(state)
        
        state.total_reasoning_chains += reasoning_chains
        state.total_creative_ideas += creative_ideas
        state.total_reflections += reflections
        self.db.commit()
        
        return {
            "total_reasoning_chains": state.total_reasoning_chains,
            "total_creative_ideas": state.total_creative_ideas,
            "total_reflections": state.total_reflections,
        }
    
    def _state_to_dict(self, state: ConsciousnessState) -> Dict:
        return {
            "awareness_level": state.awareness_level,
            "focus": state.focus,
            "emotional_state": state.emotional_state,
            "active_thoughts": state.active_thoughts or [],
            "context_buffer": state.context_buffer or [],
            "self_model": state.self_model or {},
            "energy_level": state.energy_level,
            "attention_breadth": state.attention_breadth,
            "total_reasoning_chains": state.total_reasoning_chains,
            "total_creative_ideas": state.total_creative_ideas,
            "total_reflections": state.total_reflections,
            "updated_at": state.updated_at.isoformat() if state.updated_at else None,
        }
```

|------|------|------------|--------|------------|
| T1: CreativeThinking | Ideas are generic without LLM | High | Medium | Template-based fallback with randomization. LLM enhances but isn't required. |
| T1: CreativeThinking | Brainstorm produces redundant ideas | Medium | Low | Deduplication in converge phase. Perspective diversity helps. |

| T2: MetaCognition | Feedback loop causes oscillation | Low | Medium | Maximum adjustment rate. Conservative strategy shifts. |
| T3: Consciousness | Active thoughts grow unbounded | Low | Medium | MAX_ACTIVE_THOUGHTS limit (10). Priority-based eviction. |
| T3: Consciousness | State corruption on concurrent access | Low | Low | Single-writer pattern. User-scoped state. |
