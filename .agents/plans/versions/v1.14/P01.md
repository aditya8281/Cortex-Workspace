## Architecture Decisions

### ADR-14-01: Reasoning Chain as JSON Sequence

**Decision:** Reasoning chains are stored as a JSON array of step objects, not as separate database rows per step.

**Rationale:** Reasoning chains are atomic units — they don't make sense as individual steps. JSON storage keeps the chain as a single row, simplifies queries, and allows flexible step schemas (different chain types may have different step structures).

**Consequence:** No database-level indexing on individual steps. Chain analysis happens in-memory. For chains with 100+ steps (unlikely in practice), this may need optimization.

### ADR-14-02: Consciousness State as Singleton Per User

**Decision:** Each user has exactly one ConsciousnessState row, updated in place. Not a history table.

**Rationale:** Consciousness state represents the "current" awareness — it's a live state, not a historical log. Previous states are reconstructed from meta-cognition logs and reasoning chain timestamps.

**Consequence:** State changes overwrite previous state. History is lost unless explicitly logged via MetaCognitionLog. This is intentional — consciousness is about the present, not the past.

### ADR-14-03: Creativity Scores as Float Metrics

**Decision:** Novelty and feasibility scores are stored as floats (0.0-1.0). Not integer ratings.

**Rationale:** Float scores enable fine-grained ranking and comparison. They're computed by the service layer (LLM-based or heuristic) and stored for retrieval. The schema doesn't enforce range — the service layer does.

**Consequence:** Invalid scores (>1.0 or <0.0) are rejected at the service layer, not the database layer. This is consistent with the existing pattern for confidence scores.

### Task 1: Create ReasoningChain Model

**File:** `backend/app/models/cognition/reasoning_chain.py`

```python
from sqlalchemy import Column, Integer, String, DateTime, Text, JSON, Float, Index
from datetime import datetime
from backend.app.db.base import Base


class ReasoningChain(Base):
    """
    Stores multi-step reasoning chains with confidence propagation.
    
    Chain Types:
    - deductive: General → Specific (if A then B; A; therefore B)
    - inductive: Specific → General (observed patterns → rule)
    - abductive: Observation → Best explanation (inference to best explanation)
    - analogical: Source domain → Target domain (A is like B)
    - causal: Cause → Effect chain (A caused B caused C)
    
    Chain Structure (JSON):
    [
        {
            "step": 1,
            "type": "premise",
            "content": "All humans are mortal",
            "confidence": 0.95,
            "evidence": ["established fact"]
        },
        {
            "step": 2,
            "type": "inference",
            "content": "Socrates is human",
            "confidence": 0.9,
            "evidence": ["historical record"],
            "parent_step": 1
        },
        {
            "step": 3,
            "type": "conclusion",
            "content": "Socrates is mortal",
            "confidence": 0.855,
            "derived_from": [1, 2]
        }
    ]
    """
    __tablename__ = "reasoning_chains"

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, nullable=False)
    problem = Column(Text, nullable=False)  # The original question/problem
    chain_type = Column(String(50), nullable=False, default="deductive")
    chain = Column(JSON, nullable=False, default=list)  # Array of step objects
    result = Column(Text, nullable=True)  # Final conclusion text
    confidence = Column(Float, nullable=True)  # Overall chain confidence (0.0-1.0)
    depth = Column(Integer, default=1)  # Number of steps in chain
    max_depth_reached = Column(Integer, default=0)  # Deepest step attempted
    context_used = Column(JSON, default=list)  # IDs of memories/entities used
    execution_time_ms = Column(Integer, nullable=True)  # How long the chain took
    status = Column(String(20), default="completed")  # completed, timeout, error, partial
    error_message = Column(Text, nullable=True)  # If status is error/partial
    metadata_ = Column("metadata", JSON, default=dict)
    created_at = Column(DateTime, default=datetime.utcnow)

    __table_args__ = (
        Index("idx_reasoning_user_type", "user_id", "chain_type"),
        Index("idx_reasoning_user_created", "user_id", "created_at"),
    )
```

**Design rationale:**
- `chain` stores the full step sequence as JSON — atomic and queryable as a unit
- `context_used` tracks which memories/entities influenced the reasoning (for explainability)
- `execution_time_ms` enables performance monitoring of reasoning operations
- `status` tracks whether the chain completed successfully or hit limits
- `confidence` is the final propagated confidence, not per-step (those are in the chain JSON)

### Task 2: Create CreativeIdea Model

**File:** `backend/app/models/cognition/creative_idea.py`

```python
from sqlalchemy import Column, Integer, String, DateTime, Text, JSON, Float, Index
from datetime import datetime
from backend.app.db.base import Base


class CreativeIdea(Base):
    """
    Stores generated creative ideas with quality metrics.
    
    Idea Structure:
    - prompt: The creative prompt/challenge
    - idea: The generated idea text
    - novelty_score: How novel/original (0.0-1.0)
    - feasibility_score: How practical/achievable (0.0-1.0)
    - domain: The creative domain (general, technical, artistic, business)
    - inspiration_sources: What inspired this idea (memory IDs, entities)
    - constraints_applied: What constraints were considered
    - rating: User-provided rating (null until rated)
    """
    __tablename__ = "creative_ideas"

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, nullable=False)
    prompt = Column(Text, nullable=False)  # The creative challenge
    idea = Column(Text, nullable=False)  # The generated idea
    novelty_score = Column(Float, nullable=True)  # 0.0-1.0
    feasibility_score = Column(Float, nullable=True)  # 0.0-1.0
    domain = Column(String(100), default="general")
    inspiration_sources = Column(JSON, default=list)  # [{"type": "memory", "id": 42}, ...]
    constraints_applied = Column(JSON, default=list)  # ["budget < $100", "2 week timeline"]
    rating = Column(Float, nullable=True)  # User rating (0.0-1.0), null until rated
    is_saved = Column(Boolean, default=False)  # User saved this idea
    tags = Column(JSON, default=list)
    metadata_ = Column("metadata", JSON, default=dict)
    created_at = Column(DateTime, default=datetime.utcnow)

    __table_args__ = (
        Index("idx_creative_user_domain", "user_id", "domain"),
        Index("idx_creative_user_saved", "user_id", "is_saved"),
    )
```

**Design rationale:**
- `novelty_score` and `feasibility_score` enable dual-axis ranking (novel vs practical)
- `inspiration_sources` traces which memories/entities inspired the idea (explainability)
- `constraints_applied` records what constraints shaped the idea (for reproducibility)
- `rating` enables user feedback loop — rate ideas to improve future generation
- `is_saved` enables "saved ideas" collection without a separate table

### Task 3: Create MetaCognitionLog Model

**File:** `backend/app/models/cognition/meta_cognition.py`

```python
from sqlalchemy import Column, Integer, String, DateTime, Text, JSON, Float, Index
from datetime import datetime
from backend.app.db.base import Base


class MetaCognitionLog(Base):
    """
    Logs self-reflective thinking about thinking processes.
    
    Each entry represents one reflection event:
    - What was being processed (the thinking_about)
    - What strategy was used
    - How effective it was (0.0-1.0)
    - What insight was gained
    - What adjustment should be made
    
    Over time, these logs enable:
    - Strategy effectiveness analysis
    - Pattern detection in thinking approaches
    - Adaptive strategy selection
    - Performance improvement tracking
    """
    __tablename__ = "meta_cognition_logs"

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, nullable=False)
    thinking_about = Column(Text, nullable=False)  # What was being processed
    strategy_used = Column(String(200), nullable=True)  # e.g., "deductive_chain", "brainstorm"
    strategy_effectiveness = Column(Float, default=0.5)  # 0.0-1.0, self-assessed or computed
    insight = Column(Text, nullable=True)  # What was discovered about the process
    adjustment = Column(Text, nullable=True)  # What should change next time
    context = Column(JSON, default=dict)  # {"task_type": "reasoning", "domain": "technical"}
    linked_chain_id = Column(Integer, nullable=True)  # Associated reasoning chain
    linked_idea_id = Column(Integer, nullable=True)  # Associated creative idea
    created_at = Column(DateTime, default=datetime.utcnow)

    __table_args__ = (
        Index("idx_meta_user_strategy", "user_id", "strategy_used"),
        Index("idx_meta_user_created", "user_id", "created_at"),
    )
```

**Design rationale:**
- `thinking_about` is free-form text describing the cognitive task
- `strategy_used` is a structured string enabling aggregation by strategy type
- `strategy_effectiveness` enables quantitative analysis of strategy performance
- `linked_chain_id` / `linked_idea_id` connects reflection to specific cognition events
- `context` captures metadata about the thinking context (task type, domain, etc.)

### Task 4: Create ConsciousnessState Model

**File:** `backend/app/models/cognition/consciousness_state.py`

```python
from sqlalchemy import Column, Integer, String, DateTime, Text, JSON, Float, Index
from datetime import datetime
from backend.app.db.base import Base


class ConsciousnessState(Base):
    """
    Tracks the current "awareness" state of the cognition system.
    
    This is a singleton per user — updated in place, not historical.
    Previous states are reconstructed from meta-cognition logs.
    
    Fields:
    - awareness_level: How aware/alert the system is (0.0-1.0)
    - focus: What the system is currently focused on
    - emotional_state: Simulated emotional context (neutral, curious, focused, etc.)
    - active_thoughts: Queue of thoughts currently being processed
    - context_buffer: Recent context items for working memory
    - self_model: The system's model of its own capabilities and state
    - energy_level: Available cognitive resources (0.0-1.0)
    - attention_breadth: How wide the focus is (narrow=0.0, broad=1.0)
    """
    __tablename__ = "consciousness_states"

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, nullable=False, unique=True)  # One state per user
    awareness_level = Column(Float, default=0.5)  # 0.0-1.0
    focus = Column(String(500), default="idle")  # What the system is focused on
    emotional_state = Column(String(100), default="neutral")  # Simulated emotional context
    active_thoughts = Column(JSON, default=list)  # [{"thought": "...", "priority": 0.8}, ...]
    context_buffer = Column(JSON, default=list)  # Recent context items (working memory)
    self_model = Column(JSON, default=dict)  # {"capabilities": [...], "limitations": [...]}
    energy_level = Column(Float, default=1.0)  # Available cognitive resources
    attention_breadth = Column(Float, default=0.5)  # 0.0=narrow, 1.0=broad
    total_reasoning_chains = Column(Integer, default=0)  # Lifetime counter
    total_creative_ideas = Column(Integer, default=0)  # Lifetime counter
    total_reflections = Column(Integer, default=0)  # Lifetime counter
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)

    __table_args__ = (
        Index("idx_consciousness_user", "user_id", unique=True),
    )
```

**Design rationale:**
- `user_id` is unique — one consciousness state per user (ADR-14-02)
- `active_thoughts` is a bounded JSON array (max 10 items, enforced in service)
- `context_buffer` acts as "working memory" — recent items for immediate access
- `self_model` stores the system's self-assessment of capabilities
- `energy_level` simulates cognitive fatigue — decreases with heavy use, recovers over time
- `attention_breadth` controls whether reasoning is deep-and-narrow or broad-and-shallow
- Lifetime counters (`total_*`) enable long-term growth tracking

**File:** `backend/app/schemas/cognition/advanced.py`

```python
from pydantic import BaseModel, Field, field_validator
from datetime import datetime
from typing import Optional, List, Dict, Any


class ReasoningStep(BaseModel):
    """A single step in a reasoning chain."""
    step: int
    type: str = Field(..., pattern="^(premise|inference|conclusion|observation|analogy)$")
    content: str
    confidence: float = Field(0.5, ge=0.0, le=1.0)
    evidence: List[str] = []
    parent_step: Optional[int] = None
    derived_from: List[int] = []


class ReasoningChainCreate(BaseModel):
    """Request to create a reasoning chain."""
    problem: str = Field(..., min_length=1, max_length=10000)
    chain_type: str = Field("deductive", pattern="^(deductive|inductive|abductive|analogical|causal)$")
    max_depth: int = Field(5, ge=1, le=10)
    context_ids: List[int] = []  # Memory/entity IDs to use as context


class ReasoningChainResponse(BaseModel):
    """Response containing a reasoning chain."""
    id: int
    user_id: int
    problem: str
    chain_type: str
    chain: List[Dict[str, Any]]
    result: Optional[str]
    confidence: Optional[float]
    depth: int
    max_depth_reached: int
    context_used: List[int]
    execution_time_ms: Optional[int]
    status: str
    created_at: datetime

    model_config = {"from_attributes": True}


class CreativeIdeaCreate(BaseModel):
    """Request to generate creative ideas."""
    prompt: str = Field(..., min_length=1, max_length=5000)
    domain: str = Field("general", max_length=100)
    count: int = Field(3, ge=1, le=10)
    constraints: List[str] = []
    context_ids: List[int] = []


class CreativeIdeaResponse(BaseModel):
    """Response containing a creative idea."""
    id: int
    user_id: int
    prompt: str
    idea: str
    novelty_score: Optional[float]
    feasibility_score: Optional[float]
    domain: str
    inspiration_sources: List[Dict[str, Any]]
    constraints_applied: List[str]
    rating: Optional[float]
    is_saved: bool
    tags: List[str]
    created_at: datetime

    model_config = {"from_attributes": True}


class MetaCognitionReflect(BaseModel):
    """Request to record a meta-cognitive reflection."""
    thinking_about: str = Field(..., min_length=1, max_length=5000)
    strategy_used: Optional[str] = Field(None, max_length=200)
    strategy_effectiveness: float = Field(0.5, ge=0.0, le=1.0)
    insight: Optional[str] = None
    adjustment: Optional[str] = None
    context: Dict[str, Any] = {}
    linked_chain_id: Optional[int] = None
    linked_idea_id: Optional[int] = None


class MetaCognitionResponse(BaseModel):
    """Response containing a meta-cognition log entry."""
    id: int
    user_id: int
    thinking_about: str
    strategy_used: Optional[str]
    strategy_effectiveness: float
    insight: Optional[str]
    adjustment: Optional[str]
    context: Dict[str, Any]
    created_at: datetime

    model_config = {"from_attributes": True}


class MetaCognitionPatterns(BaseModel):
    """Aggregated meta-cognitive patterns."""
    total_logs: int
    strategies: Dict[str, Dict[str, Any]]  # strategy -> {count, avg_effectiveness}
    best_strategy: Optional[str]
    worst_strategy: Optional[str]
    improvement_trend: str  # "improving", "stable", "declining"


class ConsciousnessStateResponse(BaseModel):
    """Response containing consciousness state."""
    awareness_level: float
    focus: str
    emotional_state: str
    active_thoughts: List[Dict[str, Any]]
    context_buffer: List[Dict[str, Any]]
    self_model: Dict[str, Any]
    energy_level: float
    attention_breadth: float
    total_reasoning_chains: int
    total_creative_ideas: int
    total_reflections: int
    updated_at: datetime

    model_config = {"from_attributes": True}


class ConsciousnessUpdate(BaseModel):
    """Request to update consciousness state."""
    focus: Optional[str] = None
    emotional_state: Optional[str] = Field(None, pattern="^(neutral|curious|focused|creative|analytical|resting|alert)$")
    awareness_level: Optional[float] = Field(None, ge=0.0, le=1.0)
    energy_level: Optional[float] = Field(None, ge=0.0, le=1.0)
    attention_breadth: Optional[float] = Field(None, ge=0.0, le=1.0)


class ThinkRequest(BaseModel):
    """Request to add a thought to active thinking."""
    thought: str = Field(..., min_length=1, max_length=1000)
    priority: float = Field(0.5, ge=0.0, le=1.0)
```

## Per-Task Risk Analysis

| Task | Risk | Probability | Impact | Mitigation |
|------|------|------------|--------|------------|
| T1: ReasoningChain | JSON chain grows too large | Low | Medium | Limit chain to 10 steps. Truncate in service layer. |
| T1: ReasoningChain | Complex JSON queries slow | Low | Low | Chain analysis is in-memory. No DB-level JSON queries. |
| T2: CreativeIdea | Score range validation | Low | Low | Pydantic validators enforce 0.0-1.0 range. |
| T3: MetaCognitionLog | Log volume grows unbounded | Medium | Low | Implement log rotation in service layer. Keep last 1000 per user. |
| T4: ConsciousnessState | Singleton constraint violated | Low | High | UNIQUE index on user_id. Service uses upsert pattern. |

# tests/test_cognition_models.py

import pytest
from datetime import datetime


def test_reasoning_chain_creation(db_session):
    from backend.app.models.cognition.reasoning_chain import ReasoningChain
    chain = ReasoningChain(
        user_id=1,
        problem="What is the meaning of life?",
