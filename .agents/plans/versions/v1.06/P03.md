## Implementation Tasks

### Task 1: Implement Hypothesis Service

**Architecture:** The HypothesisService manages the full lifecycle of hypotheses: creation, evidence gathering, Bayesian confidence updating, and resolution. Key design decisions:
- **Evidence weighting:** Each evidence item has a weight (0.0-1.0) reflecting its reliability
- **Bayesian updating:** Confidence is updated using a simplified Bayesian approach: `P(H|E) = P(E|H) * P(H) / P(E)`
- **Confidence history:** Every confidence change is recorded for trend analysis
- **Source tracking:** Hypotheses track what triggered them (error_analysis, planning, user_input, memory)

**Implementation:**
```python
# backend/app/services/cognition/hypothesis.py

import math
from typing import List, Dict, Any, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from backend.app.models.cognition.hypothesis import Hypothesis


class HypothesisService:
    """Hypothesis generation and management with Bayesian confidence updating.
    
    Lifecycle:
    1. Generate hypothesis (status: active, confidence: 0.5)
    2. Add supporting/contradicting evidence (confidence updates)
    3. Resolve: confirm (confidence > 0.8) or reject (confidence < 0.2)
    
    Confidence model:
    - Starts at 0.5 (prior)
    - Each supporting evidence increases confidence
    - Each contradicting evidence decreases confidence
    - Magnitude depends on evidence weight (reliability)
    - Uses simplified Bayesian update: odds ratio approach
    
    Usage:
        service = HypothesisService(db)
        hypo = await service.generate_hypothesis(
            user_id=1,
            hypothesis="The bug is in the parser module",
            source="error_analysis"
        )
        hypo = await service.add_evidence(hypo.id, "Error occurs only when parser is invoked", supports=True, weight=0.9)
        hypo = await service.add_evidence(hypo.id, "Error also occurs without parser", supports=False, weight=0.7)
    """
    
    # Prior strength: how much we trust our initial prior (0.5)
    PRIOR_STRENGTH = 2.0
    
    # Auto-resolve thresholds
    AUTO_CONFIRM_THRESHOLD = 0.90
    AUTO_REJECT_THRESHOLD = 0.10
    
    def __init__(self, db: Session):
        self.db = db
    
    async def generate_hypothesis(self, user_id: int, hypothesis: str,
                                  evidence_for: Optional[List[Dict[str, Any]]] = None,
                                  evidence_against: Optional[List[Dict[str, Any]]] = None,
                                  source: Optional[str] = None,
                                  related_plan_id: Optional[int] = None,
                                  related_hypothesis_id: Optional[int] = None) -> Hypothesis:
        """Generate a new hypothesis.
        
        Args:
            hypothesis: The hypothesis statement
            evidence_for: Initial supporting evidence [{text, weight, source}]
            evidence_against: Initial contradicting evidence
            source: What triggered this: error_analysis, planning, user_input, memory
            related_plan_id: If generated during planning
            related_hypothesis_id: If spawned from another hypothesis
        """
        ev_for = evidence_for or []
        ev_against = evidence_against or []
        
        confidence = self._calculate_confidence(ev_for, ev_against)
        
        hypo = Hypothesis(
            user_id=user_id,
            hypothesis=hypothesis,
            evidence_for=ev_for,
            evidence_against=ev_against,
            confidence=confidence,
            confidence_history=[{
                "value": confidence,
                "timestamp": datetime.utcnow().isoformat(),
                "trigger": "creation",
                "evidence_count": len(ev_for) + len(ev_against),
            }],
            status="active",
            source=source,
            related_plan_id=related_plan_id,
            related_hypothesis_id=related_hypothesis_id,
            created_at=datetime.utcnow(),
        )
        self.db.add(hypo)
        self.db.commit()
        self.db.refresh(hypo)
        return hypo
    
    async def add_evidence(self, hypothesis_id: int, text: str,
                          supports: bool, weight: float = 1.0,
                          source: Optional[str] = None) -> Hypothesis:
        """Add evidence to a hypothesis and update confidence.
        
        Args:
            hypothesis_id: ID of the hypothesis
            text: Evidence description
            supports: True = supports hypothesis, False = contradicts
            weight: Reliability of this evidence (0.0-1.0, default 1.0)
            source: Where this evidence came from
        """
        hypo = self.db.query(Hypothesis).filter(Hypothesis.id == hypothesis_id).first()
        if not hypo:
            raise ValueError(f"Hypothesis {hypothesis_id} not found")
        if hypo.status != "active":
            raise ValueError(f"Hypothesis is already {hypo.status}")
        
        # Clamp weight
        weight = max(0.0, min(1.0, weight))
        
        evidence_item = {
            "text": text,
            "weight": weight,
            "source": source,
            "timestamp": datetime.utcnow().isoformat(),
        }
        
        if supports:
            hypo.evidence_for = list(hypo.evidence_for or []) + [evidence_item]
        else:
            hypo.evidence_against = list(hypo.evidence_against or []) + [evidence_item]
        
        # Update confidence using Bayesian approach
        old_confidence = hypo.confidence
        new_confidence = self._calculate_confidence(
            hypo.evidence_for or [], hypo.evidence_against or []
        )
        hypo.confidence = new_confidence
        
        # Record confidence history
        history = list(hypo.confidence_history or [])
        history.append({
            "value": new_confidence,
            "previous_value": old_confidence,
            "timestamp": datetime.utcnow().isoformat(),
            "trigger": f"evidence_{'added' if supports else 'contradicted'}",
            "evidence_text": text[:100],
            "evidence_weight": weight,
        })
        hypo.confidence_history = history
        
        hypo.updated_at = datetime.utcnow()
        self.db.commit()
        self.db.refresh(hypo)
        
        # Auto-resolve if confidence crosses threshold
        await self._check_auto_resolve(hypo)
        
        return hypo
    
    async def resolve_hypothesis(self, hypothesis_id: int, status: str,
                                reason: Optional[str] = None) -> Hypothesis:
        """Resolve a hypothesis (confirm or reject).
        
        Args:
            status: 'confirmed' or 'rejected'
            reason: Why this resolution was chosen
        """
        if status not in ("confirmed", "rejected"):
            raise ValueError(f"Status must be 'confirmed' or 'rejected', got '{status}'")
        
        hypo = self.db.query(Hypothesis).filter(Hypothesis.id == hypothesis_id).first()
        if not hypo:
            raise ValueError(f"Hypothesis {hypothesis_id} not found")
        if hypo.status != "active":
            raise ValueError(f"Hypothesis is already {hypo.status}")
        
        hypo.status = status
        hypo.resolved_at = datetime.utcnow()
        hypo.resolution_reason = reason
        hypo.updated_at = datetime.utcnow()
        
        # Record final confidence
        history = list(hypo.confidence_history or [])
        history.append({
            "value": hypo.confidence,
            "timestamp": datetime.utcnow().isoformat(),
            "trigger": f"resolved_{status}",
            "reason": reason,
        })
        hypo.confidence_history = history
        
        self.db.commit()
        self.db.refresh(hypo)
        return hypo
    
    async def get_hypothesis(self, hypothesis_id: int) -> Optional[Hypothesis]:
        """Get a hypothesis by ID."""
        return self.db.query(Hypothesis).filter(Hypothesis.id == hypothesis_id).first()
    
    async def get_user_hypotheses(self, user_id: int, status: Optional[str] = None,
                                 limit: int = 50) -> List[Hypothesis]:
        """Get hypotheses for a user."""
        query = self.db.query(Hypothesis).filter(Hypothesis.user_id == user_id)
        if status:
            query = query.filter(Hypothesis.status == status)
        return query.order_by(Hypothesis.created_at.desc()).limit(limit).all()
    
    async def get_active_hypotheses(self, user_id: int) -> List[Hypothesis]:
        """Get all active hypotheses for a user."""
        return await self.get_user_hypotheses(user_id, status="active")
    
    async def get_high_confidence_hypotheses(self, user_id: int,
                                            threshold: float = 0.7) -> List[Hypothesis]:
        """Get active hypotheses above confidence threshold."""
        return self.db.query(Hypothesis).filter(
            Hypothesis.user_id == user_id,
            Hypothesis.status == "active",
            Hypothesis.confidence >= threshold,
        ).order_by(Hypothesis.confidence.desc()).all()
    
    async def merge_hypotheses(self, hypothesis_id: int, other_id: int) -> Hypothesis:
        """Merge two hypotheses by combining their evidence."""
        h1 = self.db.query(Hypothesis).filter(Hypothesis.id == hypothesis_id).first()
        h2 = self.db.query(Hypothesis).filter(Hypothesis.id == other_id).first()
        
        if not h1 or not h2:
            raise ValueError("One or both hypotheses not found")
        if h1.user_id != h2.user_id:
            raise ValueError("Cannot merge hypotheses from different users")
        if h1.status != "active" or h2.status != "active":
            raise ValueError("Can only merge active hypotheses")
        
        # Combine evidence
        combined_for = list(h1.evidence_for or []) + list(h2.evidence_for or [])
        combined_against = list(h1.evidence_against or []) + list(h2.evidence_against or [])
        
        h1.evidence_for = combined_for
        h1.evidence_against = combined_against
        h1.hypothesis = f"{h1.hypothesis} + {h2.hypothesis}"
        h1.confidence = self._calculate_confidence(combined_for, combined_against)
        h1.updated_at = datetime.utcnow()
        
        # Resolve the other
        h2.status = "merged"
        h2.resolved_at = datetime.utcnow()
        h2.resolution_reason = f"Merged into hypothesis {h1.id}"
        
        self.db.commit()
        self.db.refresh(h1)
        return h1
    
    def _calculate_confidence(self, evidence_for: List[Dict[str, Any]],
                             evidence_against: List[Dict[str, Any]]) -> float:
        """Calculate confidence using Bayesian odds update.
        
        Prior: 0.5 (no information)
        Each supporting evidence increases odds
        Each contradicting evidence decreases odds
        Weight scales the evidence strength
        
        Formula:
            prior_odds = P(H) / (1 - P(H))
            For each supporting evidence with weight w:
                likelihood_ratio = 1 + w (evidence is w times more likely if H is true)
                prior_odds *= likelihood_ratio
            For each contradicting evidence with weight w:
                likelihood_ratio = 1 + w (evidence is w times more likely if H is false)
                prior_odds /= likelihood_ratio
            P(H) = prior_odds / (1 + prior_odds)
        """
        if not evidence_for and not evidence_against:
            return 0.5
        
        # Start with prior odds
        prior_p = 0.5
        odds = prior_p / (1 - prior_p)  # = 1.0
        
        # Update with supporting evidence
        for ev in evidence_for:
            weight = ev.get("weight", 1.0) if isinstance(ev, dict) else 1.0
            likelihood_ratio = 1.0 + weight
            odds *= likelihood_ratio
        
        # Update with contradicting evidence
        for ev in evidence_against:
            weight = ev.get("weight", 1.0) if isinstance(ev, dict) else 1.0
            likelihood_ratio = 1.0 + weight
            odds /= likelihood_ratio
        
        # Convert back to probability
        confidence = odds / (1.0 + odds)
        
        # Clamp to [0.01, 0.99] to avoid extreme values
        return max(0.01, min(0.99, confidence))
    
    async def _check_auto_resolve(self, hypo: Hypothesis) -> None:
        """Auto-resolve hypothesis if confidence crosses thresholds."""
        if hypo.confidence >= self.AUTO_CONFIRM_THRESHOLD:
            hypo.status = "confirmed"
            hypo.resolved_at = datetime.utcnow()
            hypo.resolution_reason = "Auto-confirmed: confidence exceeded threshold"
            self.db.commit()
        elif hypo.confidence <= self.AUTO_REJECT_THRESHOLD:
            hypo.status = "rejected"
            hypo.resolved_at = datetime.utcnow()
            hypo.resolution_reason = "Auto-rejected: confidence below threshold"
            self.db.commit()
```

**Performance Considerations:**
- Confidence computation is O(n) in evidence count — fast for typical hypotheses (< 50 evidence items)
- `get_high_confidence_hypotheses` uses index on `(user_id, status, confidence)`
- Confidence history grows linearly — cap at 100 entries per hypothesis

**Risk Notes:**
- Bayesian update with unweighted evidence can overfit. Weight parameter allows tuning reliability.
- Auto-resolve thresholds may be too aggressive. Consider making them configurable.

### Task 2: Implement Confidence Estimation Service

**Architecture:** The ConfidenceEstimationService estimates how confident Cortex should be in any reasoning output. It's a meta-cognitive service — it reasons about reasoning quality. Key factors:
- **Task type:** Different tasks have different base confidence levels
- **Historical success:** Past success with similar tasks increases confidence
- **Novelty:** Novel situations decrease confidence
- **Data quality:** Better input data increases confidence
- **Evidence balance:** How much supporting vs contradicting evidence exists

**Implementation:**
```python
# backend/app/services/cognition/confidence.py

from typing import Dict, Any, List, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from backend.app.models.cognition.confidence_score import ConfidenceScore


class ConfidenceEstimationService:
    """Multi-factor confidence estimation for Cortex reasoning outputs.
    
    Estimates confidence 0-100 based on:
    1. Task type base rate (learned from history)
    2. Historical success rate for similar tasks
    3. Novelty of the current situation
    4. Quality/quantity of available data
    5. Evidence balance (supporting vs contradicting)
    6. Time pressure (more time = higher confidence)
    
    The service also tracks calibration: how well do confidence scores
    predict actual outcomes? Miscalibrated scores are adjusted.
    
    Usage:
        service = ConfidenceEstimationService(db)
        result = await service.estimate_task_confidence(
            "memory_retrieval",
            context={"similar_past_successes": 10, "novelty": 0.3, "data_quality": 0.8}
        )
    """
    
    # Base confidence by task type (learned from history, seeded with defaults)
    TASK_BASE_CONFIDENCE = {
        "memory_retrieval": 70,
        "file_analysis": 80,
        "code_generation": 60,
        "planning": 50,
        "error_analysis": 65,
        "hypothesis_generation": 55,
        "workflow_orchestration": 45,
        "tool_execution": 75,
        "data_export": 85,
        "access_check": 90,
    }
    
    # Confidence thresholds for recommendations
    HIGH_CONFIDENCE_THRESHOLD = 80
    MEDIUM_CONFIDENCE_THRESHOLD = 60
    LOW_CONFIDENCE_THRESHOLD = 40
    
    def __init__(self, db: Optional[Session] = None):
        self.db = db
    
    async def estimate_task_confidence(self, task_type: str,
                                       context: Optional[Dict[str, Any]] = None,
                                       store: bool = True) -> Dict[str, Any]:
        """Estimate confidence for a task.
        
        Args:
            task_type: Type of task
            context: Factors influencing confidence
            store: Whether to store the score for calibration tracking
        
        Returns:
            {confidence, recommendation, risk_level, factors}
        """
        context = context or {}
        
        # 1. Base confidence
        confidence = self.TASK_BASE_CONFIDENCE.get(task_type, 50)
        
        factors_applied = []
        
        # 2. Historical success adjustment
        past_successes = context.get("similar_past_successes", 0)
        past_failures = context.get("similar_past_failures", 0)
        if past_successes + past_failures > 0:
            success_rate = past_successes / (past_successes + past_failures)
            adjustment = int((success_rate - 0.5) * 20)  # -10 to +10
            confidence += adjustment
            factors_applied.append(f"historical_success_rate={success_rate:.2f} (adj={adjustment:+d})")
        
        # 3. Novelty adjustment
        novelty = context.get("novelty", 0.0)
        if novelty > 0.8:
            confidence -= 20
            factors_applied.append(f"high_novelty={novelty:.2f} (adj=-20)")
        elif novelty > 0.5:
            confidence -= 10
            factors_applied.append(f"medium_novelty={novelty:.2f} (adj=-10)")
        elif novelty > 0.2:
            confidence -= 5
            factors_applied.append(f"low_novelty={novelty:.2f} (adj=-5)")
        
        # 4. Data quality adjustment
        data_quality = context.get("data_quality", 0.5)
        if data_quality > 0.8:
            confidence += 10
            factors_applied.append(f"high_data_quality={data_quality:.2f} (adj=+10)")
        elif data_quality < 0.3:
            confidence -= 15
            factors_applied.append(f"low_data_quality={data_quality:.2f} (adj=-15)")
        
        # 5. Evidence balance
        evidence_for = context.get("evidence_for_count", 0)
        evidence_against = context.get("evidence_against_count", 0)
        total_evidence = evidence_for + evidence_against
        if total_evidence > 0:
            balance = evidence_for / total_evidence
            evidence_adjustment = int((balance - 0.5) * 15)
            confidence += evidence_adjustment
            factors_applied.append(f"evidence_balance={balance:.2f} (adj={evidence_adjustment:+d})")
        
        # 6. Time available adjustment
        time_pressure = context.get("time_pressure", 0.5)
        if time_pressure < 0.3:
            confidence += 5
            factors_applied.append("low_time_pressure (adj=+5)")
        elif time_pressure > 0.8:
            confidence -= 10
            factors_applied.append("high_time_pressure (adj=-10)")
        
        # Clamp to [1, 99]
        confidence = max(1, min(99, confidence))
        
        # Generate recommendation
        recommendation = self._generate_recommendation(confidence)
        risk_level = self._assess_risk_level(confidence)
        
        result = {
            "task_type": task_type,
            "confidence": confidence,
            "recommendation": recommendation,
            "risk_level": risk_level,
            "factors": factors_applied,
        }
        
        # Store for calibration tracking
        if store and self.db:
            score = ConfidenceScore(
                user_id=context.get("user_id", 0),
                task_type=task_type,
                confidence=confidence / 100.0,
                factors=[{"factor": f} for f in factors_applied],
                context=context,
                source=context.get("source", "estimation"),
                related_id=context.get("related_id"),
                created_at=datetime.utcnow(),
            )
            self.db.add(score)
            self.db.commit()
        
        return result
    
    async def explain_confidence(self, confidence: int,
                                factors: List[str]) -> Dict[str, Any]:
        """Generate a human-readable explanation of a confidence score."""
        recommendation = self._generate_recommendation(confidence)
        risk_level = self._assess_risk_level(confidence)
        
        explanation_parts = []
        if confidence > 80:
            explanation_parts.append("Confidence is high based on:")
        elif confidence > 60:
            explanation_parts.append("Confidence is moderate based on:")
        else:
            explanation_parts.append("Confidence is low based on:")
        
        for factor in factors:
            explanation_parts.append(f"  - {factor}")
        
        return {
            "confidence": confidence,
            "explanation": "\n".join(explanation_parts),
            "factors": factors,
            "recommendation": recommendation,
            "risk_level": risk_level,
        }
    
    async def combine_confidences(self, confidences: List[int],
                                  weights: Optional[List[float]] = None) -> Dict[str, Any]:
        """Combine multiple confidence scores into a single score.
        
        Uses weighted average. Higher weight = more influence.
        """
        if not confidences:
            return {"confidence": 50, "method": "default", "factors": []}
        
        if weights is None:
            weights = [1.0] * len(confidences)
        
        weighted_sum = sum(c * w for c, w in zip(confidences, weights))
        total_weight = sum(weights)
        
        if total_weight == 0:
            combined = 50
        else:
            combined = int(weighted_sum / total_weight)
        
        return {
            "confidence": combined,
            "method": "weighted_average",
            "input_scores": confidences,
            "input_weights": weights,
            "factors": [f"input_{i}: {c} (weight={w})" for i, (c, w) in enumerate(zip(confidences, weights))],
        }
    
    async def get_calibration_data(self, user_id: int, task_type: Optional[str] = None,
                                  days: int = 30) -> Dict[str, Any]:
        """Get calibration data: how well do confidence scores predict outcomes.
        
        Returns:
            {total_predictions, calibrated_count, calibration_score, by_task_type}
        """
        if not self.db:
            return {"error": "Database not available"}
        
        from datetime import timedelta
        since = datetime.utcnow() - timedelta(days=days)
        
        query = self.db.query(ConfidenceScore).filter(
            ConfidenceScore.user_id == user_id,
            ConfidenceScore.created_at >= since,
        )
        if task_type:
            query = query.filter(ConfidenceScore.task_type == task_type)
        
        scores = query.all()
        
        total = len(scores)
        calibrated = sum(1 for s in scores if s.was_accurate == 1)
        
        # Group by task type
        by_type: Dict[str, List] = {}
        for score in scores:
            if score.task_type not in by_type:
                by_type[score.task_type] = []
            by_type[score.task_type].append(score)
        
        type_calibration = {}
        for tt, type_scores in by_type.items():
            type_total = len(type_scores)
            type_calibrated = sum(1 for s in type_scores if s.was_accurate == 1)
            type_calibration[tt] = {
                "total": type_total,
                "calibrated": type_calibrated,
                "score": (type_calibrated / type_total * 100) if type_total > 0 else 0,
            }
        
        return {
            "total_predictions": total,
            "calibrated_count": calibrated,
            "calibration_score": (calibrated / total * 100) if total > 0 else 0,
            "by_task_type": type_calibration,
        }
    
    async def retroactive_calibration(self, score_id: int, actual_outcome: str) -> ConfidenceScore:
        """Record the actual outcome for a past confidence prediction.
        
        This enables calibration analysis: how well did the confidence
        score predict what actually happened?
        """
        if not self.db:
            raise ValueError("Database required for calibration")
        
        score = self.db.query(ConfidenceScore).filter(
            ConfidenceScore.id == score_id
        ).first()
        if not score:
            raise ValueError(f"Confidence score {score_id} not found")
        
        score.actual_outcome = actual_outcome
        
        # Determine if prediction was accurate
        predicted_positive = score.confidence > 0.5
        actual_positive = actual_outcome == "success"
        score.was_accurate = 1 if predicted_positive == actual_positive else 0
        
        self.db.commit()
        self.db.refresh(score)
        return score
    
    def _generate_recommendation(self, confidence: int) -> str:
        """Generate recommendation based on confidence level."""
        if confidence > self.HIGH_CONFIDENCE_THRESHOLD:
            return "Proceed autonomously. Confidence is high enough for automated action."
        elif confidence > self.MEDIUM_CONFIDENCE_THRESHOLD:
            return "Proceed with verification. Consider confirming critical decisions with user."
        elif confidence > self.LOW_CONFIDENCE_THRESHOLD:
            return "Request user confirmation before proceeding. Confidence is moderate."
        else:
            return "Gather more information before acting. Seek user input or additional evidence."
    
    def _assess_risk_level(self, confidence: int) -> str:
        """Assess risk level based on confidence."""
        if confidence > 75:
            return "low"
        elif confidence > 45:
            return "medium"
        else:
            return "high"
```

## Security Considerations

1. **Hypothesis text sanitization:** Sanitize hypothesis text to prevent XSS in UI rendering
2. **Confidence score storage:** Scores stored with user_id — all queries must filter by current user
3. **Evidence weight bounds:** Clamp to [0.0, 1.0] — prevent weight manipulation
4. **Auto-resolve thresholds:** Conservative defaults (0.90 confirm, 0.10 reject) — avoid premature resolution
5. **Merge safety:** Only merge hypotheses from the same user — prevent cross-user information leakage

- **Memory domain (v1.03):** Hypotheses query memory for evidence; confidence estimation uses memory quality as factor
- **Planning domain (P02):** Plans query confidence scores to decide whether to proceed or request confirmation; plan decomposition feeds hypothesis generation
- **Error analysis (P02):** Errors generate hypotheses about root causes; error patterns inform confidence estimation
- **Privacy domain (v1.05):** Hypothesis creation logged to audit trail; confidence scores included in data export
