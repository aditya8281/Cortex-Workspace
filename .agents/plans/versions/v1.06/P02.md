## Implementation Tasks

### Task 1: Implement Task Planning Service

**Architecture:** The TaskPlanningService decomposes high-level goals into ordered step DAGs. Key design decisions:
- **DAG structure:** Steps declare dependencies via `depends_on` indices. The service validates no cycles exist.
- **Decomposition:** Uses a template-based approach initially; LLM integration added in later versions.
- **Execution:** Steps are executed in topological order. Independent steps can run in parallel (future: async executor).
- **Checkpointing:** After each step, plan state is persisted. Failed steps can be retried from checkpoint.

**Implementation:**
```python
# backend/app/services/cognition/planning.py

from typing import List, Dict, Any, Optional, Set
from datetime import datetime
from sqlalchemy.orm import Session
from backend.app.models.cognition.task_plan import TaskPlan


class TaskPlanningService:
    """DAG-based task planning service.
    
    Decomposes goals into ordered steps with dependency tracking.
    Supports:
    - Goal decomposition into step DAGs
    - Cycle detection in dependency graph
    - Topological sort for execution order
    - Step execution with checkpointing
    - Plan status tracking (pending → in_progress → completed/failed)
    - Confidence estimation based on step count and complexity
    
    Usage:
        service = TaskPlanningService(db)
        plan = await service.create_plan(user_id=1, goal="Analyze code quality")
        steps = await service.decompose_task("Analyze code quality")
        plan = await service.create_plan(user_id=1, goal="...", steps=steps)
    """
    
    # Template-based decomposition (LLM integration in later versions)
    DECOMPOSITION_TEMPLATES = {
        "analyze": [
            {"description": "Gather context and data", "tool": None},
            {"description": "Process and analyze", "tool": None},
            {"description": "Generate findings", "tool": None},
            {"description": "Verify results", "tool": None},
        ],
        "build": [
            {"description": "Plan architecture", "tool": None},
            {"description": "Implement components", "tool": None},
            {"description": "Test implementation", "tool": None},
            {"description": "Deploy and verify", "tool": None},
        ],
        "research": [
            {"description": "Define research questions", "tool": None},
            {"description": "Gather sources", "tool": "web_search"},
            {"description": "Synthesize findings", "tool": None},
            {"description": "Document conclusions", "tool": None},
        ],
        "debug": [
            {"description": "Reproduce the issue", "tool": None},
            {"description": "Analyze error patterns", "tool": None},
            {"description": "Identify root cause", "tool": None},
            {"description": "Implement fix", "tool": None},
            {"description": "Verify fix", "tool": None},
        ],
    }
    
    def __init__(self, db: Session):
        self.db = db
    
    async def create_plan(self, user_id: int, goal: str,
                         steps: Optional[List[Dict[str, Any]]] = None,
                         metadata: Optional[Dict[str, Any]] = None) -> TaskPlan:
        """Create a task plan from a goal and steps.
        
        If steps are not provided, uses decompose_task() to generate them.
        Validates the DAG has no cycles before creating.
        """
        if steps is None:
            steps = await self.decompose_task(goal)
        
        # Assign step indices if not present
        for i, step in enumerate(steps):
            if "step" not in step:
                step["step"] = i
            if "status" not in step:
                step["status"] = "pending"
            if "depends_on" not in step:
                step["depends_on"] = []
        
        # Validate DAG: no cycles
        if self._has_cycle(steps):
            raise ValueError("Dependency graph contains a cycle")
        
        confidence = self._estimate_confidence(steps)
        
        plan = TaskPlan(
            user_id=user_id,
            goal=goal,
            steps=steps,
            status="pending",
            confidence=confidence,
            metadata=metadata or {},
            created_at=datetime.utcnow(),
        )
        self.db.add(plan)
        self.db.commit()
        self.db.refresh(plan)
        return plan
    
    async def decompose_task(self, goal: str) -> List[Dict[str, Any]]:
        """Decompose a goal into ordered steps.
        
        Current implementation: template-based matching on goal keywords.
        Future: LLM-based decomposition with context from memory.
        """
        goal_lower = goal.lower()
        
        # Match template by keyword
        template_key = "analyze"  # default
        for key in self.DECOMPOSITION_TEMPLATES:
            if key in goal_lower:
                template_key = key
                break
        
        template = self.DECOMPOSITION_TEMPLATES[template_key]
        
        steps = []
        for i, step_template in enumerate(template):
            steps.append({
                "step": i,
                "description": step_template["description"],
                "status": "pending",
                "tool": step_template.get("tool"),
                "params": {},
                "depends_on": [i - 1] if i > 0 else [],
                "result": None,
                "error": None,
            })
        
        return steps
    
    async def execute_step(self, plan_id: int, step_index: int,
                          result: Optional[Dict[str, Any]] = None,
                          error: Optional[str] = None) -> TaskPlan:
        """Execute a step in the plan and update status.
        
        Args:
            plan_id: ID of the plan
            step_index: Index of the step to execute
            result: Execution result (if successful)
            error: Error message (if failed)
        
        Returns:
            Updated plan
        """
        plan = self.db.query(TaskPlan).filter(TaskPlan.id == plan_id).first()
        if not plan:
            raise ValueError(f"Plan {plan_id} not found")
        
        if step_index < 0 or step_index >= len(plan.steps):
            raise ValueError(f"Step index {step_index} out of range (plan has {len(plan.steps)} steps)")
        
        # Verify dependencies are satisfied
        step = plan.steps[step_index]
        for dep_idx in step.get("depends_on", []):
            if dep_idx < len(plan.steps):
                dep_step = plan.steps[dep_idx]
                if dep_step.get("status") != "completed":
                    raise ValueError(
                        f"Step {step_index} depends on step {dep_idx} which is {dep_step.get('status')}"
                    )
        
        # Update step
        if error:
            plan.steps[step_index]["status"] = "failed"
            plan.steps[step_index]["error"] = error
            plan.status = "failed"
        else:
            plan.steps[step_index]["status"] = "completed"
            plan.steps[step_index]["result"] = result
            plan.current_step = step_index + 1
            
            # Check if all steps completed
            all_done = all(
                s.get("status") in ("completed", "skipped")
                for s in plan.steps
            )
            if all_done:
                plan.status = "completed"
                plan.completed_at = datetime.utcnow()
                plan.actual_duration_ms = int(
                    (plan.completed_at - plan.created_at).total_seconds() * 1000
                )
            else:
                plan.status = "in_progress"
        
        self.db.commit()
        self.db.refresh(plan)
        return plan
    
    async def skip_step(self, plan_id: int, step_index: int,
                       reason: Optional[str] = None) -> TaskPlan:
        """Skip a step (mark as skipped)."""
        plan = self.db.query(TaskPlan).filter(TaskPlan.id == plan_id).first()
        if not plan:
            raise ValueError(f"Plan {plan_id} not found")
        
        plan.steps[step_index]["status"] = "skipped"
        if reason:
            plan.steps[step_index]["skip_reason"] = reason
        
        plan.current_step = step_index + 1
        plan.status = "in_progress"
        
        # Check completion
        all_done = all(
            s.get("status") in ("completed", "skipped")
            for s in plan.steps
        )
        if all_done:
            plan.status = "completed"
            plan.completed_at = datetime.utcnow()
        
        self.db.commit()
        self.db.refresh(plan)
        return plan
    
    async def get_plan(self, plan_id: int) -> Optional[TaskPlan]:
        """Get a plan by ID."""
        return self.db.query(TaskPlan).filter(TaskPlan.id == plan_id).first()
    
    async def get_user_plans(self, user_id: int, status: Optional[str] = None,
                            limit: int = 50, offset: int = 0) -> List[TaskPlan]:
        """Get plans for a user, optionally filtered by status."""
        query = self.db.query(TaskPlan).filter(TaskPlan.user_id == user_id)
        if status:
            query = query.filter(TaskPlan.status == status)
        return query.order_by(TaskPlan.created_at.desc()).offset(offset).limit(limit).all()
    
    async def cancel_plan(self, plan_id: int) -> TaskPlan:
        """Cancel a plan."""
        plan = self.db.query(TaskPlan).filter(TaskPlan.id == plan_id).first()
        if not plan:
            raise ValueError(f"Plan {plan_id} not found")
        
        plan.status = "cancelled"
        plan.completed_at = datetime.utcnow()
        self.db.commit()
        self.db.refresh(plan)
        return plan
    
    async def get_next_executable_steps(self, plan_id: int) -> List[int]:
        """Get indices of steps that are ready to execute (dependencies satisfied, status=pending)."""
        plan = self.db.query(TaskPlan).filter(TaskPlan.id == plan_id).first()
        if not plan:
            return []
        
        ready = []
        for i, step in enumerate(plan.steps):
            if step.get("status") != "pending":
                continue
            
            deps = step.get("depends_on", [])
            deps_satisfied = all(
                plan.steps[d].get("status") in ("completed", "skipped")
                for d in deps
                if d < len(plan.steps)
            )
            if deps_satisfied:
                ready.append(i)
        
        return ready
    
    def _has_cycle(self, steps: List[Dict[str, Any]]) -> bool:
        """Detect cycles in the dependency graph using DFS."""
        n = len(steps)
        adj: Dict[int, List[int]] = {}
        for step in steps:
            idx = step.get("step", 0)
            adj[idx] = step.get("depends_on", [])
        
        WHITE, GRAY, BLACK = 0, 1, 2
        color = {i: WHITE for i in range(n)}
        
        def dfs(node: int) -> bool:
            color[node] = GRAY
            for neighbor in adj.get(node, []):
                if neighbor >= n:
                    continue
                if color[neighbor] == GRAY:
                    return True  # Cycle found
                if color[neighbor] == WHITE and dfs(neighbor):
                    return True
            color[node] = BLACK
            return False
        
        for i in range(n):
            if color[i] == WHITE and dfs(i):
                return True
        
        return False
    
    def _estimate_confidence(self, steps: List[Dict[str, Any]]) -> float:
        """Estimate confidence in plan success based on step characteristics."""
        if not steps:
            return 0.5
        
        base = 0.7
        
        # More steps = lower confidence
        step_penalty = min(0.3, len(steps) * 0.03)
        
        # Steps with tools = higher confidence (concrete actions)
        tool_count = sum(1 for s in steps if s.get("tool"))
        tool_bonus = min(0.2, tool_count * 0.05)
        
        # Deep dependency chains = lower confidence
        max_depth = self._max_dependency_depth(steps)
        depth_penalty = min(0.2, max_depth * 0.05)
        
        confidence = base - step_penalty + tool_bonus - depth_penalty
        return max(0.1, min(0.95, confidence))
    
    def _max_dependency_depth(self, steps: List[Dict[str, Any]]) -> int:
        """Calculate the maximum depth of the dependency chain."""
        depths: Dict[int, int] = {}
        
        def depth(idx: int) -> int:
            if idx in depths:
                return depths[idx]
            step = next((s for s in steps if s.get("step") == idx), None)
            if not step or not step.get("depends_on"):
                depths[idx] = 0
                return 0
            max_dep = max(depth(d) for d in step["depends_on"] if d < len(steps))
            depths[idx] = max_dep + 1
            return depths[idx]
        
        return max(depth(i) for i in range(len(steps))) if steps else 0
```

**Performance Considerations:**
- Cycle detection is O(V + E) where V = steps, E = dependencies — fast for typical plan sizes (< 50 steps)
- `get_next_executable_steps` scans all steps — acceptable for small plans; optimize with index if plans grow large
- Plan JSON column is loaded entirely into memory for manipulation — acceptable for plan sizes < 100 steps

**Risk Notes:**
- Cycle detection must run before plan creation — prevents infinite loops in execution
- Step index must be validated against plan bounds — prevents index out of range errors

### Task 2: Implement Error Analysis Service

**Architecture:** The ErrorAnalysisService classifies errors, determines root causes via pattern matching against historical errors, and suggests resolutions. Key features:
- **Fingerprinting:** Errors are normalized into fingerprints for pattern matching
- **Pattern detection:** Frequently occurring fingerprints indicate systematic issues
- **Root cause correlation:** Links current error to historical errors with similar fingerprints
- **Resolution suggestions:** Based on what resolved similar past errors

**Implementation:**
```python
# backend/app/services/cognition/error_analysis.py

from typing import Dict, Any, Optional, List, Tuple
from datetime import datetime, timedelta
from sqlalchemy.orm import Session
from sqlalchemy import func
from backend.app.models.cognition.error_analysis import ErrorAnalysis


class ErrorAnalysisService:
    """Error analysis service with pattern matching and root cause determination.
    
    Features:
    - Error classification and fingerprinting
    - Pattern detection across error history
    - Root cause determination via historical correlation
    - Resolution and prevention suggestions
    - Error severity assessment
    
    Usage:
        service = ErrorAnalysisService(db)
        analysis = await service.analyze_error(
            user_id=1, error_type="ValueError",
            error_message="Invalid input: expected int, got str",
            context={"module": "parser", "function": "parse_config", "line": 42}
        )
    """
    
    # Severity classification rules
    SEVERITY_RULES = {
        "critical": ["SecurityError", "DataCorruptionError", "EncryptionError"],
        "error": ["ValueError", "TypeError", "RuntimeError", "IOError"],
        "warning": ["DeprecationWarning", "ResourceWarning", "TimeoutError"],
        "info": ["UserWarning", "SyntaxWarning"],
    }
    
    # Common error pattern → resolution mappings
    RESOLUTION_PATTERNS = {
        "ConnectionError:*timeout": "Check network connectivity; increase timeout; verify server status",
        "FileNotFoundError:*": "Verify file path exists; check permissions; ensure correct working directory",
        "ValueError:*invalid literal": "Validate input format before parsing; add input sanitization",
        "KeyError:*": "Check key exists before access; use .get() with default; validate input structure",
        "PermissionError:*": "Check file/directory permissions; run with appropriate privileges",
        "TimeoutError:*": "Increase timeout value; check for deadlocks; optimize operation",
    }
    
    def __init__(self, db: Session):
        self.db = db
    
    async def analyze_error(self, user_id: int, error_type: str,
                           error_message: str, context: Dict[str, Any]) -> ErrorAnalysis:
        """Analyze an error and determine root cause.
        
        Flow:
        1. Classify severity
        2. Generate fingerprint
        3. Search for similar historical errors
        4. Determine root cause via correlation
        5. Suggest resolution based on patterns
        6. Store analysis
        """
        fingerprint = self._generate_fingerprint(error_type, error_message)
        severity = self._classify_severity(error_type)
        
        # Find similar historical errors
        similar_errors = await self._find_similar_errors(fingerprint, user_id)
        
        # Determine root cause
        root_cause = await self._determine_root_cause(
            error_type, error_message, context, similar_errors
        )
        
        # Suggest resolution
        resolution = await self._suggest_resolution(error_type, error_message, similar_errors)
        
        # Suggest prevention
        prevention = await self._suggest_prevention(error_type, similar_errors)
        
        analysis = ErrorAnalysis(
            user_id=user_id,
            error_type=error_type,
            error_message=error_message,
            fingerprint=fingerprint,
            context=context,
            root_cause=root_cause,
            resolution=resolution,
            prevention=prevention,
            severity=severity,
            created_at=datetime.utcnow(),
        )
        self.db.add(analysis)
        self.db.commit()
        self.db.refresh(analysis)
        return analysis
    
    async def get_error_patterns(self, user_id: int, days: int = 30) -> Dict[str, Any]:
        """Get common error patterns for a user.
        
        Returns:
            {
                "total_errors": int,
                "patterns": [
                    {"fingerprint": str, "count": int, "severity": str, "last_seen": str}
                ],
                "severity_breakdown": {"critical": int, "error": int, "warning": int, "info": int},
                "most_common": str,
                "trend": "increasing" | "decreasing" | "stable"
            }
        """
        since = datetime.utcnow() - timedelta(days=days)
        
        errors = self.db.query(ErrorAnalysis).filter(
            ErrorAnalysis.user_id == user_id,
            ErrorAnalysis.created_at >= since,
        ).all()
        
        # Count by fingerprint
        pattern_counts: Dict[str, List[ErrorAnalysis]] = {}
        severity_counts: Dict[str, int] = {"critical": 0, "error": 0, "warning": 0, "info": 0}
        
        for error in errors:
            fp = error.fingerprint or f"{error.error_type}:unknown"
            if fp not in pattern_counts:
                pattern_counts[fp] = []
            pattern_counts[fp].append(error)
            severity_counts[error.severity] = severity_counts.get(error.severity, 0) + 1
        
        # Build pattern list
        patterns = []
        for fp, error_list in sorted(pattern_counts.items(), key=lambda x: -len(x[1])):
            patterns.append({
                "fingerprint": fp,
                "count": len(error_list),
                "severity": error_list[0].severity,
                "last_seen": max(e.created_at for e in error_list).isoformat(),
                "first_seen": min(e.created_at for e in error_list).isoformat(),
            })
        
        # Calculate trend
        trend = self._calculate_trend(errors)
        
        return {
            "total_errors": len(errors),
            "patterns": patterns,
            "severity_breakdown": severity_counts,
            "most_common": patterns[0]["fingerprint"] if patterns else None,
            "trend": trend,
        }
    
    async def resolve_error(self, analysis_id: int, 
                           resolution_method: str = "manual") -> ErrorAnalysis:
        """Mark an error analysis as resolved."""
        analysis = self.db.query(ErrorAnalysis).filter(
            ErrorAnalysis.id == analysis_id
        ).first()
        if not analysis:
            raise ValueError(f"Analysis {analysis_id} not found")
        
        analysis.resolved = 1
        analysis.resolution_method = resolution_method
        analysis.resolved_at = datetime.utcnow()
        self.db.commit()
        self.db.refresh(analysis)
        return analysis
    
    async def get_analysis(self, analysis_id: int) -> Optional[ErrorAnalysis]:
        """Get an error analysis by ID."""
        return self.db.query(ErrorAnalysis).filter(
            ErrorAnalysis.id == analysis_id
        ).first()
    
    async def get_user_analyses(self, user_id: int, 
                               severity: Optional[str] = None,
                               limit: int = 50) -> List[ErrorAnalysis]:
        """Get error analyses for a user."""
        query = self.db.query(ErrorAnalysis).filter(
            ErrorAnalysis.user_id == user_id
        )
        if severity:
            query = query.filter(ErrorAnalysis.severity == severity)
        return query.order_by(ErrorAnalysis.created_at.desc()).limit(limit).all()
    
    def _generate_fingerprint(self, error_type: str, message: str) -> str:
        """Generate a normalized fingerprint for pattern matching.
        
        Fingerprint format: `{ErrorType}:{normalized_message}`
        Normalized message replaces variable parts with wildcards.
        """
        import re
        # Replace numbers, paths, URLs, UUIDs with wildcards
        normalized = message
        normalized = re.sub(r'\d+', '*', normalized)
        normalized = re.sub(r'[/\\][\w./\\]+', '/*', normalized)
        normalized = re.sub(r'https?://\S+', '*URL*', normalized)
        normalized = re.sub(
            r'[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}',
            '*UUID*', normalized, flags=re.IGNORECASE
        )
        # Truncate
        normalized = normalized[:100]
        return f"{error_type}:{normalized}"
    
    def _classify_severity(self, error_type: str) -> str:
        """Classify error severity based on type."""
        for severity, types in self.SEVERITY_RULES.items():
            if error_type in types:
                return severity
        return "error"  # default
    
    async def _find_similar_errors(self, fingerprint: str, user_id: int,
                                  limit: int = 10) -> List[ErrorAnalysis]:
        """Find historical errors with matching or similar fingerprints."""
        # Exact match first
        exact = self.db.query(ErrorAnalysis).filter(
            ErrorAnalysis.fingerprint == fingerprint,
            ErrorAnalysis.user_id == user_id,
        ).order_by(ErrorAnalysis.created_at.desc()).limit(limit).all()
        
        if len(exact) >= 3:
            return exact
        
        # Partial match (same error type)
        error_type = fingerprint.split(":")[0]
        partial = self.db.query(ErrorAnalysis).filter(
            ErrorAnalysis.error_type == error_type,
            ErrorAnalysis.user_id == user_id,
            ErrorAnalysis.fingerprint != fingerprint,
        ).order_by(ErrorAnalysis.created_at.desc()).limit(limit - len(exact)).all()
        
        return exact + partial
    
    async def _determine_root_cause(self, error_type: str, message: str,
                                   context: Dict[str, Any],
                                   similar_errors: List[ErrorAnalysis]) -> str:
        """Determine root cause via correlation with historical errors."""
        if similar_errors:
            # Find the most common root cause from similar errors
            causes = [e.root_cause for e in similar_errors if e.root_cause]
            if causes:
                from collections import Counter
                most_common = Counter(causes).most_common(1)[0][0]
                return f"Similar to previous errors. Most common root cause: {most_common}"
        
        # Default root cause based on error type
        module = context.get("module", "unknown")
        function = context.get("function", "unknown")
        return f"{error_type} in {module}.{function}: {message[:200]}"
    
    async def _suggest_resolution(self, error_type: str, message: str,
                                 similar_errors: List[ErrorAnalysis]) -> str:
        """Suggest resolution based on error patterns and historical data."""
        # Check resolution patterns
        for pattern, resolution in self.RESOLUTION_PATTERNS.items():
            pattern_type, pattern_msg = pattern.split(":", 1)
            if error_type == pattern_type and (
                pattern_msg == "*" or pattern_msg.lower() in message.lower()
            ):
                return resolution
        
        # Check what resolved similar past errors
        resolved = [e for e in similar_errors if e.resolved and e.resolution]
        if resolved:
            return f"Based on similar past errors: {resolved[0].resolution}"
        
        return f"Manual investigation recommended for {error_type}. Check context: {context}"
    
    async def _suggest_prevention(self, error_type: str,
                                 similar_errors: List[ErrorAnalysis]) -> str:
        """Suggest prevention strategy based on error patterns."""
        unresolved_count = sum(1 for e in similar_errors if not e.resolved)
        
        if unresolved_count > 5:
            return f"This error type has occurred {unresolved_count} times unresolved. Consider adding input validation or error handling in the affected module."
        
        resolved = [e for e in similar_errors if e.prevention]
        if resolved:
            return resolved[0].prevention
        
        return f"Add defensive checks for {error_type} conditions in affected code paths."
    
    def _calculate_trend(self, errors: List[ErrorAnalysis]) -> str:
        """Calculate error trend over time."""
        if len(errors) < 4:
            return "stable"
        
        now = datetime.utcnow()
        recent = sum(1 for e in errors if e.created_at >= now - timedelta(days=7))
        older = sum(1 for e in errors if e.created_at < now - timedelta(days=7))
        
        if recent > older * 1.5:
            return "increasing"
        elif recent < older * 0.5:
            return "decreasing"
        return "stable"
```

## Security Considerations

1. **Error message sanitization:** Error messages may contain sensitive data (paths, tokens). The `_generate_fingerprint` method normalizes but doesn't strip — ensure error messages are sanitized before storage.
2. **Context validation:** Context dict may contain arbitrary data. Validate structure before DB storage (JSON column handles this at DB level).
3. **Pattern matching:** Fingerprint matching is read-only — no risk of injection.
4. **Resolution suggestions:** Based on historical patterns only — no code execution.

## Cross-Domain Integration

- **Memory domain (v1.03):** Plans query memory for context during decomposition; error analysis learns from memory patterns
- **Privacy domain (v1.05):** Plan creation logged to audit trail; error analysis logged to audit trail; access control gates plan creation
- **Execution domain (P04):** Plans drive tool execution; execution results feed back into plan status; errors from execution feed into error analysis
