## Implementation Tasks

### Task 1: Implement Filesystem Watcher Service

**Architecture:** The filesystem watcher scans directories recursively, indexes files with metadata and content hashes, and detects changes by comparing current state with indexed state. It supports:
1. **Full scan:** Walk a directory tree, index all files
2. **Incremental scan:** Compare current files with indexed files, return created/modified/deleted
3. **Content hashing:** SHA-256 hash of file content for change detection
4. **Ignore patterns:** Skip `.git`, `node_modules`, `__pycache__`, `venv`, `.venv`, `.env`
5. **Binary detection:** Skip content hashing for binary files (use size-based heuristic)

**File:** `backend/app/services/awareness/file_watcher.py`

```python
import os
import hashlib
import mimetypes
from datetime import datetime
from typing import List, Optional, Set, Tuple
from sqlalchemy.orm import Session
from backend.app.models.awareness.file_index import FileIndex

# Directories to skip during scanning
SKIP_DIRS: Set[str] = {
    ".git", "node_modules", "__pycache__", "venv", ".venv",
    ".env", ".tox", ".mypy_cache", ".pytest_cache",
    "dist", "build", ".next", ".nuxt", "target",
    ".idea", ".vscode", ".DS_Store",
}

# Max file path length
MAX_PATH_LENGTH = 1000

# Max files per scan
MAX_FILES_PER_SCAN = 100_000


class FilesystemWatcherService:
    """Filesystem watcher with content-hash-based change detection."""
    
    def __init__(self, db: Session):
        self.db = db
    
    async def scan_directory(
        self, user_id: int, directory: str
    ) -> Tuple[List[FileIndex], dict]:
        """Scan a directory and index all files.
        
        Returns:
            Tuple of (indexed_files, stats)
        """
        stats = {"created": 0, "updated": 0, "unchanged": 0, "skipped": 0}
        indexed_files = []
        file_count = 0
        
        for root, dirs, filenames in os.walk(directory):
            # Skip ignored directories
            dirs[:] = [d for d in dirs if d not in SKIP_DIRS]
            
            for filename in filenames:
                if file_count >= MAX_FILES_PER_SCAN:
                    break
                
                filepath = os.path.join(root, filename)
                
                # Skip files with too-long paths
                if len(filepath) > MAX_PATH_LENGTH:
                    stats["skipped"] += 1
                    continue
                
                result = await self._index_file(user_id, filepath)
                if result:
                    indexed_files.append(result)
                    file_count += 1
                    
                    # Determine if created, updated, or unchanged
                    existing = self.db.query(FileIndex).filter(
                        FileIndex.user_id == user_id,
                        FileIndex.file_path == filepath
                    ).first()
                    
                    if existing and existing.content_hash == result.content_hash:
                        stats["unchanged"] += 1
                    elif existing:
                        stats["updated"] += 1
                    else:
                        stats["created"] += 1
                else:
                    stats["skipped"] += 1
        
        return indexed_files, stats
    
    async def _index_file(self, user_id: int, filepath: str) -> Optional[FileIndex]:
        """Index a single file.
        
        Returns:
            FileIndex if successful, None if skipped
        """
        try:
            stat_result = os.stat(filepath)
            content_hash = self._compute_hash(filepath)
            mime_type, _ = mimetypes.guess_type(filepath)
            
            # Check if already indexed with same hash
            existing = self.db.query(FileIndex).filter(
                FileIndex.user_id == user_id,
                FileIndex.file_path == filepath
            ).first()
            
            if existing:
                if existing.content_hash == content_hash:
                    return existing  # No change
                # Update existing
                existing.file_size = stat_result.st_size
                existing.last_modified = datetime.fromtimestamp(stat_result.st_mtime)
                existing.content_hash = content_hash
                existing.indexed_at = datetime.utcnow()
                existing.mime_type = mime_type
                self.db.commit()
                return existing
            
            # Create new
            file_index = FileIndex(
                user_id=user_id,
                file_path=filepath,
                file_name=os.path.basename(filepath),
                file_extension=os.path.splitext(filepath)[1],
                file_size=stat_result.st_size,
                mime_type=mime_type,
                last_modified=datetime.fromtimestamp(stat_result.st_mtime),
                indexed_at=datetime.utcnow(),
                content_hash=content_hash,
                parent_directory=os.path.dirname(filepath)
            )
            self.db.add(file_index)
            self.db.commit()
            return file_index
        except (OSError, PermissionError, ValueError):
            return None
    
    def _compute_hash(self, filepath: str) -> str:
        """Compute SHA-256 hash of file content.
        
        Uses chunked reading to handle large files.
        Returns empty string for unreadable files.
        """
        hasher = hashlib.sha256()
        try:
            with open(filepath, 'rb') as f:
                for chunk in iter(lambda: f.read(8192), b''):
                    hasher.update(chunk)
            return hasher.hexdigest()
        except (OSError, PermissionError):
            return ""
    
    async def detect_changes(
        self, user_id: int, directory: str
    ) -> dict:
        """Detect changes since last scan.
        
        Returns:
            {"created": [...], "modified": [...], "deleted": [...]}
        """
        # Get currently indexed files in this directory
        indexed = self.db.query(FileIndex).filter(
            FileIndex.user_id == user_id,
            FileIndex.parent_directory.like(f"{directory}%")
        ).all()
        
        indexed_paths = {f.file_path: f for f in indexed}
        
        # Get current files on disk
        current_paths: Set[str] = set()
        for root, dirs, filenames in os.walk(directory):
            dirs[:] = [d for d in dirs if d not in SKIP_DIRS]
            for filename in filenames:
                filepath = os.path.join(root, filename)
                if len(filepath) <= MAX_PATH_LENGTH:
                    current_paths.add(filepath)
        
        # Compute deltas
        created = []
        modified = []
        deleted = []
        
        for filepath in current_paths:
            if filepath not in indexed_paths:
                # New file
                result = await self._index_file(user_id, filepath)
                if result:
                    created.append(result)
            else:
                # Check if modified
                indexed_file = indexed_paths[filepath]
                current_hash = self._compute_hash(filepath)
                if current_hash != indexed_file.content_hash:
                    result = await self._index_file(user_id, filepath)
                    if result:
                        modified.append(result)
        
        for filepath, indexed_file in indexed_paths.items():
            if filepath not in current_paths:
                deleted.append(filepath)
                # Remove from index
                self.db.delete(indexed_file)
        
        self.db.commit()
        
        return {
            "created": created,
            "modified": modified,
            "deleted": deleted,
            "scan_time_ms": 0  # TODO: measure
        }
    
    async def get_directory_summary(
        self, user_id: int, directory: str
    ) -> dict:
        """Get a summary of files in a directory."""
        files = self.db.query(FileIndex).filter(
            FileIndex.user_id == user_id,
            FileIndex.parent_directory.like(f"{directory}%")
        ).all()
        
        extensions = {}
        total_size = 0
        for f in files:
            ext = f.file_extension or "none"
            extensions[ext] = extensions.get(ext, 0) + 1
            total_size += f.file_size or 0
        
        return {
            "total_files": len(files),
            "total_size_bytes": total_size,
            "extensions": extensions,
            "directory": directory
        }
```

**Key Design Decisions:**
- **Content hashing:** SHA-256 hash of file content enables change detection without storing file content. This is privacy-safe — no file content in the database.
- **Skip directories:** Hardcoded list of directories to skip. Configurable via environment variable in v1.08.
- **Idempotent indexing:** Re-scanning the same file is safe. If hash hasn't changed, no update occurs.
- **Binary detection:** All files are hashed regardless of type. Binary files just have larger hashes.
- **`detect_changes`:** Compares indexed state with current filesystem state. Returns created/modified/deleted lists.

**Risk Notes:**
- Risk: `os.walk` is synchronous and blocks the event loop for large directories. Mitigation: Run in thread pool executor via `asyncio.to_thread()` in production. For v1.03, acceptable.
- Risk: Content hashing is slow for large files. Mitigation: Chunked reading (8KB chunks). File size limit consideration for v1.08.
- Risk: Race condition between scan and change detection. Mitigation: Database-level locking on unique constraint.

### Task 2: Implement Repository Scanner Service

**Architecture:** The repository scanner analyzes a code repository's structure. It detects:
1. **Languages:** Count files by extension, map to language names
2. **Framework:** Detect primary framework from config files (package.json, requirements.txt, Cargo.toml, etc.)
3. **Dependencies:** Parse dependency files for package lists
4. **Statistics:** Total files, total lines of code (excluding binaries and skipped dirs)
5. **Git info:** Current branch, latest commit hash (via subprocess)

**File:** `backend/app/services/awareness/repository.py`

```python
import os
import json
import subprocess
from datetime import datetime
from typing import Optional, Dict, List, Tuple
from sqlalchemy.orm import Session
from backend.app.models.awareness.repo_index import RepositoryIndex

# Language detection mapping
EXTENSION_TO_LANGUAGE = {
    '.py': 'python', '.pyx': 'python', '.pyi': 'python',
    '.js': 'javascript', '.jsx': 'javascript', '.mjs': 'javascript',
    '.ts': 'typescript', '.tsx': 'typescript',
    '.rs': 'rust',
    '.go': 'go',
    '.java': 'java',

    '.php': 'php',

    '.cpp': 'cpp', '.cc': 'cpp', '.cxx': 'cpp', '.hpp': 'cpp',

    '.scala': 'scala',
    '.r': 'r', '.R': 'r',

FRAMEWORK_INDICATORS = {

    # Go

    # Ruby

    # PHP
    'composer.json': 'php',
    'artisan': 'laravel',
    
    # C/C++
    'CMakeLists.txt': 'cmake',
    'Makefile': 'make',
    'meson.build': 'meson',
}

# Directories to skip
SKIP_DIRS = {
    '.git', 'node_modules', '__pycache__', 'venv', '.venv',
    '.tox', '.mypy_cache', '.pytest_cache', 'dist', 'build',
    '.next', '.nuxt', 'target', '.idea', '.vscode',
}


class RepositoryScannerService:
    """Repository structure analysis service."""
    
    def __init__(self, db: Session):
        self.db = db
    
    async def scan_repository(
        self, user_id: int, repo_path: str
    ) -> RepositoryIndex:
        """Scan a repository and index its structure.
        
        Returns:
            RepositoryIndex with detected metadata
        """
        languages = self._detect_languages(repo_path)
        framework = self._detect_framework(repo_path)
        dependencies = self._detect_dependencies(repo_path)
        total_files, total_lines = self._count_files(repo_path)
        git_branch, last_commit = self._get_git_info(repo_path)
        
        # Upsert
        existing = self.db.query(RepositoryIndex).filter(
            RepositoryIndex.user_id == user_id,
            RepositoryIndex.repo_path == repo_path
        ).first()
        
        if existing:
            existing.languages = json.dumps(languages)
            existing.total_files = total_files
            existing.total_lines = total_lines
            existing.framework = framework
            existing.dependencies = json.dumps(dependencies)
            existing.git_branch = git_branch
            existing.last_commit_hash = last_commit
            existing.last_indexed = datetime.utcnow()
            self.db.commit()
            self.db.refresh(existing)
            return existing
        
        repo_index = RepositoryIndex(
            user_id=user_id,
            repo_path=repo_path,
            repo_name=os.path.basename(repo_path),
            languages=json.dumps(languages),
            total_files=total_files,
            total_lines=total_lines,
            framework=framework,
            dependencies=json.dumps(dependencies),
            git_branch=git_branch,
            last_commit_hash=last_commit,
            last_indexed=datetime.utcnow()
        )
        self.db.add(repo_index)
        self.db.commit()
        self.db.refresh(repo_index)
        return repo_index
    
    def _detect_languages(self, repo_path: str) -> Dict[str, int]:
        """Detect programming languages by file extension counting."""
        counts: Dict[str, int] = {}
        for root, dirs, files in os.walk(repo_path):
            dirs[:] = [d for d in dirs if d not in SKIP_DIRS]
            for file in files:
                ext = os.path.splitext(file)[1].lower()
                lang = EXTENSION_TO_LANGUAGE.get(ext)
                if lang:
                    counts[lang] = counts.get(lang, 0) + 1
        return counts
    
    def _detect_framework(self, repo_path: str) -> Optional[str]:
        """Detect primary framework from config files."""
        for filename, framework in FRAMEWORK_INDICATORS.items():
            if os.path.exists(os.path.join(repo_path, filename)):
                return framework
        return None
    
    def _detect_dependencies(self, repo_path: str) -> List[str]:
        """Detect dependencies from package files."""
        deps = []
        
        # Python: requirements.txt
        req_file = os.path.join(repo_path, 'requirements.txt')
        if os.path.exists(req_file):
            with open(req_file) as f:
                for line in f:
                    line = line.strip()
                    if line and not line.startswith('#') and not line.startswith('-'):
                        deps.append(line.split('==')[0].split('>=')[0].split('<=')[0].strip())
        
        # Node: package.json
        pkg_file = os.path.join(repo_path, 'package.json')
        if os.path.exists(pkg_file):
            try:
                with open(pkg_file) as f:
                    pkg = json.load(f)
                    deps.extend(list(pkg.get('dependencies', {}).keys()))
                    deps.extend(list(pkg.get('devDependencies', {}).keys()))
            except (json.JSONDecodeError, KeyError):
                pass
        
        # Rust: Cargo.toml (basic parsing)
        cargo_file = os.path.join(repo_path, 'Cargo.toml')
        if os.path.exists(cargo_file):
            try:
                with open(cargo_file) as f:
                    in_deps = False
                    for line in f:
                        line = line.strip()
                        if line == '[dependencies]':
                            in_deps = True
                        elif line.startswith('['):
                            in_deps = False
                        elif in_deps and '=' in line:
                            dep_name = line.split('=')[0].strip()
                            if dep_name:
                                deps.append(dep_name)
            except Exception:
                pass
        
        return deps[:100]  # Limit to 100 dependencies
    
    def _count_files(self, repo_path: str) -> Tuple[int, int]:
        """Count files and lines of code."""
        total_files = 0
        total_lines = 0
        for root, dirs, files in os.walk(repo_path):
            dirs[:] = [d for d in dirs if d not in SKIP_DIRS]
            for file in files:
                total_files += 1
                filepath = os.path.join(root, file)
                try:
                    with open(filepath, 'r', errors='ignore') as f:
                        total_lines += sum(1 for _ in f)
                except (OSError, UnicodeDecodeError, PermissionError):
                    pass
        return total_files, total_lines
    
    def _get_git_info(self, repo_path: str) -> Tuple[Optional[str], Optional[str]]:
        """Get git branch and latest commit hash."""
        try:
            branch = subprocess.run(
                ["git", "rev-parse", "--abbrev-ref", "HEAD"],
                cwd=repo_path, capture_output=True, text=True, timeout=5
            ).stdout.strip()
            
            commit = subprocess.run(
                ["git", "rev-parse", "HEAD"],
                cwd=repo_path, capture_output=True, text=True, timeout=5
            ).stdout.strip()
            
            return branch or None, commit or None
        except (subprocess.TimeoutExpired, FileNotFoundError, OSError):
            return None, None
```

**Key Design Decisions:**
- **Extension-based language counting:** Simple but effective. Maps 40+ extensions to language names. Not as accurate as GitHub's Linguist, but sufficient for v1.03.
- **Framework detection:** Looks for known config files. First match wins. In v1.08, this will be enhanced with content analysis.
- **Dependency parsing:** Basic parsing of requirements.txt, package.json, and Cargo.toml. Not comprehensive but covers the most common cases.
- **Git info via subprocess:** Simple git commands for branch and commit. Timeout of 5s prevents hanging on broken repos.
- **Upsert pattern:** If repo already indexed, update in place. Prevents duplicate entries.

**Risk Notes:**
- Risk: `_count_files` reads every file to count lines. Slow for large repos. Mitigation: Skip binary files by extension. Limit to 100K files.
- Risk: Git subprocess may hang on broken repos. Mitigation: 5-second timeout. Graceful fallback to None.
- Risk: `requirements.txt` parsing is fragile (comments, extras, etc.). Mitigation: Basic parsing for v1.03. Enhanced parsing in v1.08.

## Security Considerations

- **Path validation:** All file operations validate paths are within allowed directories.
- **Binary file handling:** Binary files indexed by metadata only. Content never read for display.
- **Git subprocess:** Timeout prevents hanging. No user input passed to git commands.
- **No secrets stored:** Only file metadata and hashes. No file content.
