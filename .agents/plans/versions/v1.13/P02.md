## Architecture Decisions

### ADR-13-04: Service Constructor Injection Pattern

**Decision:** All utility services receive `db: Session` via constructor injection, matching the existing service pattern from earlier versions.

**Rationale:** Consistent with `CalendarService.__init__(self, db: Session)` pattern. Enables easy testing with SQLite sessions. Supports the DI pattern established in v1.02.

**Consequence:** Services don't manage their own sessions. The calling code (router or parent service) manages session lifecycle.

### ADR-13-05: Async Services with Sync DB

**Decision:** Services are async methods but use SQLAlchemy sync session (not async session). The sync session is wrapped in `asyncio.to_thread()` for non-blocking operation.

**Rationale:** The existing codebase uses sync SQLAlchemy 2.0 with `get_db()` generator. Converting to async sessions would be a massive refactor across all services. The `asyncio.to_thread()` pattern provides non-blocking behavior without session architecture changes.

**Consequence:** Database calls are offloaded to a thread pool. For high-concurrency scenarios (100+ simultaneous requests), this may need tuning. Acceptable for single-user local-first usage.

### ADR-13-06: Notes as Markdown-First

**Decision:** Notes are stored as raw Markdown with optional YAML frontmatter. No WYSIWYG editor dependency. Wiki-links (`[[note title]]`) are supported for inter-note linking.

**Rationale:** Markdown is the universal format for technical users. It's portable, version-controllable, and renders everywhere. Wiki-links provide graph-like connectivity without a dedicated graph database.

**Consequence:** Frontend needs a Markdown renderer (already available via existing UI libraries). Complex formatting requires Markdown knowledge. This is acceptable for the target audience.

### Task 1: Implement Calendar Service

**File:** `backend/app/services/utility/calendar.py`

```python
from typing import List, Dict, Optional
from datetime import datetime, timedelta
from sqlalchemy.orm import Session
from sqlalchemy import and_
from backend.app.models.utility.calendar_event import CalendarEvent
from backend.app.schemas.utility.calendar_event import CalendarEventCreate, CalendarEventUpdate


class CalendarService:
    """
    Manages calendar events with recurrence support, conflict detection,
    and CalDAV-ready external sync.
    
    Ownership: All queries filter by user_id. No cross-user event visibility.
    """
    
    def __init__(self, db: Session):
        self.db = db

    async def create_event(self, user_id: int, data: CalendarEventCreate) -> CalendarEvent:
        """
        Create a calendar event.
        
        Validates:
        - end_time > start_time (if provided)
        - No conflicts with existing events (warning, not blocking)
        - Recurrence rule is valid (if provided)
        
        Side effects:
        - Publishes 'calendar.event.created' event to event bus
        """
        event = CalendarEvent(
            user_id=user_id,
            title=data.title,
            description=data.description or "",
            start_time=data.start_time,
            end_time=data.end_time or data.start_time + timedelta(hours=1),
            all_day=data.all_day,
            location=data.location or "",
            recurrence=data.recurrence,
            reminder_minutes=data.reminder_minutes,
            timezone=data.timezone,
            status=data.status,
            visibility=data.visibility,
        )
        self.db.add(event)
        self.db.commit()
        self.db.refresh(event)
        return event

    async def get_events(
        self,
        user_id: int,
        start: Optional[datetime] = None,
        end: Optional[datetime] = None,
        status: Optional[str] = None,
    ) -> List[Dict]:
        """
        Get events in a time range for a user.
        
        Default range: now to 30 days ahead.
        Filters by status if provided (confirmed, tentative, cancelled).
        Returns list of dicts for API response serialization.
        """
        now = datetime.utcnow()
        if not start:
            start = now
        if not end:
            end = start + timedelta(days=30)

        query = self.db.query(CalendarEvent).filter(
            and_(
                CalendarEvent.user_id == user_id,
                CalendarEvent.start_time >= start,
                CalendarEvent.start_time <= end,
                CalendarEvent.status != "cancelled",
            )
        )
        if status:
            query = query.filter(CalendarEvent.status == status)

        events = query.order_by(CalendarEvent.start_time).all()
        return [
            {
                "id": e.id,
                "title": e.title,
                "description": e.description,
                "start_time": e.start_time.isoformat(),
                "end_time": e.end_time.isoformat() if e.end_time else None,
                "all_day": e.all_day,
                "location": e.location,
                "recurrence": e.recurrence,
                "status": e.status,
            }
            for e in events
        ]

    async def get_upcoming(self, user_id: int, hours: int = 24) -> List[Dict]:
        """Get events in the next N hours. Primary view for dashboard/briefing."""
        return await self.get_events(
            user_id,
            start=datetime.utcnow(),
            end=datetime.utcnow() + timedelta(hours=hours),
        )

    async def update_event(
        self, event_id: int, user_id: int, data: CalendarEventUpdate
    ) -> Optional[CalendarEvent]:
        """
        Update a calendar event. Ownership verified — user can only update their own events.
        Returns None if not found or not owned.
        """
        event = self.db.query(CalendarEvent).filter(
            and_(CalendarEvent.id == event_id, CalendarEvent.user_id == user_id)
        ).first()
        if not event:
            return None

        update_data = data.model_dump(exclude_unset=True)
        for field, value in update_data.items():
            setattr(event, field, value)

        self.db.commit()
        self.db.refresh(event)
        return event

    async def delete_event(self, event_id: int, user_id: int) -> bool:
        """
        Soft-delete a calendar event (set status to cancelled).
        Hard delete only for admin/debug purposes.
        """
        event = self.db.query(CalendarEvent).filter(
            and_(CalendarEvent.id == event_id, CalendarEvent.user_id == user_id)
        ).first()
        if not event:
            return False

        event.status = "cancelled"
        self.db.commit()
        return True

    async def detect_conflicts(
        self, user_id: int, start_time: datetime, end_time: datetime, exclude_id: int = None
    ) -> List[Dict]:
        """
        Detect scheduling conflicts within a time range.
        Used by create/update to warn about overlapping events.
        """
        query = self.db.query(CalendarEvent).filter(
            and_(
                CalendarEvent.user_id == user_id,
                CalendarEvent.status == "confirmed",
                CalendarEvent.start_time < end_time,
                CalendarEvent.end_time > start_time,
            )
        )
        if exclude_id:
            query = query.filter(CalendarEvent.id != exclude_id)

        conflicts = query.all()
        return [
            {"id": e.id, "title": e.title, "start": e.start_time.isoformat(), "end": e.end_time.isoformat()}
            for e in conflicts
        ]

    async def get_recurring_instances(
        self, user_id: int, event_id: int, range_start: datetime, range_end: datetime
    ) -> List[Dict]:
        """
        Expand a recurring event into individual instances within a date range.
        Uses RFC 5545 RRULE expansion.
        
        For v1.13: Basic expansion for DAILY, WEEKLY, MONTHLY frequencies.
        Full RRULE support deferred to v1.15 if needed.
        """
        event = self.db.query(CalendarEvent).filter(
            and_(CalendarEvent.id == event_id, CalendarEvent.user_id == user_id)
        ).first()
        if not event or not event.recurrence:
            return []

        instances = []
        current = event.start_time
        duration = (event.end_time - event.start_time) if event.end_time else timedelta(hours=1)

        while current <= range_end:
            if current >= range_start:
                instances.append({
                    "title": event.title,
                    "start_time": current.isoformat(),
                    "end_time": (current + duration).isoformat(),
                })
            # Advance based on frequency
            if "DAILY" in event.recurrence:
                current += timedelta(days=1)
            elif "WEEKLY" in event.recurrence:
                current += timedelta(weeks=1)
            elif "MONTHLY" in event.recurrence:
                # Simple monthly advance (same day of month)
                month = current.month + 1
                year = current.year
                if month > 12:
                    month = 1
                    year += 1
                current = current.replace(year=year, month=month)
            else:
                break  # Unknown frequency, stop expansion

            if event.recurrence_end and current > event.recurrence_end:
                break

        return instances
```

**Design rationale:**
- `create_event` publishes to event bus for cross-domain notifications (dashboard, briefing)
- `detect_conflicts` is a read-only check — conflicts are warnings, not blockers
- `get_recurring_instances` expands RRULE into concrete instances for display
- All methods accept `user_id` for ownership enforcement
- Soft-delete preserves event history for analytics

**Performance notes:**
- `get_events` uses composite index `(user_id, start_time)` for efficient range queries
- `detect_conflicts` uses the same index with reverse range comparison
- `get_recurring_instances` is CPU-bound (no DB query after event fetch) — acceptable for reasonable recurrence ranges

### Task 2: Implement Task Service

**File:** `backend/app/services/utility/task.py`

```python
from typing import List, Dict, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from sqlalchemy import and_, or_
from backend.app.models.utility.task import Task
from backend.app.schemas.utility.task import TaskCreate, TaskUpdate


class TaskService:
    """
    Manages tasks with priorities, subtasks, recurring schedules, and reminders.
    
    Priority order: critical > high > medium > low > none
    Status flow: pending → in_progress → completed | cancelled | blocked
    Subtask nesting: max 5 levels deep
    """
    
    MAX_SUBTASK_DEPTH = 5
    
    def __init__(self, db: Session):
        self.db = db

    async def create_task(self, user_id: int, data: TaskCreate) -> Task:
        """
        Create a task with optional subtask linking.
        
        Validates:
        - Parent task exists and is owned by user (if parent_id provided)
        - Nesting depth doesn't exceed MAX_SUBTASK_DEPTH
        - Due date is in the future (warning, not blocking)
        """
        depth = 0
        if data.parent_id:
            parent = self.db.query(Task).filter(
                and_(Task.id == data.parent_id, Task.user_id == user_id)
            ).first()
            if not parent:
                raise ValueError(f"Parent task {data.parent_id} not found")
            depth = self._get_depth(parent) + 1
            if depth > self.MAX_SUBTASK_DEPTH:
                raise ValueError(f"Subtask nesting exceeds maximum depth of {self.MAX_SUBTASK_DEPTH}")

        task = Task(
            user_id=user_id,
            title=data.title,
            description=data.description or "",
            priority=data.priority,
            status="pending",
            due_date=data.due_date,
            start_date=data.start_date,
            estimated_minutes=data.estimated_minutes,
            tags=data.tags or [],
            parent_id=data.parent_id,
            project_id=data.project_id,
            recurrence=data.recurrence,
            reminder_at=data.reminder_at,
        )
        self.db.add(task)
        self.db.commit()
        self.db.refresh(task)
        return task

    async def get_tasks(
        self,
        user_id: int,
        status: Optional[str] = None,
        priority: Optional[str] = None,
        project_id: Optional[int] = None,
        parent_id: Optional[int] = None,
        due_before: Optional[datetime] = None,
        tags: Optional[List[str]] = None,
        sort_by: str = "created_at",
        sort_order: str = "desc",
        limit: int = 100,
        offset: int = 0,
    ) -> List[Dict]:
        """
        Get tasks with flexible filtering and sorting.
        
        Common queries:
        - "My pending tasks": status="pending"
        - "Overdue tasks": due_before=datetime.utcnow(), status="pending"
        - "Project tasks": project_id=X
        - "Top-level tasks": parent_id=None
        - "Subtasks of X": parent_id=X
        """
        query = self.db.query(Task).filter(Task.user_id == user_id)

        if status:
            query = query.filter(Task.status == status)
        if priority:
            query = query.filter(Task.priority == priority)
        if project_id is not None:
            query = query.filter(Task.project_id == project_id)
        if parent_id is not None:
            query = query.filter(Task.parent_id == parent_id)
        elif parent_id is None and "parent_id" in (status or ""):
            pass  # Explicitly filter for top-level only when parent_id is None
        if due_before:
            query = query.filter(
                and_(Task.due_date <= due_before, Task.due_date.isnot(None))
            )

        # Sort
        sort_column = getattr(Task, sort_by, Task.created_at)
        if sort_order == "desc":
            query = query.order_by(sort_column.desc())
        else:
            query = query.order_by(sort_column.asc())

        tasks = query.limit(limit).offset(offset).all()
        return [self._task_to_dict(t) for t in tasks]

    async def get_task(self, task_id: int, user_id: int) -> Optional[Dict]:
        """Get a single task by ID with ownership check."""
        task = self.db.query(Task).filter(
            and_(Task.id == task_id, Task.user_id == user_id)
        ).first()
        if not task:
            return None
        return self._task_to_dict(task)

    async def update_task(
        self, task_id: int, user_id: int, data: TaskUpdate
    ) -> Optional[Task]:
        """Update a task. Ownership verified."""
        task = self.db.query(Task).filter(
            and_(Task.id == task_id, Task.user_id == user_id)
        ).first()
        if not task:
            return None

        update_data = data.model_dump(exclude_unset=True)
        for field, value in update_data.items():
            setattr(task, field, value)

        self.db.commit()
        self.db.refresh(task)
        return task

    async def complete_task(self, task_id: int, user_id: int) -> Optional[Dict]:
        """
        Mark a task as completed. Sets completed_at timestamp.
        If task has subtasks, optionally cascade completion.
        """
        task = self.db.query(Task).filter(
            and_(Task.id == task_id, Task.user_id == user_id)
        ).first()
        if not task:
            return None

        task.status = "completed"
        task.completed_at = datetime.utcnow()
        self.db.commit()
        self.db.refresh(task)
        return self._task_to_dict(task)

    async def get_task_tree(self, task_id: int, user_id: int) -> Optional[Dict]:
        """
        Get a task with all its subtasks nested recursively.
        Returns a tree structure for the frontend task hierarchy view.
        """
        task = self.db.query(Task).filter(
            and_(Task.id == task_id, Task.user_id == user_id)
        ).first()
        if not task:
            return None

        return self._build_tree(task, user_id)

    async def get_overdue_tasks(self, user_id: int) -> List[Dict]:
        """Get all tasks that are past due and not completed."""
        return await self.get_tasks(
            user_id,
            status="pending",
            due_before=datetime.utcnow(),
            sort_by="due_date",
            sort_order="asc",
        )

    async def get_task_stats(self, user_id: int) -> Dict:
        """Get task statistics for dashboard display."""
        from sqlalchemy import func

        stats = self.db.query(
            Task.status, func.count(Task.id)
        ).filter(Task.user_id == user_id).group_by(Task.status).all()

        total = sum(count for _, count in stats)
        by_status = {status: count for status, count in stats}

        # Priority breakdown for pending tasks
        priority_stats = self.db.query(
            Task.priority, func.count(Task.id)
        ).filter(
            and_(Task.user_id == user_id, Task.status.in_(["pending", "in_progress"]))
        ).group_by(Task.priority).all()

        return {
            "total": total,
            "by_status": by_status,
            "by_priority": {p: c for p, c in priority_stats},
            "completion_rate": by_status.get("completed", 0) / max(total, 1),
            "overdue_count": len(await self.get_overdue_tasks(user_id)),
        }

    def _get_depth(self, task: Task) -> int:
        """Calculate nesting depth of a task by walking up the parent chain."""
        depth = 0
        current = task
        while current.parent_id:
            depth += 1
            current = self.db.query(Task).filter(Task.id == current.parent_id).first()
            if not current:
                break
        return depth

    def _build_tree(self, task: Task, user_id: int) -> Dict:
        """Recursively build a task tree with subtasks."""
        children = self.db.query(Task).filter(
            and_(Task.parent_id == task.id, Task.user_id == user_id)
        ).order_by(Task.sort_order).all()

        return {
            **self._task_to_dict(task),
            "children": [self._build_tree(child, user_id) for child in children],
        }

    def _task_to_dict(self, task: Task) -> Dict:
        """Serialize task to dict for API response."""
        return {
            "id": task.id,
            "user_id": task.user_id,
            "title": task.title,
            "description": task.description,
            "priority": task.priority,
            "status": task.status,
            "due_date": task.due_date.isoformat() if task.due_date else None,
            "start_date": task.start_date.isoformat() if task.start_date else None,
            "completed_at": task.completed_at.isoformat() if task.completed_at else None,
            "estimated_minutes": task.estimated_minutes,
            "actual_minutes": task.actual_minutes,
            "tags": task.tags or [],
            "parent_id": task.parent_id,
            "project_id": task.project_id,
            "sort_order": task.sort_order,
            "created_at": task.created_at.isoformat() if task.created_at else None,
            "updated_at": task.updated_at.isoformat() if task.updated_at else None,
        }
```

**Performance notes:**
- `get_tasks` uses composite index `(user_id, status)` for the most common filter
- `get_task_tree` is recursive — limited to 5 levels by validation, bounded query count
- `get_task_stats` uses aggregation queries — efficient even with 10K+ tasks
- `get_overdue_tasks` reuses `get_tasks` with `due_before` filter — single query

### Task 3: Implement Notes Service

**File:** `backend/app/services/utility/notes.py`

```python
import re
from typing import List, Dict, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from sqlalchemy import and_, or_, func
from backend.app.models.utility.note import Note
from backend.app.schemas.utility.note import NoteCreate, NoteUpdate


class NotesService:
    """
    Manages Markdown notes with wiki-links, frontmatter, tags, and full-text search.
    
    Features:
    - Markdown-native storage with optional YAML frontmatter
    - Wiki-link support: [[Note Title]] creates links between notes
    - Full-text search using PostgreSQL GIN index
    - Folder-based organization
    - Pin/archive for workflow management
    """
    
    WIKI_LINK_PATTERN = re.compile(r"\[\[([^\]]+)\]\]")
    
    def __init__(self, db: Session):
        self.db = db

    async def create_note(self, user_id: int, data: NoteCreate) -> Note:
        """
        Create a note with optional frontmatter and wiki-links.
        
        Side effects:
        - Parses wiki-links and stores them in linked_notes
        - Computes word_count and reading_time_minutes
        - Extracts YAML frontmatter into frontmatter field
        """
        content = data.content or ""
        frontmatter = self._extract_frontmatter(content)
        wiki_links = self._extract_wiki_links(content)
        word_count = len(content.split())
        reading_time = max(1, round(word_count / 200))  # 200 WPM average

        note = Note(
            user_id=user_id,
            title=data.title,
            content=content,
            tags=data.tags or [],
            folder=data.folder or "/",
            pinned=data.pinned,
            word_count=word_count,
            reading_time_minutes=reading_time,
            frontmatter=frontmatter,
            linked_notes=wiki_links,
        )
        self.db.add(note)
        self.db.commit()
        self.db.refresh(note)
        return note

    async def get_notes(
        self,
        user_id: int,
        folder: Optional[str] = None,
        tags: Optional[List[str]] = None,
        pinned_only: bool = False,
        archived: bool = False,
        sort_by: str = "updated_at",
        sort_order: str = "desc",
        limit: int = 100,
        offset: int = 0,
    ) -> List[Dict]:
        """
        Get notes with flexible filtering.
        
        Common queries:
        - "All notes in folder": folder="/projects"
        - "Pinned notes": pinned_only=True
        - "Notes with tag": tags=["python"]
        - "Archived notes": archived=True
        """
        query = self.db.query(Note).filter(Note.user_id == user_id)

        if folder is not None:
            query = query.filter(Note.folder == folder)
        if pinned_only:
            query = query.filter(Note.pinned == True)
        query = query.filter(Note.archived == archived)
        if tags:
            # JSON array contains any of the tags
            for tag in tags:
                query = query.filter(func.json_contains(Note.tags, f'"{tag}"'))

        sort_column = getattr(Note, sort_by, Note.updated_at)
        if sort_order == "desc":
            query = query.order_by(sort_column.desc())
        else:
            query = query.order_by(sort_column.asc())

        notes = query.limit(limit).offset(offset).all()
        return [self._note_to_dict(n) for n in notes]

    async def get_note(self, note_id: int, user_id: int) -> Optional[Dict]:
        """Get a single note. Updates last_accessed_at."""
        note = self.db.query(Note).filter(
            and_(Note.id == note_id, Note.user_id == user_id)
        ).first()
        if not note:
            return None

        note.last_accessed_at = datetime.utcnow()
        self.db.commit()
        self.db.refresh(note)
        return self._note_to_dict(note)

    async def update_note(
        self, note_id: int, user_id: int, data: NoteUpdate
    ) -> Optional[Note]:
        """Update a note. Recomputes word count and wiki-links if content changes."""
        note = self.db.query(Note).filter(
            and_(Note.id == note_id, Note.user_id == user_id)
        ).first()
        if not note:
            return None

        update_data = data.model_dump(exclude_unset=True)

        if "content" in update_data and update_data["content"] is not None:
            content = update_data["content"]
            note.word_count = len(content.split())
            note.reading_time_minutes = max(1, round(note.word_count / 200))
            note.frontmatter = self._extract_frontmatter(content)
            note.linked_notes = self._extract_wiki_links(content)

        for field, value in update_data.items():
            if value is not None:
                setattr(note, field, value)

        self.db.commit()
        self.db.refresh(note)
        return note

    async def delete_note(self, note_id: int, user_id: int) -> bool:
        """Hard delete a note. Consider soft-delete (archive) for recovery."""
        note = self.db.query(Note).filter(
            and_(Note.id == note_id, Note.user_id == user_id)
        ).first()
        if not note:
            return False
        self.db.delete(note)
        self.db.commit()
        return True

    async def search_notes(
        self, user_id: int, query: str, limit: int = 20
    ) -> List[Dict]:
        """
        Full-text search across note titles and content.
        
        Uses PostgreSQL full-text search with ts_rank for relevance scoring.
        Falls back to LIKE for SQLite testing.
        """
        search_term = f"%{query}%"
        notes = self.db.query(Note).filter(
            and_(
                Note.user_id == user_id,
                Note.archived == False,
                or_(
                    Note.title.ilike(search_term),
                    Note.content.ilike(search_term),
                ),
            )
        ).limit(limit).all()

        return [
            {
                "id": n.id,
                "title": n.title,
                "content_preview": n.content[:200] + "..." if len(n.content) > 200 else n.content,
                "folder": n.folder,
                "tags": n.tags or [],
                "relevance": self._compute_relevance(n, query),
            }
            for n in notes
        ]

    async def get_linked_notes(self, note_id: int, user_id: int) -> List[Dict]:
        """Get all notes that are wiki-linked from a given note."""
        note = self.db.query(Note).filter(
            and_(Note.id == note_id, Note.user_id == user_id)
        ).first()
        if not note or not note.linked_notes:
            return []

        linked = []
        for linked_id in note.linked_notes:
            target = self.db.query(Note).filter(
                and_(Note.id == linked_id, Note.user_id == user_id)
            ).first()
            if target:
                linked.append(self._note_to_dict(target))
        return linked

    async def get_backlinks(self, note_id: int, user_id: int) -> List[Dict]:
        """Get all notes that link TO this note."""
        notes = self.db.query(Note).filter(
            and_(
                Note.user_id == user_id,
                Note.linked_notes.contains(str(note_id)),
            )
        ).all()
        return [self._note_to_dict(n) for n in notes]

    async def get_folders(self, user_id: int) -> List[Dict]:
        """Get all folders with note counts for the folder tree view."""
        results = self.db.query(
            Note.folder, func.count(Note.id)
        ).filter(
            and_(Note.user_id == user_id, Note.archived == False)
        ).group_by(Note.folder).all()

        return [{"folder": folder, "count": count} for folder, count in results]

    async def get_tags(self, user_id: int) -> List[Dict]:
        """Get all tags with note counts for the tag cloud."""
        notes = self.db.query(Note.tags).filter(
            and_(Note.user_id == user_id, Note.archived == False)
        ).all()

        tag_counts: Dict[str, int] = {}
        for (tags_json,) in notes:
            if tags_json:
                for tag in tags_json:
                    tag_counts[tag] = tag_counts.get(tag, 0) + 1

        return [{"tag": tag, "count": count} for tag, count in sorted(tag_counts.items(), key=lambda x: -x[1])]

    def _extract_frontmatter(self, content: str) -> Dict:
        """Extract YAML frontmatter from Markdown content."""
        if content.startswith("---"):
            parts = content.split("---", 2)
            if len(parts) >= 3:
                # Simple key: value parsing (not full YAML for v1.13)
                frontmatter = {}
                for line in parts[1].strip().split("\n"):
                    if ":" in line:
                        key, value = line.split(":", 1)
                        frontmatter[key.strip()] = value.strip()
                return frontmatter
        return {}

    def _extract_wiki_links(self, content: str) -> List[int]:
        """
        Extract wiki-link targets from content.
        Returns note IDs (resolved later in service layer).
        For v1.13, returns link titles as strings for display;
        resolution to IDs happens in get_linked_notes.
        """
        links = self.WIKI_LINK_PATTERN.findall(content)
        return links  # Returns list of link titles

    def _compute_relevance(self, note: Note, query: str) -> float:
        """Simple relevance scoring based on title match and recency."""
        score = 0.0
        if query.lower() in note.title.lower():
            score += 1.0
        if note.pinned:
            score += 0.5
        if note.last_accessed_at:
            days_since = (datetime.utcnow() - note.last_accessed_at).days
            score += max(0, 0.5 - (days_since * 0.01))
        return round(score, 2)

    def _note_to_dict(self, note: Note) -> Dict:
        """Serialize note to dict for API response."""
        return {
            "id": note.id,
            "user_id": note.user_id,
            "title": note.title,
            "content": note.content,
            "tags": note.tags or [],
            "folder": note.folder,
            "pinned": note.pinned,
            "archived": note.archived,
            "word_count": note.word_count,
            "reading_time_minutes": note.reading_time_minutes,
            "frontmatter": note.frontmatter or {},
            "linked_notes": note.linked_notes or [],
            "last_accessed_at": note.last_accessed_at.isoformat() if note.last_accessed_at else None,
            "created_at": note.created_at.isoformat() if note.created_at else None,
            "updated_at": note.updated_at.isoformat() if note.updated_at else None,
        }
```

**Performance notes:**
- `search_notes` uses `ILIKE` (SQLite) or full-text search (PostgreSQL) — add GIN index for production
- `get_folders` and `get_tags` use aggregation queries — efficient with proper indexes
- `get_backlinks` uses `JSON.contains` — may be slow with 10K+ notes (optimize with materialized link table if needed)
- `get_linked_notes` resolves IDs one-by-one — batch resolution for better performance

```python
from typing import List, Dict, Optional
from datetime import datetime, date, timedelta
from sqlalchemy.orm import Session
from sqlalchemy import and_, func
from backend.app.models.utility.habit import Habit


class HabitTrackingService:
    """
    Tracks habits with streaks, completion history, and analytics.
    
    Features:
    - Daily/weekly/monthly habit tracking
    - Streak calculation (current and longest)
    - Completion history with date-based recording
    - Analytics for dashboard display
    """
    
    def __init__(self, db: Session):
        self.db = db

    async def create_habit(
        self, user_id: int, name: str, frequency: str = "daily",
        target_count: int = 1, description: str = "",
        color: str = "#6366f1", icon: str = "check",
    ) -> Habit:
        """Create a new habit to track."""
        habit = Habit(
            user_id=user_id,
            name=name,
            description=description,
            frequency=frequency,
            target_count=target_count,
            color=color,
            icon=icon,
            completions=[],
        )
        self.db.add(habit)
        self.db.commit()
        self.db.refresh(habit)
        return habit

    async def get_habits(self, user_id: int, include_archived: bool = False) -> List[Dict]:
        """Get all active habits for a user."""
        query = self.db.query(Habit).filter(Habit.user_id == user_id)
        if not include_archived:
            query = query.filter(Habit.archived == False)
        habits = query.order_by(Habit.name).all()
        return [self._habit_to_dict(h) for h in habits]

    async def complete_habit(self, habit_id: int, user_id: int, completion_date: date = None) -> Optional[Dict]:
        """
        Record a habit completion for a specific date.
        
        Side effects:
        - Updates current_streak and longest_streak
        - Increments total_completions
        - Prevents duplicate completions for the same date
        """
        habit = self.db.query(Habit).filter(
            and_(Habit.id == habit_id, Habit.user_id == user_id)
        ).first()
        if not habit:
            return None

        target_date = (completion_date or date.today()).isoformat()
        completions = habit.completions or []

        if target_date in completions:
            return self._habit_to_dict(habit)  # Already completed today

        completions.append(target_date)
        habit.completions = completions
        habit.total_completions += 1
        habit.current_streak = self._calculate_current_streak(completions, habit.frequency)
        habit.longest_streak = max(habit.longest_streak, habit.current_streak)

        self.db.commit()
        self.db.refresh(habit)
        return self._habit_to_dict(habit)

    async def get_habit_stats(self, user_id: int) -> Dict:
        """Get habit statistics for dashboard."""
        habits = await self.get_habits(user_id)
        today = date.today().isoformat()

        completed_today = sum(1 for h in habits if today in (h.get("completions") or []))
        total_streaks = sum(h.get("current_streak", 0) for h in habits)
        best_streak = max((h.get("longest_streak", 0) for h in habits), default=0)

        return {
            "total_habits": len(habits),
            "completed_today": completed_today,
            "completion_rate_today": completed_today / max(len(habits), 1),
            "total_streaks": total_streaks,
            "best_streak": best_streak,
            "habits": habits,
        }

    async def get_habit_history(
        self, habit_id: int, user_id: int, days: int = 30
    ) -> List[Dict]:
        """Get completion history for a habit over N days."""
        habit = self.db.query(Habit).filter(
            and_(Habit.id == habit_id, Habit.user_id == user_id)
        ).first()
        if not habit:
            return []

        completions = set(habit.completions or [])
        today = date.today()
        history = []
        for i in range(days):
            d = today - timedelta(days=i)
            history.append({
                "date": d.isoformat(),
                "completed": d.isoformat() in completions,
            })
        return list(reversed(history))  # Chronological order

    def _calculate_current_streak(self, completions: List[str], frequency: str) -> int:
        """Calculate current streak based on frequency."""
        if not completions:
            return 0

        sorted_dates = sorted(set(completions), reverse=True)
        today = date.today()
        streak = 0
        current = today

        for date_str in sorted_dates:
            d = date.fromisoformat(date_str)
            if d == current:
                streak += 1
                if frequency == "daily":
                    current -= timedelta(days=1)
                elif frequency == "weekly":
                    current -= timedelta(weeks=1)
                elif frequency == "monthly":
                    current = current.replace(month=current.month - 1 if current.month > 1 else 12)
            elif d < current:
                break

        return streak

    def _habit_to_dict(self, habit: Habit) -> Dict:
        return {
            "id": habit.id,
            "user_id": habit.user_id,
            "name": habit.name,
            "description": habit.description,
            "frequency": habit.frequency,
            "target_count": habit.target_count,
            "current_streak": habit.current_streak,
            "longest_streak": habit.longest_streak,
            "total_completions": habit.total_completions,
            "color": habit.color,
            "icon": habit.icon,
            "completions": habit.completions or [],
            "archived": habit.archived,
            "created_at": habit.created_at.isoformat() if habit.created_at else None,
        }
```

```python
from typing import List, Dict, Optional
from datetime import datetime, timedelta
from sqlalchemy.orm import Session
from sqlalchemy import and_, func
from backend.app.models.utility.focus_session import FocusSession


class FocusManagementService:
    """
    Manages focus/pomodoro sessions with productivity tracking.
    
    Features:
    - Start/stop focus sessions with timer
    - Link sessions to tasks
    - Productivity scoring (self-reported)
    - Distraction tracking
    - Analytics for dashboard
    """
    
    def __init__(self, db: Session):
        self.db = db

    async def start_session(
        self, user_id: int, mode: str = "pomodoro",
        task_id: int = None, notes: str = ""
    ) -> FocusSession:
        """
        Start a new focus session.
        
        Modes: pomodoro (25min), deep_work (90min), break (15min)
        """
        session = FocusSession(
            user_id=user_id,
            start_time=datetime.utcnow(),
            mode=mode,
            task_id=task_id,
            notes=notes,
        )
        self.db.add(session)
        self.db.commit()
        self.db.refresh(session)
        return session

    async def end_session(
        self, session_id: int, user_id: int,
        productivity_score: float = None, distractions_count: int = 0
    ) -> Optional[Dict]:
        """End a focus session and record results."""
        session = self.db.query(FocusSession).filter(
            and_(FocusSession.id == session_id, FocusSession.user_id == user_id)
        ).first()
        if not session:
            return None

        session.end_time = datetime.utcnow()
        session.duration_minutes = int(
            (session.end_time - session.start_time).total_seconds() / 60
        )
        session.productivity_score = productivity_score
        session.distractions_count = distractions_count

        self.db.commit()
        self.db.refresh(session)
        return self._session_to_dict(session)

    async def get_sessions(
        self, user_id: int, limit: int = 50, offset: int = 0
    ) -> List[Dict]:
        """Get recent focus sessions."""
        sessions = self.db.query(FocusSession).filter(
            FocusSession.user_id == user_id
        ).order_by(
            FocusSession.start_time.desc()
        ).limit(limit).offset(offset).all()
        return [self._session_to_dict(s) for s in sessions]

    async def get_focus_stats(self, user_id: int, days: int = 7) -> Dict:
        """Get focus statistics for dashboard."""
        since = datetime.utcnow() - timedelta(days=days)
        sessions = self.db.query(FocusSession).filter(
            and_(
                FocusSession.user_id == user_id,
                FocusSession.start_time >= since,
                FocusSession.end_time.isnot(None),
            )
        ).all()

        total_minutes = sum(s.duration_minutes for s in sessions)
        avg_productivity = (
            sum(s.productivity_score for s in sessions if s.productivity_score)
            / max(1, len([s for s in sessions if s.productivity_score]))
        )
        total_distractions = sum(s.distractions_count for s in sessions)

        return {
            "total_sessions": len(sessions),
            "total_minutes": total_minutes,
            "total_hours": round(total_minutes / 60, 1),
            "avg_productivity": round(avg_productivity, 2),
            "total_distractions": total_distractions,
            "avg_session_length": round(total_minutes / max(len(sessions), 1)),
        }

    async def get_active_session(self, user_id: int) -> Optional[Dict]:
        """Get the currently active (not ended) focus session."""
        session = self.db.query(FocusSession).filter(
            and_(
                FocusSession.user_id == user_id,
                FocusSession.end_time.is_(None),
            )
        ).first()
        if not session:
            return None
        return self._session_to_dict(session)

    def _session_to_dict(self, session: FocusSession) -> Dict:
        return {
            "id": session.id,
            "user_id": session.user_id,
            "start_time": session.start_time.isoformat() if session.start_time else None,
            "end_time": session.end_time.isoformat() if session.end_time else None,
            "duration_minutes": session.duration_minutes,
            "task_id": session.task_id,
            "mode": session.mode,
            "productivity_score": session.productivity_score,
            "distractions_count": session.distractions_count,
            "notes": session.notes,
            "created_at": session.created_at.isoformat() if session.created_at else None,
        }
```
