## Architecture Decisions

### ADR-13-07: Email Processing Without IMAP in v1.13

**Decision:** EmailProcessingService processes emails that are imported/synced into the database. It does NOT implement IMAP/SMTP directly in v1.13. Real email connectivity is deferred to v1.15 (or handled by an extension).

**Rationale:** IMAP/SMTP requires OAuth flows, credential management, and network dependencies that conflict with the local-first principle for the initial release. The service processes email data regardless of source.

**Consequence:** Users import emails via data portability (P04) or extensions (P05). The processing logic (categorization, summarization, action detection) works on any email data in the database.

### ADR-13-08: Document Storage Strategy

**Decision:** Documents are stored in the filesystem with metadata in the database. The `file_path` in the Document model points to the actual file. For sensitive documents, files are stored in the Fernet-encrypted vault.

**Rationale:** Storing large binary files in PostgreSQL is inefficient. Filesystem storage with database metadata is the standard pattern. The vault provides encryption at rest.

**Consequence:** File paths must be validated for security (no path traversal). Cleanup must handle both database and filesystem. Backup must include both database and filesystem.

### ADR-13-09: Contact Entity Linking

**Decision:** Contacts are linked to other entities (tasks, emails, calendar events) via `linked_entities` JSON field. This is a flexible, denormalized approach.

**Rationale:** Explicit join tables for every entity type would be overkill for v1.13. JSON field allows linking to any entity type without schema changes. The trade-off is no referential integrity at the database level.

**Consequence:** Entity linking is validated at the service level. Orphaned links (deleted entities) are handled gracefully by filtering in the service layer. A dedicated link table may replace this in v1.15 if performance requires it.

```python
from typing import List, Dict, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from sqlalchemy import and_, or_, func
from backend.app.models.utility.email_message import EmailMessage


class EmailProcessingService:
    """
    Processes emails with AI-powered categorization, summarization, and action detection.
    
    Features:
    - Email categorization (meeting, action, update, notification, general)
    - Summarization (extract key points)
    - Action required detection (keyword + pattern analysis)
    - Thread grouping
    - Priority scoring
    - Search across email content
    """
    
    # Category keyword mappings
    CATEGORY_KEYWORDS = {
        "meeting": ["meeting", "calendar", "schedule", "invite", "agenda", "conference", "zoom", "teams"],
        "action": ["action required", "please", "urgent", "deadline", "asap", "todo", "follow up", "respond"],
        "update": ["update", "newsletter", "announcement", "digest", "summary", "report"],
        "notification": ["notification", "alert", "warning", "error", "failed", "reminder"],
    }
    
    # Priority signal words
    URGENT_WORDS = ["urgent", "asap", "critical", "emergency", "immediately", "deadline today"]
    
    def __init__(self, db: Session):
        self.db = db

    async def ingest_email(
        self,
        user_id: int,
        subject: str,
        body: str,
        sender: str,
        recipients: List[str] = None,
        received_at: datetime = None,
        message_id: str = None,
        thread_id: str = None,
    ) -> EmailMessage:
        """
        Ingest an email into the system.
        
        Auto-categorizes and scores priority on ingest.
        Deduplicates by message_id if provided.
        """
        # Check for duplicate
        if message_id:
            existing = self.db.query(EmailMessage).filter(
                and_(
                    EmailMessage.user_id == user_id,
                    EmailMessage.message_id == message_id,
                )
            ).first()
            if existing:
                return existing

        category = self._categorize_email(subject, body)
        priority = self._score_priority(subject, body)
        summary = self._generate_summary(subject, body)

        email = EmailMessage(
            user_id=user_id,
            message_id=message_id,
            subject=subject,
            sender=sender,
            recipients=recipients or [],
            body=body,
            body_html="",  # HTML parsing deferred to extension
            summary=summary,
            category=category,
            priority=priority,
            thread_id=thread_id,
            received_at=received_at or datetime.utcnow(),
        )
        self.db.add(email)
        self.db.commit()
        self.db.refresh(email)
        return email

    async def get_emails(
        self,
        user_id: int,
        category: Optional[str] = None,
        is_read: Optional[bool] = None,
        is_starred: Optional[bool] = None,
        sender: Optional[str] = None,
        search: Optional[str] = None,
        limit: int = 50,
        offset: int = 0,
    ) -> List[Dict]:
        """
        Get emails with flexible filtering.
        
        Common queries:
        - "Unread emails": is_read=False
        - "Starred emails": is_starred=True
        - "Emails from Alice": sender="alice@example.com"
        - "Emails about meetings": category="meeting"
        - "Search emails": search="project deadline"
        """
        query = self.db.query(EmailMessage).filter(EmailMessage.user_id == user_id)

        if category:
            query = query.filter(EmailMessage.category == category)
        if is_read is not None:
            query = query.filter(EmailMessage.is_read == is_read)
        if is_starred is not None:
            query = query.filter(EmailMessage.is_starred == is_starred)
        if sender:
            query = query.filter(EmailMessage.sender.ilike(f"%{sender}%"))
        if search:
            search_term = f"%{search}%"
            query = query.filter(
                or_(
                    EmailMessage.subject.ilike(search_term),
                    EmailMessage.body.ilike(search_term),
                    EmailMessage.summary.ilike(search_term),
                )
            )

        emails = query.order_by(EmailMessage.received_at.desc()).limit(limit).offset(offset).all()
        return [self._email_to_dict(e) for e in emails]

    async def get_email(self, email_id: int, user_id: int) -> Optional[Dict]:
        """Get a single email and mark as read."""
        email = self.db.query(EmailMessage).filter(
            and_(EmailMessage.id == email_id, EmailMessage.user_id == user_id)
        ).first()
        if not email:
            return None

        if not email.is_read:
            email.is_read = True
            self.db.commit()
            self.db.refresh(email)

        return self._email_to_dict(email)

    async def get_thread(self, thread_id: str, user_id: int) -> List[Dict]:
        """Get all emails in a conversation thread, ordered chronologically."""
        emails = self.db.query(EmailMessage).filter(
            and_(
                EmailMessage.user_id == user_id,
                EmailMessage.thread_id == thread_id,
            )
        ).order_by(EmailMessage.received_at.asc()).all()
        return [self._email_to_dict(e) for e in emails]

    async def get_email_stats(self, user_id: int) -> Dict:
        """Get email statistics for dashboard."""
        total = self.db.query(func.count(EmailMessage.id)).filter(
            EmailMessage.user_id == user_id
        ).scalar()

        unread = self.db.query(func.count(EmailMessage.id)).filter(
            and_(EmailMessage.user_id == user_id, EmailMessage.is_read == False)
        ).scalar()

        category_counts = self.db.query(
            EmailMessage.category, func.count(EmailMessage.id)
        ).filter(EmailMessage.user_id == user_id).group_by(EmailMessage.category).all()

        action_required = self.db.query(func.count(EmailMessage.id)).filter(
            and_(
                EmailMessage.user_id == user_id,
                EmailMessage.category == "action",
                EmailMessage.is_read == False,
            )
        ).scalar()

        return {
            "total": total,
            "unread": unread,
            "action_required": action_required,
            "by_category": {cat: count for cat, count in category_counts},
        }

    async def star_email(self, email_id: int, user_id: int) -> Optional[bool]:
        """Toggle star status on an email."""
        email = self.db.query(EmailMessage).filter(
            and_(EmailMessage.id == email_id, EmailMessage.user_id == user_id)
        ).first()
        if not email:
            return None
        email.is_starred = not email.is_starred
        self.db.commit()
        return email.is_starred

    async def mark_read(self, email_id: int, user_id: int) -> bool:
        """Mark an email as read."""
        email = self.db.query(EmailMessage).filter(
            and_(EmailMessage.id == email_id, EmailMessage.user_id == user_id)
        ).first()
        if not email:
            return False
        email.is_read = True
        self.db.commit()
        return True

    async def extract_action_items(self, user_id: int, unread_only: bool = True) -> List[Dict]:
        """
        Extract action items from emails for task creation.
        Returns emails that likely require user action.
        """
        query = self.db.query(EmailMessage).filter(
            and_(
                EmailMessage.user_id == user_id,
                EmailMessage.category == "action",
            )
        )
        if unread_only:
            query = query.filter(EmailMessage.is_read == False)

        emails = query.order_by(EmailMessage.received_at.desc()).limit(20).all()
        return [
            {
                "email_id": e.id,
                "subject": e.subject,
                "sender": e.sender,
                "summary": e.summary,
                "received_at": e.received_at.isoformat() if e.received_at else None,
                "suggested_task": f"Respond to: {e.subject[:100]}",
            }
            for e in emails
        ]

    def _categorize_email(self, subject: str, body: str) -> str:
        """Categorize email based on keyword analysis."""
        text = (subject + " " + body).lower()
        scores = {}
        for category, keywords in self.CATEGORY_KEYWORDS.items():
            scores[category] = sum(1 for kw in keywords if kw in text)

        if max(scores.values()) > 0:
            return max(scores, key=scores.get)
        return "general"

    def _score_priority(self, subject: str, body: str) -> str:
        """Score email priority based on urgency signals."""
        text = (subject + " " + body).lower()
        for word in self.URGENT_WORDS:
            if word in text:
                return "urgent"
        if any(w in text for w in ["deadline", "important", "asap"]):
            return "high"
        return "normal"

    def _generate_summary(self, subject: str, body: str) -> str:
        """
        Generate a summary of the email body.
        For v1.13: Extractive summary (first 3 sentences).
        For v1.15: LLM-based abstractive summary.
        """
        sentences = [s.strip() for s in body.split(".") if len(s.strip()) > 10]
        if not sentences:
            return body[:200] if body else subject
        return ". ".join(sentences[:3]) + "."

    def _email_to_dict(self, email: EmailMessage) -> Dict:
        return {
            "id": email.id,
            "user_id": email.user_id,
            "message_id": email.message_id,
            "subject": email.subject,
            "sender": email.sender,
            "recipients": email.recipients or [],
            "body": email.body,
            "summary": email.summary,
            "category": email.category,
            "priority": email.priority,
            "is_read": email.is_read,
            "is_starred": email.is_starred,
            "has_attachments": email.has_attachments,
            "attachment_count": email.attachment_count,
            "labels": email.labels or [],
            "thread_id": email.thread_id,
            "received_at": email.received_at.isoformat() if email.received_at else None,
            "created_at": email.created_at.isoformat() if email.created_at else None,
        }
```

**Performance notes:**
- `_categorize_email` is O(n) where n = keyword count — very fast
- `get_emails` uses composite index `(user_id, category)` for category filter
- `get_email_stats` uses aggregation queries — efficient with proper indexes
- `extract_action_items` limits to 20 results — bounded query

### Task 2: Implement Document Handling Service

**File:** `backend/app/services/utility/document.py`

```python
import os
import hashlib
from typing import List, Dict, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from sqlalchemy import and_, or_, func
from backend.app.models.utility.document import Document, DocumentVersion


class DocumentHandlingService:
    """
    Manages documents with multi-format support, version history, and search.
    
    Features:
    - Document registration and metadata management
    - Version history with diff tracking
    - Content extraction (text from PDF, DOCX, etc.)
    - Deduplication via content hash
    - Smart chunking for vector search
    - Format conversion awareness
    """
    
    SUPPORTED_FORMATS = {
        "txt": "text/plain",
        "md": "text/markdown",
        "pdf": "application/pdf",
        "docx": "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
        "html": "text/html",
        "csv": "text/csv",
        "json": "application/json",
    }
    
    def __init__(self, db: Session, vault_path: str = None):
        """
        Args:
            db: Database session
            vault_path: Path to encrypted vault for sensitive documents
        """
        self.db = db
        self.vault_path = vault_path

    async def register_document(
        self,
        user_id: int,
        title: str,
        file_path: str = None,
        content: str = None,
        file_type: str = "txt",
        tags: List[str] = None,
        folder: str = "/",
        encrypt: bool = False,
    ) -> Document:
        """
        Register a document in the system.
        
        If file_path is provided, extracts metadata from the file.
        If content is provided directly, stores it as the initial version.
        Deduplicates by content hash.
        """
        file_size = 0
        extracted_text = ""
        content_hash = ""

        if file_path and os.path.exists(file_path):
            file_size = os.path.getsize(file_path)
            extracted_text = self._extract_text(file_path, file_type)
            content_hash = self._compute_hash(file_path)
        elif content:
            extracted_text = content
            content_hash = hashlib.sha256(content.encode()).hexdigest()
            file_size = len(content.encode())

        # Check for duplicate
        if content_hash:
            existing = self.db.query(Document).filter(
                and_(
                    Document.user_id == user_id,
                    Document.content_hash == content_hash,
                )
            ).first()
            if existing:
                return existing

        doc = Document(
            user_id=user_id,
            title=title,
            file_path=file_path,
            file_type=file_type,
            file_size=file_size,
            content_hash=content_hash,
            extracted_text=extracted_text,
            tags=tags or [],
            folder=folder,
            current_version=1,
            is_encrypted=encrypt,
            chunk_count=self._count_chunks(extracted_text),
        )
        self.db.add(doc)
        self.db.commit()
        self.db.refresh(doc)

        # Create initial version
        version = DocumentVersion(
            document_id=doc.id,
            version=1,
            content=extracted_text[:10000],  # Truncate for storage
            change_summary="Initial version",
            created_by=user_id,
        )
        self.db.add(version)
        self.db.commit()

        return doc

    async def get_documents(
        self,
        user_id: int,
        file_type: Optional[str] = None,
        folder: Optional[str] = None,
        tags: Optional[List[str]] = None,
        search: Optional[str] = None,
        limit: int = 50,
        offset: int = 0,
    ) -> List[Dict]:
        """Get documents with filtering and search."""
        query = self.db.query(Document).filter(Document.user_id == user_id)

        if file_type:
            query = query.filter(Document.file_type == file_type)
        if folder:
            query = query.filter(Document.folder == folder)
        if search:
            search_term = f"%{search}%"
            query = query.filter(
                or_(
                    Document.title.ilike(search_term),
                    Document.summary.ilike(search_term),
                    Document.extracted_text.ilike(search_term),
                )
            )

        docs = query.order_by(Document.updated_at.desc()).limit(limit).offset(offset).all()
        return [self._doc_to_dict(d) for d in docs]

    async def get_document(self, doc_id: int, user_id: int) -> Optional[Dict]:
        """Get a single document with full metadata."""
        doc = self.db.query(Document).filter(
            and_(Document.id == doc_id, Document.user_id == user_id)
        ).first()
        if not doc:
            return None
        return self._doc_to_dict(doc)

    async def update_document(
        self, doc_id: int, user_id: int, content: str = None,
        title: str = None, tags: List[str] = None
    ) -> Optional[Document]:
        """
        Update a document and create a new version.
        
        If content changes, creates a new DocumentVersion entry.
        """
        doc = self.db.query(Document).filter(
            and_(Document.id == doc_id, Document.user_id == user_id)
        ).first()
        if not doc:
            return None

        if title:
            doc.title = title
        if tags is not None:
            doc.tags = tags

        if content:
            new_version = doc.current_version + 1
            doc.current_version = new_version
            doc.extracted_text = content
            doc.content_hash = hashlib.sha256(content.encode()).hexdigest()
            doc.chunk_count = self._count_chunks(content)
            doc.file_size = len(content.encode())

            version = DocumentVersion(
                document_id=doc.id,
                version=new_version,
                content=content[:10000],
                change_summary=f"Version {new_version}",
                created_by=user_id,
            )
            self.db.add(version)

        self.db.commit()
        self.db.refresh(doc)
        return doc

    async def get_versions(self, doc_id: int, user_id: int) -> List[Dict]:
        """Get version history for a document."""
        doc = self.db.query(Document).filter(
            and_(Document.id == doc_id, Document.user_id == user_id)
        ).first()
        if not doc:
            return []

        versions = self.db.query(DocumentVersion).filter(
            DocumentVersion.document_id == doc_id
        ).order_by(DocumentVersion.version.desc()).all()

        return [
            {
                "id": v.id,
                "version": v.version,
                "change_summary": v.change_summary,
                "created_at": v.created_at.isoformat() if v.created_at else None,
            }
            for v in versions
        ]

    async def search_documents(
        self, user_id: int, query: str, limit: int = 20
    ) -> List[Dict]:
        """Full-text search across document content."""
        search_term = f"%{query}%"
        docs = self.db.query(Document).filter(
            and_(
                Document.user_id == user_id,
                or_(
                    Document.title.ilike(search_term),
                    Document.extracted_text.ilike(search_term),
                    Document.summary.ilike(search_term),
                ),
            )
        ).limit(limit).all()

        return [
            {
                "id": d.id,
                "title": d.title,
                "file_type": d.file_type,
                "preview": d.extracted_text[:200] + "..." if len(d.extracted_text) > 200 else d.extracted_text,
                "relevance": self._compute_relevance(d, query),
            }
            for d in docs
        ]

    async def delete_document(self, doc_id: int, user_id: int) -> bool:
        """
        Delete a document and all its versions.
        Does NOT delete the physical file (manual cleanup or background job).
        """
        doc = self.db.query(Document).filter(
            and_(Document.id == doc_id, Document.user_id == user_id)
        ).first()
        if not doc:
            return False

        # Delete versions first
        self.db.query(DocumentVersion).filter(
            DocumentVersion.document_id == doc_id
        ).delete()

        self.db.delete(doc)
        self.db.commit()
        return True

    async def get_document_stats(self, user_id: int) -> Dict:
        """Get document statistics for dashboard."""
        total = self.db.query(func.count(Document.id)).filter(
            Document.user_id == user_id
        ).scalar()

        total_size = self.db.query(func.sum(Document.file_size)).filter(
            Document.user_id == user_id
        ).scalar() or 0

        type_counts = self.db.query(
            Document.file_type, func.count(Document.id)
        ).filter(Document.user_id == user_id).group_by(Document.file_type).all()

        return {
            "total_documents": total,
            "total_size_bytes": total_size,
            "total_size_mb": round(total_size / (1024 * 1024), 2),
            "by_type": {ft: count for ft, count in type_counts},
        }

    def _extract_text(self, file_path: str, file_type: str) -> str:
        """Extract text content from a file based on its type."""
        try:
            if file_type in ("txt", "md", "json", "csv"):
                with open(file_path, "r", errors="ignore") as f:
                    return f.read()
            elif file_type == "html":
                with open(file_path, "r", errors="ignore") as f:
                    content = f.read()
                    # Simple HTML tag stripping
                    import re
                    return re.sub(r"<[^>]+>", " ", content)
            else:
                # Unsupported format — return empty, will be processed by extension
                return ""
        except Exception:
            return ""

    def _compute_hash(self, file_path: str) -> str:
        """Compute SHA-256 hash of file content."""
        hasher = hashlib.sha256()
        try:
            with open(file_path, "rb") as f:
                for chunk in iter(lambda: f.read(8192), b""):
                    hasher.update(chunk)
            return hasher.hexdigest()
        except Exception:
            return ""

    def _count_chunks(self, text: str, chunk_size: int = 500) -> int:
        """Estimate the number of search chunks for a document."""
        if not text:
            return 0
        return max(1, len(text) // chunk_size)

    def _compute_relevance(self, doc: Document, query: str) -> float:
        """Simple relevance scoring for search results."""
        score = 0.0
        if query.lower() in doc.title.lower():
            score += 1.0
        if query.lower() in doc.summary.lower():
            score += 0.5
        return round(score, 2)

    def _doc_to_dict(self, doc: Document) -> Dict:
        return {
            "id": doc.id,
            "user_id": doc.user_id,
            "title": doc.title,
            "file_path": doc.file_path,
            "file_type": doc.file_type,
            "file_size": doc.file_size,
            "summary": doc.summary,
            "tags": doc.tags or [],
            "folder": doc.folder,
            "current_version": doc.current_version,
            "chunk_count": doc.chunk_count,
            "is_encrypted": doc.is_encrypted,
            "created_at": doc.created_at.isoformat() if doc.created_at else None,
            "updated_at": doc.updated_at.isoformat() if doc.updated_at else None,
        }
```

from typing import List, Dict, Optional
from datetime import datetime
from sqlalchemy.orm import Session
from sqlalchemy import and_, or_, func
from backend.app.models.utility.contact import Contact


class ContactService:
    """
    Manages contacts with entity linking and interaction tracking.
    
    Features:
    - CRUD operations with ownership enforcement
    - Entity linking (tasks, emails, calendar events)
    - Interaction frequency tracking
    - Favorite contacts
    - Search by name, email, organization
    - CardDAV-ready sync fields
    """
    
    def __init__(self, db: Session):
        self.db = db

    async def create_contact(
        self, user_id: int, name: str, email: str = None,
        phone: str = None, organization: str = None,
        job_title: str = None, address: str = None,
        notes: str = "", tags: List[str] = None,
        birthday: datetime = None,
    ) -> Contact:
        """Create a new contact."""
        name_sortable = self._make_sortable(name)

        contact = Contact(
            user_id=user_id,
            name=name,
            name_sortable=name_sortable,
            email=email,
            phone=phone,
            organization=organization,
            job_title=job_title,
            address=address,
            notes=notes,
            tags=tags or [],
            birthday=birthday,
        )
        self.db.add(contact)
        self.db.commit()
        self.db.refresh(contact)
        return contact

    async def get_contacts(
        self,
        user_id: int,
        search: Optional[str] = None,
        organization: Optional[str] = None,
        is_favorite: Optional[bool] = None,
        tags: Optional[List[str]] = None,
        sort_by: str = "name_sortable",
        limit: int = 100,
        offset: int = 0,
    ) -> List[Dict]:
        """Get contacts with flexible filtering."""
        query = self.db.query(Contact).filter(Contact.user_id == user_id)

        if search:
            search_term = f"%{search}%"
            query = query.filter(
                or_(
                    Contact.name.ilike(search_term),
                    Contact.email.ilike(search_term),
                    Contact.organization.ilike(search_term),
                )
            )
        if organization:
            query = query.filter(Contact.organization.ilike(f"%{organization}%"))
        if is_favorite is not None:
            query = query.filter(Contact.is_favorite == is_favorite)

        sort_column = getattr(Contact, sort_by, Contact.name_sortable)
        contacts = query.order_by(sort_column).limit(limit).offset(offset).all()
        return [self._contact_to_dict(c) for c in contacts]

    async def get_contact(self, contact_id: int, user_id: int) -> Optional[Dict]:
        """Get a single contact."""
        contact = self.db.query(Contact).filter(
            and_(Contact.id == contact_id, Contact.user_id == user_id)
        ).first()
        if not contact:
            return None
        return self._contact_to_dict(contact)

    async def update_contact(
        self, contact_id: int, user_id: int, **kwargs
    ) -> Optional[Contact]:
        """Update a contact. Ownership verified."""
        contact = self.db.query(Contact).filter(
            and_(Contact.id == contact_id, Contact.user_id == user_id)
        ).first()
        if not contact:
            return None

        for key, value in kwargs.items():
            if value is not None and hasattr(contact, key):
                setattr(contact, key, value)
            if key == "name" and value:
                contact.name_sortable = self._make_sortable(value)

        self.db.commit()
        self.db.refresh(contact)
        return contact

    async def delete_contact(self, contact_id: int, user_id: int) -> bool:
        """Delete a contact."""
        contact = self.db.query(Contact).filter(
            and_(Contact.id == contact_id, Contact.user_id == user_id)
        ).first()
        if not contact:
            return False
        self.db.delete(contact)
        self.db.commit()
        return True

    async def link_entity(
        self, contact_id: int, user_id: int, entity_type: str, entity_id: int
    ) -> Optional[Dict]:
        """
        Link a contact to an entity (task, email, calendar event).
        
        Args:
            entity_type: "task", "email", "calendar_event"
            entity_id: ID of the linked entity
        """
        contact = self.db.query(Contact).filter(
            and_(Contact.id == contact_id, Contact.user_id == user_id)
        ).first()
        if not contact:
            return None

        links = contact.linked_entities or []
        new_link = {"type": entity_type, "id": entity_id}
        if new_link not in links:
            links.append(new_link)
            contact.linked_entities = links
            self.db.commit()
            self.db.refresh(contact)

        return self._contact_to_dict(contact)

    async def increment_interaction(self, contact_id: int, user_id: int) -> Optional[Dict]:
        """Record an interaction with a contact (auto-called when email/task references them)."""
        contact = self.db.query(Contact).filter(
            and_(Contact.id == contact_id, Contact.user_id == user_id)
        ).first()
        if not contact:
            return None

        contact.contact_frequency += 1
        contact.last_contacted_at = datetime.utcnow()
        self.db.commit()
        self.db.refresh(contact)
        return self._contact_to_dict(contact)

    async def get_stale_contacts(self, user_id: int, days: int = 90) -> List[Dict]:
        """Get contacts not interacted with in N days."""
        from datetime import timedelta
        cutoff = datetime.utcnow() - timedelta(days=days)
        contacts = self.db.query(Contact).filter(
            and_(
                Contact.user_id == user_id,
                or_(
                    Contact.last_contacted_at < cutoff,
                    Contact.last_contacted_at.is_(None),
                ),
            )
        ).order_by(Contact.last_contacted_at.asc()).limit(50).all()
        return [self._contact_to_dict(c) for c in contacts]

    async def find_by_email(self, user_id: int, email: str) -> Optional[Dict]:
        """Find a contact by email address."""
        contact = self.db.query(Contact).filter(
            and_(Contact.user_id == user_id, Contact.email == email)
        ).first()
        if not contact:
            return None
        return self._contact_to_dict(contact)

    async def auto_link_from_email(self, user_id: int, email_id: int, sender: str) -> Optional[int]:
        """
        Auto-link an email to a contact by matching sender email.
        Returns the linked contact_id or None.
        """
        contact = self.db.query(Contact).filter(
            and_(Contact.user_id == user_id, Contact.email == sender)
        ).first()
        if not contact:
            return None

        links = contact.linked_entities or []
        new_link = {"type": "email", "id": email_id}
        if new_link not in links:
            links.append(new_link)
            contact.linked_entities = links
            contact.contact_frequency += 1
            contact.last_contacted_at = datetime.utcnow()
            self.db.commit()

        return contact.id

    def _make_sortable(self, name: str) -> str:
        """Convert name to sortable format: 'Last, First'."""
        parts = name.strip().split()
        if len(parts) >= 2:
            return f"{parts[-1]}, {' '.join(parts[:-1])}"
        return name

    def _contact_to_dict(self, contact: Contact) -> Dict:
        return {
            "id": contact.id,
            "user_id": contact.user_id,
            "name": contact.name,
            "email": contact.email,
            "phone": contact.phone,
            "organization": contact.organization,
            "job_title": contact.job_title,
            "notes": contact.notes,
            "tags": contact.tags or [],
            "linked_entities": contact.linked_entities or [],
            "is_favorite": contact.is_favorite,
            "contact_frequency": contact.contact_frequency,
            "last_contacted_at": contact.last_contacted_at.isoformat() if contact.last_contacted_at else None,
            "birthday": contact.birthday.isoformat() if contact.birthday else None,
            "created_at": contact.created_at.isoformat() if contact.created_at else None,
            "updated_at": contact.updated_at.isoformat() if contact.updated_at else None,
        }
