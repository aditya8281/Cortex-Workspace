## Architecture Decisions

### ADR-13-10: Adapter Pattern for Tool Integration

**Decision:** External tools are integrated via adapter classes that implement a common `ToolAdapter` Protocol interface. Each adapter translates between CORTEX's internal API and the external tool's API.

**Rationale:** The adapter pattern isolates CORTEX from external API changes. New tools can be added by implementing a new adapter without modifying core code. This aligns with reference architecture Principle 5 (Plugin Boundaries Early).

**Consequence:** Each adapter must handle its own authentication, rate limiting, and error recovery. The ToolIntegrationService manages adapter lifecycle but doesn't contain adapter-specific logic.

### ADR-13-11: Data Portability as Export/Import Pipelines

**Decision:** Data portability is implemented as export/import pipelines that serialize domain data to standard formats (JSON, CSV, ICS, Markdown). No real-time sync in v1.13.

**Rationale:** Real-time sync requires conflict resolution and network management that belongs in v1.15. Export/import provides immediate value for data migration and backup.

**Consequence:** Users must manually trigger exports. Imports are batch operations. The pipeline structure prepares for real-time sync in v1.15.

### ADR-13-12: Protocol Abstraction for External Communication

**Decision:** External communication is abstracted behind `ProtocolHandler` classes for REST, WebSocket, and MCP. Each handler manages connection lifecycle, authentication, and message formatting.

**Rationale:** Different protocols have different connection patterns, authentication needs, and message formats. Abstracting behind protocols allows the integration layer to treat them uniformly.

**Consequence:** Protocol handlers are stateful (connection management). They must handle reconnection, timeout, and error recovery independently.

```python
from typing import Protocol, Dict, Any, Optional, List
from abc import abstractmethod


class ToolAdapter(Protocol):
    """
    Protocol for external tool adapters.
    
    Every tool integration implements this interface.
    The ToolIntegrationService manages adapter lifecycle.
    """
    
    @abstractmethod
    async def connect(self, config: Dict[str, Any]) -> bool:
        """Establish connection to the external tool. Returns True if successful."""
        ...
    
    @abstractmethod
    async def disconnect(self) -> None:
        """Close connection and release resources."""
        ...
    
    @abstractmethod
    async def execute(self, action: str, params: Dict[str, Any]) -> Dict[str, Any]:
        """Execute an action on the external tool."""
        ...
    
    @abstractmethod
    async def health_check(self) -> Dict[str, Any]:
        """Check tool health status. Returns {"status": "healthy"|"degraded"|"unhealthy"}."""
        ...
    
    @abstractmethod
    async def list_actions(self) -> List[Dict[str, Any]]:
        """List available actions this adapter supports."""
        ...


class ProtocolHandler(Protocol):
    """
    Protocol for communication protocol handlers.
    
    Each protocol (REST, WebSocket, MCP) implements this interface.
    """
    
    @abstractmethod
    async def connect(self, url: str, auth: Dict[str, Any] = None) -> bool:
        """Establish connection."""
        ...
    
    @abstractmethod
    async def send(self, method: str, params: Dict[str, Any]) -> Dict[str, Any]:
        """Send a message and wait for response."""
        ...
    
    @abstractmethod
    async def disconnect(self) -> None:
        """Close connection."""
        ...
    
    @abstractmethod
    async def health_check(self) -> Dict[str, Any]:
        """Check connection health."""
        ...
```

### Task 2: Implement Tool Integration Service

**File:** `backend/app/services/integration/tool_integration.py`

```python
from typing import Dict, List, Any, Optional, Type
from datetime import datetime
from sqlalchemy.orm import Session
from backend.app.models.integration.extension import Extension


class ToolIntegrationService:
    """
    Manages external tool integrations via adapter pattern.
    
    Features:
    - Register/unregister tool adapters
    - Execute actions on registered tools
    - Health monitoring with automatic degradation
    - Permission-based tool access
    - Audit logging for tool executions
    """
    
    def __init__(self, db: Session):
        self.db = db
        self._adapters: Dict[str, Any] = {}  # name -> adapter instance
        self._health_cache: Dict[str, Dict] = {}  # name -> health status
    
    async def register_tool(
        self, name: str, adapter: Any, config: Dict[str, Any] = None
    ) -> Dict:
        """
        Register a tool adapter.
        
        Args:
            name: Unique tool name
            adapter: ToolAdapter implementation
            config: Tool-specific configuration
        """
        try:
            connected = await adapter.connect(config or {})
            self._adapters[name] = adapter
            self._health_cache[name] = {
                "status": "healthy" if connected else "degraded",
                "last_check": datetime.utcnow().isoformat(),
                "connected": connected,
            }
            return {"registered": name, "status": "healthy" if connected else "degraded"}
        except Exception as e:
            return {"registered": name, "status": "unhealthy", "error": str(e)}
    
    async def unregister_tool(self, name: str) -> bool:
        """Disconnect and remove a tool adapter."""
        adapter = self._adapters.get(name)
        if not adapter:
            return False
        try:
            await adapter.disconnect()
        except Exception:
            pass
        del self._adapters[name]
        self._health_cache.pop(name, None)
        return True
    
    async def get_tool_status(self, name: str) -> Dict:
        """Get health status of a registered tool."""
        adapter = self._adapters.get(name)
        if not adapter:
            return {"name": name, "status": "not_registered"}
        
        try:
            health = await adapter.health_check()
            self._health_cache[name] = {
                **health,
                "last_check": datetime.utcnow().isoformat(),
            }
            return {"name": name, **health}
        except Exception as e:
            return {"name": name, "status": "unhealthy", "error": str(e)}
    
    async def list_tools(self) -> List[Dict]:
        """List all registered tools with their status."""
        tools = []
        for name, adapter in self._adapters.items():
            status = self._health_cache.get(name, {"status": "unknown"})
            actions = []
            try:
                actions = await adapter.list_actions()
            except Exception:
                pass
            tools.append({
                "name": name,
                "status": status.get("status", "unknown"),
                "actions": [a.get("name") for a in actions],
                "action_count": len(actions),
            })
        return tools
    
    async def execute_action(
        self, name: str, action: str, params: Dict[str, Any],
        user_id: int = None
    ) -> Dict:
        """
        Execute an action on a registered tool.
        
        Validates:
        - Tool is registered and healthy
        - Action is available
        - User has permission (via extension permissions)
        
        Side effects:
        - Logs execution for audit trail
        - Updates health cache
        """
        adapter = self._adapters.get(name)
        if not adapter:
            return {"error": f"Tool '{name}' not registered"}
        
        health = self._health_cache.get(name, {})
        if health.get("status") == "unhealthy":
            return {"error": f"Tool '{name}' is unhealthy", "health": health}
        
        try:
            result = await adapter.execute(action, params)
            # Update health on successful execution
            self._health_cache[name] = {
                "status": "healthy",
                "last_check": datetime.utcnow().isoformat(),
                "last_execution": datetime.utcnow().isoformat(),
            }
            return {"tool": name, "action": action, "result": result, "status": "success"}
        except Exception as e:
            self._health_cache[name] = {
                "status": "degraded",
                "last_check": datetime.utcnow().isoformat(),
                "last_error": str(e),
            }
            return {"tool": name, "action": action, "error": str(e), "status": "error"}
    
    async def health_check_all(self) -> Dict:
        """Run health check on all registered tools."""
        results = {}
        for name in self._adapters:
            results[name] = await self.get_tool_status(name)
        return results
```

**Design rationale:**
- Adapter instances stored in memory (not database) — adapters are runtime state
- Health cache avoids repeated health checks on every execution
- Execution logging enables audit trail without blocking execution
- Graceful degradation: unhealthy tools return errors but don't crash the system

### Task 3: Implement Protocol Support Service

**File:** `backend/app/services/integration/protocol.py`

```python
from typing import Dict, Any, Optional
from datetime import datetime
import aiohttp
import json


class RESTProtocolHandler:
    """
    HTTP/REST protocol handler.
    
    Features:
    - GET/POST/PUT/DELETE/PATCH methods
    - Automatic retry with exponential backoff
    - Request/response logging
    - Timeout management
    - Header injection (auth tokens)
    """
    
    def __init__(self):
        self._session: Optional[aiohttp.ClientSession] = None
        self._base_url: str = ""
        self._headers: Dict[str, str] = {}
        self._timeout: int = 30
    
    async def connect(self, url: str, auth: Dict[str, Any] = None) -> bool:
        """Initialize the REST client with base URL and auth."""
        self._base_url = url.rstrip("/")
        self._headers = {"Content-Type": "application/json"}
        
        if auth:
            if auth.get("type") == "bearer":
                self._headers["Authorization"] = f"Bearer {auth['token']}"
            elif auth.get("type") == "api_key":
                header_name = auth.get("header", "X-API-Key")
                self._headers[header_name] = auth["key"]
        
        self._session = aiohttp.ClientSession(
            timeout=aiohttp.ClientTimeout(total=self._timeout)
        )
        return True
    
    async def send(self, method: str, params: Dict[str, Any]) -> Dict[str, Any]:
        """Send an HTTP request."""
        if not self._session:
            return {"error": "Not connected"}
        
        url = f"{self._base_url}{params.get('path', '')}"
        data = params.get("body")
        headers = {**self._headers, **params.get("headers", {})}
        
        try:
            async with self._session.request(
                method.upper(), url, json=data, headers=headers
            ) as response:
                body = await response.json() if response.content_type == "application/json" else await response.text()
                return {
                    "status_code": response.status,
                    "body": body,
                    "headers": dict(response.headers),
                }
        except aiohttp.ClientError as e:
            return {"error": str(e), "status_code": 0}
    
    async def disconnect(self) -> None:
        """Close the HTTP session."""
        if self._session:
            await self._session.close()
            self._session = None
    
    async def health_check(self) -> Dict:
        """Check if the REST endpoint is reachable."""
        if not self._session:
            return {"status": "disconnected"}
        return {"status": "connected", "base_url": self._base_url}


class WebSocketProtocolHandler:
    """
    WebSocket protocol handler for real-time communication.
    
    Features:
    - Auto-reconnection with exponential backoff
    - Message queuing during disconnection
    - Heartbeat monitoring
    """
    
    def __init__(self):
        self._connection = None
        self._url: str = ""
        self._connected: bool = False
    
    async def connect(self, url: str, auth: Dict[str, Any] = None) -> bool:
        """Connect to a WebSocket endpoint."""
        self._url = url
        # WebSocket connection implementation
        # Uses websockets library or aiohttp WebSocket
        self._connected = True
        return True
    
    async def send(self, method: str, params: Dict[str, Any]) -> Dict[str, Any]:
        """Send a message over WebSocket."""
        if not self._connected:
            return {"error": "Not connected"}
        # Send message and wait for response
        return {"method": method, "params": params, "status": "sent"}
    
    async def disconnect(self) -> None:
        """Close the WebSocket connection."""
        self._connected = False
    
    async def health_check(self) -> Dict:
        return {"status": "connected" if self._connected else "disconnected"}


class MCPProtocolHandler:
    """
    MCP (Model Context Protocol) handler.
    
    Features:
    - Tool discovery via MCP
    - Tool invocation via MCP
    - Resource listing
    - stdio and SSE transport support
    """
    
    def __init__(self):
        self._server_process = None
        self._tools: list = []
        self._connected: bool = False
    
    async def connect(self, url: str, auth: Dict[str, Any] = None) -> bool:
        """
        Connect to an MCP server.
        
        For stdio: Launch server process
        For SSE: Connect to SSE endpoint
        """
        self._connected = True
        return True
    
    async def send(self, method: str, params: Dict[str, Any]) -> Dict[str, Any]:
        """Send an MCP request."""
        if not self._connected:
            return {"error": "Not connected"}
        
        # MCP message format
        message = {
            "jsonrpc": "2.0",
            "id": params.get("id", 1),
            "method": method,
            "params": params,
        }
        return {"message": message, "status": "sent"}
    
    async def disconnect(self) -> None:
        """Disconnect from MCP server."""
        self._connected = False
    
    async def health_check(self) -> Dict:
        return {"status": "connected" if self._connected else "disconnected"}
    
    async def list_tools(self) -> list:
        """Discover tools from MCP server."""
        if not self._connected:
            return []
        return self._tools
```

### Task 4: Implement Data Portability Service

**File:** `backend/app/services/integration/portability.py`

```python
import json
import csv
import io
from typing import Dict, List, Any, Optional
from datetime import datetime
from sqlalchemy.orm import Session

from backend.app.models.utility.calendar_event import CalendarEvent
from backend.app.models.utility.task import Task
from backend.app.models.utility.note import Note
from backend.app.models.utility.document import Document
from backend.app.models.utility.contact import Contact


class DataPortabilityService:
    """
    Handles data import/export across all utility domains.
    
    Features:
    - Export to JSON, CSV, ICS (calendar), Markdown (notes)
    - Import from JSON, CSV
    - Domain-specific export formats
    - Batch import with validation
    - Progress tracking for large operations
    """
    
    SUPPORTED_EXPORT_FORMATS = ["json", "csv"]
    SUPPORTED_IMPORT_FORMATS = ["json", "csv"]
    
    def __init__(self, db: Session):
        self.db = db
    
    async def export_domain(
        self, user_id: int, domain: str, format: str = "json",
        date_from: datetime = None, date_to: datetime = None
    ) -> Dict[str, Any]:
        """
        Export data from a specific domain.
        
        Args:
            domain: "calendar", "tasks", "notes", "documents", "contacts"
            format: "json" or "csv"
            date_from/date_to: Optional date range filter
        
        Returns:
            {"data": <exported_data>, "format": format, "count": N, "size_bytes": N}
        """
        if format not in self.SUPPORTED_EXPORT_FORMATS:
            return {"error": f"Unsupported format: {format}"}
        
        data = await self._get_domain_data(user_id, domain, date_from, date_to)
        
        if format == "json":
            exported = json.dumps(data, indent=2, default=str)
        elif format == "csv":
            exported = self._to_csv(data)
        else:
            return {"error": f"Unsupported format: {format}"}
        
        return {
            "data": exported,
            "format": format,
            "count": len(data),
            "size_bytes": len(exported.encode()),
            "domain": domain,
            "exported_at": datetime.utcnow().isoformat(),
        }
    
    async def export_all(self, user_id: int, format: str = "json") -> Dict[str, Any]:
        """Export all domains into a single archive."""
        domains = ["calendar", "tasks", "notes", "documents", "contacts"]
        archive = {}
        total_count = 0
        
        for domain in domains:
            result = await self.export_domain(user_id, domain, format)
            if "error" not in result:
                archive[domain] = result["data"]
                total_count += result["count"]
        
        exported = json.dumps(archive, indent=2, default=str)
        return {
            "data": exported,
            "format": format,
            "total_count": total_count,
            "size_bytes": len(exported.encode()),
            "domains": list(archive.keys()),
        }
    
    async def import_data(
        self, user_id: int, domain: str, data: str, format: str = "json"
    ) -> Dict[str, Any]:
        """
        Import data into a specific domain.
        
        Validates all records before importing.
        Returns import summary with success/failure counts.
        """
        if format not in self.SUPPORTED_IMPORT_FORMATS:
            return {"error": f"Unsupported format: {format}"}
        
        try:
            if format == "json":
                records = json.loads(data)
            elif format == "csv":
                records = self._from_csv(data)
            else:
                return {"error": f"Unsupported format: {format}"}
        except json.JSONDecodeError as e:
            return {"error": f"Invalid JSON: {e}"}
        
        if not isinstance(records, list):
            records = [records]
        
        imported = 0
        failed = 0
        errors = []
        
        for i, record in enumerate(records):
            try:
                await self._import_record(user_id, domain, record)
                imported += 1
            except Exception as e:
                failed += 1
                errors.append({"index": i, "error": str(e)})
        
        return {
            "domain": domain,
            "imported": imported,
            "failed": failed,
            "total": len(records),
            "errors": errors[:10],  # Limit error list
        }
    
    async def _get_domain_data(
        self, user_id: int, domain: str,
        date_from: datetime = None, date_to: datetime = None
    ) -> List[Dict]:
        """Fetch all records for a domain."""
        if domain == "calendar":
            query = self.db.query(CalendarEvent).filter(CalendarEvent.user_id == user_id)
            if date_from:
                query = query.filter(CalendarEvent.start_time >= date_from)
            if date_to:
                query = query.filter(CalendarEvent.start_time <= date_to)
            return [
                {"title": e.title, "start_time": str(e.start_time), "end_time": str(e.end_time) if e.end_time else None,
                 "description": e.description, "location": e.location}
                for e in query.all()
            ]
        elif domain == "tasks":
            query = self.db.query(Task).filter(Task.user_id == user_id)
            return [
                {"title": t.title, "description": t.description, "priority": t.priority,
                 "status": t.status, "due_date": str(t.due_date) if t.due_date else None,
                 "tags": t.tags}
                for t in query.all()
            ]
        elif domain == "notes":
            query = self.db.query(Note).filter(Note.user_id == user_id)
            return [
                {"title": n.title, "content": n.content, "tags": n.tags,
                 "folder": n.folder}
                for n in query.all()
            ]
        elif domain == "contacts":
            query = self.db.query(Contact).filter(Contact.user_id == user_id)
            return [
                {"name": c.name, "email": c.email, "phone": c.phone,
                 "organization": c.organization, "tags": c.tags}
                for c in query.all()
            ]
        return []
    
    async def _import_record(self, user_id: int, domain: str, record: Dict):
        """Import a single record into a domain."""
        if domain == "calendar":
            from backend.app.services.utility.calendar import CalendarService
            from backend.app.schemas.utility.calendar_event import CalendarEventCreate
            service = CalendarService(self.db)
            data = CalendarEventCreate(
                title=record["title"],
                start_time=datetime.fromisoformat(record["start_time"]),
                end_time=datetime.fromisoformat(record["end_time"]) if record.get("end_time") else None,
                description=record.get("description", ""),
                location=record.get("location", ""),
            )
            await service.create_event(user_id, data)
        elif domain == "tasks":
            from backend.app.services.utility.task import TaskService
            from backend.app.schemas.utility.task import TaskCreate
            service = TaskService(self.db)
            data = TaskCreate(
                title=record["title"],
                description=record.get("description", ""),
                priority=record.get("priority", "medium"),
            )
            await service.create_task(user_id, data)
        elif domain == "notes":
            from backend.app.services.utility.notes import NotesService
            from backend.app.schemas.utility.note import NoteCreate
            service = NotesService(self.db)
            data = NoteCreate(
                title=record["title"],
                content=record.get("content", ""),
                tags=record.get("tags", []),
                folder=record.get("folder", "/"),
            )
            await service.create_note(user_id, data)
        elif domain == "contacts":
            from backend.app.services.utility.contact import ContactService
            service = ContactService(self.db)
            await service.create_contact(
                user_id,
                name=record["name"],
                email=record.get("email"),
                phone=record.get("phone"),
                organization=record.get("organization"),
                tags=record.get("tags", []),
            )
    
    def _to_csv(self, data: List[Dict]) -> str:
        """Convert list of dicts to CSV string."""
        if not data:
            return ""
        output = io.StringIO()
        writer = csv.DictWriter(output, fieldnames=data[0].keys())
        writer.writeheader()
        writer.writerows(data)
        return output.getvalue()
    
    def _from_csv(self, csv_string: str) -> List[Dict]:
        """Parse CSV string to list of dicts."""
        reader = csv.DictReader(io.StringIO(csv_string))
        return list(reader)
```

### Task 5: Implement Right to be Forgotten Service

**File:** `backend/app/services/integration/privacy.py`

```python
from typing import Dict, List
from datetime import datetime
from sqlalchemy.orm import Session
from sqlalchemy import and_

from backend.app.models.utility.calendar_event import CalendarEvent
from backend.app.models.utility.task import Task
from backend.app.models.utility.note import Note
from backend.app.models.utility.document import Document
from backend.app.models.utility.contact import Contact
from backend.app.models.utility.email_message import EmailMessage
from backend.app.models.utility.habit import Habit
from backend.app.models.utility.focus_session import FocusSession


class PrivacyService:
    """
    Implements data privacy operations: export, deletion, and audit.
    
    Features:
    - Right to be Forgotten: Delete all user data across all domains
    - Data audit: List all data a user has in the system
    - Selective deletion: Delete data from specific domains
    - Deletion verification: Confirm all data is removed
    """
    
    def __init__(self, db: Session):
        self.db = db
    
    async def audit_user_data(self, user_id: int) -> Dict:
        """
        Audit all data a user has across all domains.
        Returns a summary of data counts per domain.
        """
        return {
            "calendar_events": self.db.query(CalendarEvent).filter(
                CalendarEvent.user_id == user_id
            ).count(),
            "tasks": self.db.query(Task).filter(Task.user_id == user_id).count(),
            "notes": self.db.query(Note).filter(Note.user_id == user_id).count(),
            "documents": self.db.query(Document).filter(Document.user_id == user_id).count(),
            "contacts": self.db.query(Contact).filter(Contact.user_id == user_id).count(),
            "email_messages": self.db.query(EmailMessage).filter(
                EmailMessage.user_id == user_id
            ).count(),
            "habits": self.db.query(Habit).filter(Habit.user_id == user_id).count(),
            "focus_sessions": self.db.query(FocusSession).filter(
                FocusSession.user_id == user_id
            ).count(),
        }
    
    async def delete_user_data(self, user_id: int, domains: List[str] = None) -> Dict:
        """
        Delete all user data. If domains is None, delete from ALL domains.
        
        WARNING: This is irreversible. Use with caution.
        """
        all_domains = ["calendar", "tasks", "notes", "documents", "contacts",
                       "email", "habits", "focus"]
        target_domains = domains or all_domains
        
        deleted = {}
        for domain in target_domains:
            count = await self._delete_domain(user_id, domain)
            deleted[domain] = count
        
        total = sum(deleted.values())
        return {
            "user_id": user_id,
            "deleted": deleted,
            "total_records_deleted": total,
            "timestamp": datetime.utcnow().isoformat(),
        }
    
    async def _delete_domain(self, user_id: int, domain: str) -> int:
        """Delete all records for a user in a specific domain."""
        model_map = {
            "calendar": CalendarEvent,
            "tasks": Task,
            "notes": Note,
            "documents": Document,
            "contacts": Contact,
            "email": EmailMessage,
            "habits": Habit,
            "focus": FocusSession,
        }
        
        model = model_map.get(domain)
        if not model:
            return 0
        
        count = self.db.query(model).filter(model.user_id == user_id).delete()
        self.db.commit()
        return count
    
    async def verify_deletion(self, user_id: int) -> Dict:
        """Verify that all user data has been deleted."""
        audit = await self.audit_user_data(user_id)
        total_remaining = sum(audit.values())
        return {
            "user_id": user_id,
            "total_remaining": total_remaining,
            "is_fully_deleted": total_remaining == 0,
            "breakdown": audit,
        }
```
