# REDESIGN P01: Design Tokens & Tailwind Config

**This should be the first phase implemented.** It updates the foundational design system (globals.css, tailwind.config.ts) to align with redesign0.md color palette, typography, radii, shadows, z-index scale, and motion tokens. Every subsequent phase depends on these values existing.

> **For agentic workers:** This is a READ-AND-MODIFY task — no TDD needed for pure config/stylesheet changes. Test by verifying the dev server renders pages with the new tokens applied.

**Architecture:** Monolithic CSS variables in globals.css + Tailwind's `theme.extend` config. All tokens defined once, referenced throughout via `bg-*`, `text-*`, `shadow-*`, etc.
