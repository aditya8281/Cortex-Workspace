# REDESIGN P07: Search Mode — Unified Prefix Search

**Build unified search mode with prefix-based routing (/, /web, /chat, /code, /files, /vault), results panel, filter sidebar.**

**Dependencies:** P01, P02, P04 (mode shell)

**Backend reality:** Default search ✅ at POST /api/v1/search. Prefix routes 🔴 until v1.11 (web), v1.12 (code), etc. Frontend must show graceful "not yet available" for 🔴 prefixes.

---

## Tasks

### Task 7.1: Create Search Page Shell

**Create: `frontend/src/features/search/page.tsx`**

Full-screen mode with search bar, results panel (left), filter sidebar (right). Uses ModeShell.

### Task 7.2: Build Prefix Toggle System

Prefix chips below search bar: Default, /web, /chat, /code, /files, /vault. Active chip gets accent-red bg. Disabled chips (🔴) show with opacity 0.5 + tooltip "Planned for v1.XX".

### Task 7.3: Build Result Cards

Glass-morphism cards showing: title, file path, snippet with highlighted terms, relevance score (color-coded), source type badge, timestamp, action buttons (open, copy, share).

### Task 7.4: Build Filter Sidebar

Source filter, date range, type filter, relevance slider. Quick filter buttons: Memories, Files, Chat, Web, Code.

### Task 7.5: Wire Default Search to Backend

Default (no prefix) → POST /api/v1/search with query body. Parse response into result cards. Handle empty results and error states with proper messaging.
