# P06: Planning Reorganization — CORTEX

**Document:** Phase 06 of Version 1.01
**Authority:** Stage 6 — Master Versioned Implementation Roadmap
**Date:** 2026-06-27

---

## Objective

Organize planning documents into a versioned structure with templates. Transform the scattered planning files into a systematic hierarchy that makes it clear what's planned, what's in progress, and what's complete.

---

## Purpose

Planning is currently scattered across `.agents/plans/` with no clear structure. Version directories exist but lack templates and conventions. Organizing:

1. **Establishes planning conventions** — templates ensure consistency across versions
2. **Makes version status clear** — progress tracking is standardized
3. **Enables automated validation** — templates can be checked programmatically
4. **Reduces planning overhead** — new versions start from templates, not scratch

**Template validation:**
```bash
# Verify templates have required sections
for template in .agents/plans/templates/*.md; do
  echo "=== $(basename $template) ==="
  grep -c "^##" "$template"  # Count sections
  grep "^## Objective" "$template" || echo "  WARNING: Missing Objective section"
  grep "^## Definition of Done" "$template" || echo "  WARNING: Missing DoD section"
done
```

**CLAUDE.md verification:**
```bash
# Verify CLAUDE.md references are correct
grep "agents/plans" CLAUDE.md | while read -r line; do
  path=$(echo "$line" | grep -o "\.agents/plans/[^`|]*" | head -1)
  if [ -n "$path" ]; then
    test -e "$path" && echo "OK: $path" || echo "BROKEN: $path"
  fi
done
```

**Specific test cases:**
- `test-planning-structure.py`: Verify all planning subdirectories exist
- `test-templates.py`: Verify all template files exist and are well-formed
- `test-examples.py`: Verify all example files exist and demonstrate template usage
- `test-version-directories.py`: Verify all version directories exist
- `test-CLAUDE-md-planning.py`: Verify CLAUDE.md planning references are accurate
