# P05: Documentation Reorganization — CORTEX

**Document:** Phase 05 of Version 1.01
**Authority:** Stage 6 — Master Versioned Implementation Roadmap
**Date:** 2026-06-27

---

## Objective

Organize documentation into subdirectories by topic. Transform the flat `docs/` directory into a structured documentation hierarchy that is browsable, discoverable, and maintainable.

---

## Purpose

Documentation is currently scattered in `docs/` root. When a contributor needs to understand the database schema, they must know the exact filename (`DATABASE.md`) rather than browsing a `reference/` directory. Reorganizing:

1. **Enables discovery** — browse by topic, not by filename
2. **Groups related docs** — architecture docs together, guides together
3. **Prevents doc sprawl** — new docs go in the correct subdirectory
4. **Aligns with code domains** — domain documentation mirrors code domains

### Task 4: Update Cross-References

Update all internal links in documentation to point to new locations.

**Cross-reference update strategy:**

1. Find all internal links: `grep -rn "\[.*\](.*\.md)" docs/ --include="*.md"`
2. Update each link to point to new location
3. Verify no broken links

**Common link patterns:**

```markdown
<!-- Before (broken) -->
[Architecture](ARCHITECTURE.md)
[Database](DATABASE.md)
[Developer Guide](DEVELOPER_GUIDE.md)

<!-- After (fixed) -->
[Architecture](architecture/overview.md)
[Database](reference/database.md)
[Developer Guide](guides/developer.md)
```

**Test Criteria:**
- All internal links updated
- `grep -rn "\[.*\](.*\.md)" docs/ --include="*.md"` shows no broken references
- All links resolve to existing files

**Risk Notes:**
- *Risk:* Missed a broken link. *Mitigation:* Use automated link checker (e.g., `markdown-link-check`).
- *Risk:* Links are correct but files don't exist. *Mitigation:* Verify each target file exists before updating link.

## Testing Strategy

**Link verification:**
```bash
# Find all internal links
grep -rn "\[.*\](.*\.md)" docs/ --include="*.md" | head -20

# Verify each target exists
for link in $(grep -roh "\[.*\](.*\.md)" docs/ --include="*.md" | grep -o "(.*\.md)" | tr -d "()" | sort -u); do
  test -f "docs/$link" && echo "OK: $link" || echo "BROKEN: $link"
done
```

**Directory verification:**
```bash
# Verify all subdirectories exist
for dir in architecture domains guides reference decisions planning research audits workflows; do
  test -d "docs/$dir" && echo "OK: $dir" || echo "MISSING: $dir"
done

# Verify domain stubs exist
for domain in memory awareness intelligence interaction cognition privacy integration developer utility system; do
  test -f "docs/domains/$domain.md" && echo "OK: $domain" || echo "MISSING: $domain"
done
```

**CLAUDE.md verification:**
```bash
# Verify CLAUDE.md references are correct
grep "docs/" CLAUDE.md | while read -r line; do
  path=$(echo "$line" | grep -o "docs/[^`|]*" | head -1)
  if [ -n "$path" ]; then
    test -e "$path" && echo "OK: $path" || echo "BROKEN: $path"
  fi
done
```

**Specific test cases:**
- `test-docs-structure.py`: Verify all documentation subdirectories exist
- `test-domain-stubs.py`: Verify all 10 domain stubs exist with correct content
- `test-cross-references.py`: Verify all internal links resolve to existing files
- `test-CLAUDE-md.py`: Verify CLAUDE.md documentation table is accurate
