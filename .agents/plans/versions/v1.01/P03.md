# P03: Import Migration — CORTEX

**Document:** Phase 03 of Version 1.01
**Authority:** Stage 6 — Master Versioned Implementation Roadmap
**Date:** 2026-06-27

---

## Objective

Update all import paths across the entire codebase to reflect the new domain-organized structure established in P01 (services) and P02 (models). This is the most mechanically intensive phase — every Python file that imports from `app.services`, `app.models`, or `app.schemas` must be updated.

---

## Purpose

After P01 and P02, files have moved but imports still reference old locations. The codebase currently has a dual state: files live in new locations, but consumers still import from old paths. This phase resolves the duality:

1. **Eliminate all old-path imports** — grep verification confirms zero remaining
2. **Establish canonical import paths** — `from backend.app.services.memory import X` becomes the standard
3. **Verify full application works** — every endpoint, every service, every model importable
4. **Create import conventions** — documented rules for future development

```python
# tests/migration/import_inventory.py
"""Import migration tracking — run this to verify all imports are updated."""

import subprocess
import re
from pathlib import Path


def find_old_imports() -> dict[str, list[str]]:
    """Find all imports using old flat paths."""
    results = {
        "services": [],
        "models": [],
        "schemas": [],
    }

    # Service imports
    result = subprocess.run(
        ["grep", "-rn", "from app.services import\\|from app.services\\.",
         "backend/", "--include=*.py"],
        capture_output=True, text=True,
    )
    for line in result.stdout.strip().split("\n"):
        if line and "__pycache__" not in line:
            results["services"].append(line)

    # Model imports
    result = subprocess.run(
        ["grep", "-rn", "from app.models import\\|from app.models\\.",
         "backend/", "--include=*.py"],
        capture_output=True, text=True,
    )
    for line in result.stdout.strip().split("\n"):
        if line and "__pycache__" not in line:
            results["models"].append(line)

    return results


def verify_migration() -> dict[str, bool]:
    """Verify all imports are updated."""
    old_imports = find_old_imports()
    return {
        "no_old_service_imports": len(old_imports["services"]) == 0,
        "no_old_model_imports": len(old_imports["models"]) == 0,
        "no_old_schema_imports": len(old_imports["schemas"]) == 0,
    }


if __name__ == "__main__":
    old = find_old_imports()
    print(f"Old service imports: {len(old['services'])}")
    print(f"Old model imports: {len(old['models'])}")
    print(f"Old schema imports: {len(old['schemas'])}")

    for category, imports in old.items():
        if imports:
            print(f"\n=== Remaining {category} imports ===")
            for imp in imports[:10]:  # Show first 10
                print(f"  {imp}")
            if len(imports) > 10:
                print(f"  ... and {len(imports) - 10} more")
```

**Test Criteria:**
- Inventory script runs without errors
- Import counts are accurate (verified against grep)
- All old-path imports are listed

**Risk Notes:**
- *Risk:* Missed imports (grep doesn't catch all patterns). *Mitigation:* Also check for `import app.services.X` and `from app import services.X` patterns.
- *Risk:* Dynamic imports not caught by grep. *Mitigation:* Search for `importlib.import_module` calls separately.
