## Implementation Tasks

### Task 1: Implement Episodic Memory Service

**Architecture:** The episodic memory service manages the lifecycle of experience memories. Key behaviors:
1. **Create:** Store new episodic memory with initial importance and 0.5 confidence
2. **Retrieve:** Increment access_count and update last_accessed on every retrieval
3. **List:** Paginated retrieval with ordering options (recency, importance, confidence)
4. **Update:** Partial updates via dict, with automatic updated_at timestamp
5. **Delete:** Hard delete with cascade to graph nodes (via application logic, not DB cascade)

**File:** `backend/app/services/memory/episodic.py`

```python
from datetime import datetime
from typing import List, Optional, Tuple
from sqlalchemy.orm import Session
from sqlalchemy import desc, asc
from backend.app.models.memory.episodic import EpisodicMemory
from backend.app.schemas.memory.episodic import EpisodicMemoryCreate, EpisodicMemoryUpdate


class EpisodicMemoryService:
    """Service for managing episodic memories (experiences, events, conversations)."""
    
    def __init__(self, db: Session):
        self.db = db
    
    async def create(self, user_id: int, data: EpisodicMemoryCreate) -> EpisodicMemory:
        """Store a new episodic memory.
        
        Args:
            user_id: Owner's user ID
            data: Validated creation schema
            
        Returns:
            Created EpisodicMemory with generated ID
            
        Raises:
            ValueError: If content exceeds 10000 characters
        """
        memory = EpisodicMemory(
            user_id=user_id,
            content=data.content,
            context=data.context,
            emotion=data.emotion,
            importance=data.importance,
            confidence=0.5,
            recency_score=1.0,
            access_count=0,
            created_at=datetime.utcnow(),
            updated_at=datetime.utcnow()
        )
        self.db.add(memory)
        self.db.commit()
        self.db.refresh(memory)
        return memory
    
    async def retrieve(self, user_id: int, memory_id: int) -> Optional[EpisodicMemory]:
        """Retrieve a specific episodic memory.
        
        Side effects: Increments access_count, updates last_accessed.
        """
        memory = self.db.query(EpisodicMemory).filter(
            EpisodicMemory.id == memory_id,
            EpisodicMemory.user_id == user_id
        ).first()
        if memory:
            memory.access_count += 1
            memory.last_accessed = datetime.utcnow()
            self.db.commit()
        return memory
    
    async def list_recent(
        self, user_id: int, limit: int = 10, offset: int = 0
    ) -> Tuple[List[EpisodicMemory], int]:
        """List recent episodic memories with pagination.
        
        Returns:
            Tuple of (memories, total_count)
        """
        query = self.db.query(EpisodicMemory).filter(
            EpisodicMemory.user_id == user_id
        )
        total = query.count()
        memories = query.order_by(
            desc(EpisodicMemory.created_at)
        ).offset(offset).limit(limit).all()
        return memories, total
    
    async def list_by_importance(
        self, user_id: int, min_importance: float = 0.5, limit: int = 10
    ) -> List[EpisodicMemory]:
        """List episodic memories above an importance threshold."""
        return self.db.query(EpisodicMemory).filter(
            EpisodicMemory.user_id == user_id,
            EpisodicMemory.importance >= min_importance
        ).order_by(desc(EpisodicMemory.importance)).limit(limit).all()
    
    async def update(
        self, user_id: int, memory_id: int, data: EpisodicMemoryUpdate
    ) -> Optional[EpisodicMemory]:
        """Update an episodic memory with partial data."""
        memory = self.db.query(EpisodicMemory).filter(
            EpisodicMemory.id == memory_id,
            EpisodicMemory.user_id == user_id
        ).first()
        if not memory:
            return None
        
        update_data = data.model_dump(exclude_unset=True)
        for key, value in update_data.items():
            setattr(memory, key, value)
        memory.updated_at = datetime.utcnow()
        self.db.commit()
        self.db.refresh(memory)
        return memory
    
    async def delete(self, user_id: int, memory_id: int) -> bool:
        """Delete an episodic memory.
        
        Also cleans up associated graph nodes and edges.
        """
        memory = self.db.query(EpisodicMemory).filter(
            EpisodicMemory.id == memory_id,
            EpisodicMemory.user_id == user_id
        ).first()
        if not memory:
            return False
        
        # Clean up graph references first
        from backend.app.models.memory.graph import MemoryNode, MemoryEdge
        nodes = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id,
            MemoryNode.memory_type == "episodic",
            MemoryNode.memory_id == memory_id
        ).all()
        
        for node in nodes:
            # Delete edges involving this node
            self.db.query(MemoryEdge).filter(
                (MemoryEdge.source_id == node.id) | (MemoryEdge.target_id == node.id)
            ).delete(synchronize_session="fetch")
            self.db.delete(node)
        
        self.db.delete(memory)
        self.db.commit()
        return True
    
    async def search_content(
        self, user_id: int, query: str, limit: int = 10
    ) -> List[EpisodicMemory]:
        """Fulltext search across episodic memory content.
        
        Uses ILIKE for PostgreSQL case-insensitive matching.
        In v1.07, this will be enhanced with vector similarity search.
        """
        return self.db.query(EpisodicMemory).filter(
            EpisodicMemory.user_id == user_id,
            EpisodicMemory.content.ilike(f"%{query}%")
        ).order_by(
            desc(EpisodicMemory.importance),
            desc(EpisodicMemory.created_at)
        ).limit(limit).all()
```

**Key Design Decisions:**
- `create` sets `confidence=0.5` and `recency_score=1.0` as defaults. These are managed by `ForgettingService` (P04).
- `retrieve` has side effects: it increments `access_count` and updates `last_accessed`. This is intentional — the access pattern feeds into temporal scoring.
- `delete` cascades to graph nodes and edges. This prevents orphaned graph references.
- `search_content` uses ILIKE for now. Vector search is deferred to v1.07 when embeddings are available.
- `list_recent` returns `(memories, total)` tuple for pagination support.

**Risk Notes:**
- Risk: `retrieve` side effects on every access could cause write contention. Mitigation: Acceptable for single-user local system. For multi-user, batch access_count updates.
- Risk: `delete` cascading to graph could be slow for highly-connected memories. Mitigation: Graph cleanup is bounded by number of edges per node (typically < 20).

### Task 2: Implement Semantic Memory Service

**Architecture:** The semantic memory service manages knowledge storage. Key behaviors:
1. **Create with dedup:** Before creating, check for existing semantic memories with similar content. If found, strengthen the existing memory's confidence rather than creating a duplicate.
2. **Categorized retrieval:** List by category with confidence filtering.
3. **Confidence decay support:** Exposes methods for `ForgettingService` to update confidence.

**File:** `backend/app/services/memory/semantic.py`

```python
from datetime import datetime
from typing import List, Optional, Tuple
from sqlalchemy.orm import Session
from sqlalchemy import desc
from backend.app.models.memory.semantic import SemanticMemory
from backend.app.schemas.memory.semantic import SemanticMemoryCreate, SemanticMemoryUpdate


class SemanticMemoryService:
    """Service for managing semantic memories (facts, preferences, knowledge)."""
    
    def __init__(self, db: Session):
        self.db = db
    
    async def create(self, user_id: int, data: SemanticMemoryCreate) -> SemanticMemory:
        """Store a new semantic memory.
        
        Attempts deduplication: if a memory with identical content exists,
        strengthens its confidence instead of creating a duplicate.
        """
        # Dedup check: exact content match
        existing = self.db.query(SemanticMemory).filter(
            SemanticMemory.user_id == user_id,
            SemanticMemory.content == data.content
        ).first()
        
        if existing:
            # Strengthen existing memory
            existing.confidence = min(1.0, existing.confidence + 0.1)
            existing.access_count += 1
            existing.last_accessed = datetime.utcnow()
            existing.updated_at = datetime.utcnow()
            self.db.commit()
            self.db.refresh(existing)
            return existing
        
        memory = SemanticMemory(
            user_id=user_id,
            content=data.content,
            category=data.category,
            confidence=0.5,
            source=data.source,
            access_count=0,
            created_at=datetime.utcnow(),
            updated_at=datetime.utcnow()
        )
        self.db.add(memory)
        self.db.commit()
        self.db.refresh(memory)
        return memory
    
    async def retrieve(self, user_id: int, memory_id: int) -> Optional[SemanticMemory]:
        """Retrieve a specific semantic memory.
        
        Side effects: Increments access_count, updates last_accessed.
        """
        memory = self.db.query(SemanticMemory).filter(
            SemanticMemory.id == memory_id,
            SemanticMemory.user_id == user_id
        ).first()
        if memory:
            memory.access_count += 1
            memory.last_accessed = datetime.utcnow()
            self.db.commit()
        return memory
    
    async def list_by_category(
        self, user_id: int, category: str, limit: int = 50
    ) -> List[SemanticMemory]:
        """List semantic memories by category."""
        return self.db.query(SemanticMemory).filter(
            SemanticMemory.user_id == user_id,
            SemanticMemory.category == category
        ).order_by(desc(SemanticMemory.confidence)).limit(limit).all()
    
    async def list_all(
        self, user_id: int, limit: int = 50, offset: int = 0
    ) -> Tuple[List[SemanticMemory], int]:
        """List all semantic memories with pagination."""
        query = self.db.query(SemanticMemory).filter(
            SemanticMemory.user_id == user_id
        )
        total = query.count()
        memories = query.order_by(
            desc(SemanticMemory.confidence)
        ).offset(offset).limit(limit).all()
        return memories, total
    
    async def search_content(
        self, user_id: int, query: str, limit: int = 10
    ) -> List[SemanticMemory]:
        """Fulltext search across semantic memory content."""
        return self.db.query(SemanticMemory).filter(
            SemanticMemory.user_id == user_id,
            SemanticMemory.content.ilike(f"%{query}%")
        ).order_by(
            desc(SemanticMemory.confidence),
            desc(SemanticMemory.access_count)
        ).limit(limit).all()
    
    async def update(
        self, user_id: int, memory_id: int, data: SemanticMemoryUpdate
    ) -> Optional[SemanticMemory]:
        """Update a semantic memory with partial data."""
        memory = self.db.query(SemanticMemory).filter(
            SemanticMemory.id == memory_id,
            SemanticMemory.user_id == user_id
        ).first()
        if not memory:
            return None
        
        update_data = data.model_dump(exclude_unset=True)
        for key, value in update_data.items():
            setattr(memory, key, value)
        memory.updated_at = datetime.utcnow()
        self.db.commit()
        self.db.refresh(memory)
        return memory
    
    async def delete(self, user_id: int, memory_id: int) -> bool:
        """Delete a semantic memory with graph cleanup."""
        memory = self.db.query(SemanticMemory).filter(
            SemanticMemory.id == memory_id,
            SemanticMemory.user_id == user_id
        ).first()
        if not memory:
            return False
        
        # Clean up graph references
        from backend.app.models.memory.graph import MemoryNode, MemoryEdge
        nodes = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id,
            MemoryNode.memory_type == "semantic",
            MemoryNode.memory_id == memory_id
        ).all()
        
        for node in nodes:
            self.db.query(MemoryEdge).filter(
                (MemoryEdge.source_id == node.id) | (MemoryEdge.target_id == node.id)
            ).delete(synchronize_session="fetch")
            self.db.delete(node)
        
        self.db.delete(memory)
        self.db.commit()
        return True
    
    async def get_categories(self, user_id: int) -> List[dict]:
        """Get all categories with counts for this user.
        
        Returns:
            [{"category": "preference", "count": 15}, ...]
        """
        from sqlalchemy import func
        results = self.db.query(
            SemanticMemory.category,
            func.count(SemanticMemory.id).label("count")
        ).filter(
            SemanticMemory.user_id == user_id
        ).group_by(SemanticMemory.category).all()
        
        return [{"category": r.category, "count": r.count} for r in results]
```

**Key Design Decisions:**
- **Deduplication:** Exact content match triggers confidence strengthening instead of duplication. This prevents knowledge bloat. In v1.07, semantic similarity dedup will be added.
- **`get_categories`:** Provides aggregated category counts for the frontend dashboard. Avoids N+1 queries.
- **`search_content`:** Orders by confidence first, then access count. High-confidence, frequently-accessed knowledge surfaces first.

**Risk Notes:**
- Risk: Exact-match dedup misses near-duplicates ("Python is great" vs "Python is awesome"). Mitigation: Acceptable for v1.03. Semantic similarity dedup in v1.07.
- Risk: `get_categories` GROUP BY could be slow with many categories. Mitigation: Categories are bounded (typically < 20). Index on `(user_id, category)` helps.

### Task 3: Create Service Factory and Package Init

**Architecture:** The service factory provides a single entry point for all memory services. It follows the constructor injection pattern: pass a `db` Session, get access to all memory services. This avoids creating multiple service instances per request.

**File:** `backend/app/services/memory/__init__.py`

```python
from .episodic import EpisodicMemoryService
from .semantic import SemanticMemoryService
from sqlalchemy.orm import Session


class MemoryServiceFactory:
    """Factory for creating memory services with shared database session.
    
    Usage:
        factory = MemoryServiceFactory(db)
        episodic_memory = await factory.episodic.create(user_id, data)
        semantic_memory = await factory.semantic.create(user_id, data)
    """
    
    def __init__(self, db: Session):
        self._db = db
        self._episodic: EpisodicMemoryService | None = None
        self._semantic: SemanticMemoryService | None = None
    
    @property
    def episodic(self) -> EpisodicMemoryService:
        if self._episodic is None:
            self._episodic = EpisodicMemoryService(self._db)
        return self._episodic
    
    @property
    def semantic(self) -> SemanticMemoryService:
        if self._semantic is None:
            self._semantic = SemanticMemoryService(self._db)
        return self._semantic
```

**Key Feature:** Lazy initialization — services are only created when accessed. This avoids unnecessary object creation in requests that only need one service type.

## Performance Considerations

| Operation | Expected Latency | Notes |
|-----------|-----------------|-------|
| Create episodic | < 30ms | Single INSERT + commit |
| Retrieve by ID | < 10ms | PK lookup + UPDATE (access_count) |
| List recent (10 items) | < 20ms | Indexed query on `(user_id, created_at)` |
| Search content ILIKE | < 100ms for 10K memories | Full table scan. Optimized in v1.07 with trigram index |
| Dedup check (semantic) | < 10ms | Exact content lookup |

**Caching Opportunities:**
- Cache semantic memory categories: `get_categories` results cached in Redis for 5 minutes
- Cache frequently accessed episodic memories: LRU cache for last 100 accessed per user

## Cross-Domain Integration

- **v1.02 Event System:** Memory creation can emit `memory.episodic.created` and `memory.semantic.created` events for future consumers (e.g., auto-connection in P03).
- **v1.04 Awareness:** File changes can trigger episodic memory creation ("user modified file X").
- **v1.03 P03 (Working Memory):** Working memory items can reference episodic/semantic memories via memory IDs.
- **v1.03 P04 (Search):** Search service calls `search_content` on both services and merges results.

---

## Security Considerations

- **User isolation:** Every query includes `user_id` filter. Service methods require `user_id` as first parameter.
- **Input validation:** Pydantic schemas enforce content length (10,000 chars) and reject secrets via regex.
- **No SQL injection:** All queries use SQLAlchemy ORM parameterized queries.
- **No data leakage:** `search_content` is scoped to `user_id`. Cross-user search is impossible.
- **Hard delete:** `delete` permanently removes data (no soft-delete). Supports GDPR Article 17.
