## Implementation Tasks

### Task 1: Create Episodic Memory Model

**Architecture:** Episodic memory stores experiences with full temporal context. The model supports Ebbinghaus-style decay via `recency_score` and `confidence` columns. The `context` JSON column stores provenance metadata (source, trigger, environment). The `temporal_context` JSON stores time-of-day patterns for contextual retrieval.

**File:** `backend/app/models/memory/episodic.py`

```python
from sqlalchemy import Column, Integer, String, Text, DateTime, Float, JSON, ForeignKey, Index
from sqlalchemy.orm import relationship
from datetime import datetime
from backend.app.db.base import Base


class EpisodicMemory(Base):
    """Stores experiences, events, and conversations with temporal context."""
    
    __tablename__ = "episodic_memories"
    
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey("users.id"), nullable=False, index=True)
    content = Column(Text, nullable=False)  # What happened (max 10000 chars enforced by schema)
    context = Column(JSON)  # {"source": "chat", "trigger": "user_question", "environment": "terminal"}
    emotion = Column(String(50))  # Optional emotion tag: "neutral", "frustrated", "excited"
    importance = Column(Float, default=0.5, nullable=False)  # 0.0-1.0, set at creation
    confidence = Column(Float, default=0.5, nullable=False)  # 0.0-1.0, decays over time
    access_count = Column(Integer, default=0, nullable=False)  # Increments on retrieval
    last_accessed = Column(DateTime)  # Updated on each retrieval
    created_at = Column(DateTime, default=datetime.utcnow, nullable=False)
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
    expires_at = Column(DateTime)  # Optional hard expiry for session memories
    temporal_context = Column(JSON)  # {"time_of_day": "morning", "day_of_week": "monday"}
    recency_score = Column(Float, default=1.0, nullable=False)  # Decays via ForgettingService
    
    # Relationships
    nodes = relationship("MemoryNode", back_populates="episodic_memory", lazy="selectin")
    
    # Composite indexes for common query patterns
    __table_args__ = (
        Index("ix_episodic_user_created", "user_id", "created_at"),
        Index("ix_episodic_user_importance", "user_id", "importance"),
        Index("ix_episodic_user_confidence", "user_id", "confidence"),
        Index("ix_episodic_user_recency", "user_id", "recency_score"),
    )
```

**Key Design Decisions:**
- `confidence` starts at 0.5 and decays via `ForgettingService`. Floor is 0.05 (never fully zero until garbage collected).
- `importance` is set at creation and stays fixed. It represents intrinsic importance, not time-dependent relevance.
- `recency_score` is a materialized column updated by `ForgettingService`, avoiding expensive real-time computation during search.
- `temporal_context` enables "what was I doing at this time last week?" queries.
- `context` JSON tracks provenance: where the memory came from, what triggered it.
- Composite indexes optimize the most common query patterns: user+time, user+importance, user+confidence.

**Risk Notes:**
- Risk: `content` column size grows unbounded. Mitigation: Pydantic schema enforces 10,000 char limit.
- Risk: JSON columns may not index well in PostgreSQL. Mitigation: Use GIN index on `context` if query patterns require it (deferred to v1.07).
- Risk: `onupdate=datetime.utcnow` uses Python time, not DB time. Mitigation: Acceptable for our use case; precision is seconds, not microseconds.

### Task 2: Create Semantic Memory Model

**Architecture:** Semantic memory stores facts, preferences, concepts, and knowledge. Unlike episodic memory, semantic memories are timeless — they represent "what is true" rather than "what happened." The `category` field enables type-based retrieval (preference, fact, concept, rule, definition). The `source` field tracks provenance for knowledge reliability assessment.

**File:** `backend/app/models/memory/semantic.py`

```python
from sqlalchemy import Column, Integer, String, Text, DateTime, Float, ForeignKey, Index
from sqlalchemy.orm import relationship
from datetime import datetime
from backend.app.db.base import Base


class SemanticMemory(Base):
    """Stores facts, preferences, concepts, and knowledge."""
    
    __tablename__ = "semantic_memories"
    
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey("users.id"), nullable=False, index=True)
    content = Column(Text, nullable=False)  # The fact/knowledge statement
    category = Column(String(100), index=True)  # "preference", "fact", "concept", "rule", "definition"
    confidence = Column(Float, default=0.5, nullable=False)  # 0.0-1.0, decays slowly
    source = Column(String(200))  # Where this came from: "user_input", "inferred", "learned"
    access_count = Column(Integer, default=0, nullable=False)
    last_accessed = Column(DateTime)
    created_at = Column(DateTime, default=datetime.utcnow, nullable=False)
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
    
    # Relationships
    nodes = relationship("MemoryNode", back_populates="semantic_memory", lazy="selectin")
    
    __table_args__ = (
        Index("ix_semantic_user_category", "user_id", "category"),
        Index("ix_semantic_user_confidence", "user_id", "confidence"),
    )
```

**Key Design Decisions:**
- Semantic memories decay 2x slower than episodic (`0.005` vs `0.01` daily). Facts are more stable than experiences.
- `category` is a free-form string, not an enum, to allow user-defined categories without migrations.
- `source` tracks whether the memory was explicitly stated by the user, inferred by the system, or learned from patterns.
- No `expires_at` — semantic memories don't expire by default. They only fade via confidence decay.

**Risk Notes:**
- Risk: Free-form `category` leads to inconsistent categorization (e.g., "preference" vs "Preference" vs "user_preference"). Mitigation: Pydantic validator normalizes to lowercase.
- Risk: Duplicate semantic memories from repeated user input. Mitigation: Deduplication logic in `SemanticMemoryService` (P02).

### Task 3: Create Working Memory Model

**Architecture:** Working memory is session-scoped, volatile context. It implements a slot-based model: "active" items are in current focus, "buffer" items are ready for promotion, "archive" items are retained but not active. Items auto-expire after 1 hour (configurable). This is the cognitive architecture's short-term memory buffer.

**File:** `backend/app/models/memory/working.py`

```python
from sqlalchemy import Column, Integer, String, Text, DateTime, ForeignKey, Index
from datetime import datetime
from backend.app.db.base import Base


class WorkingMemory(Base):
    """Session-scoped working context with slot-based management."""
    
    __tablename__ = "working_memories"
    
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey("users.id"), nullable=False, index=True)
    session_id = Column(String(100), nullable=False)  # UUID session identifier
    content = Column(Text, nullable=False)  # The context item
    slot = Column(String(50), default="active", nullable=False)  # "active", "buffer", "archive"
    priority = Column(Integer, default=0, nullable=False)  # Higher = more important
    created_at = Column(DateTime, default=datetime.utcnow, nullable=False)
    expires_at = Column(DateTime, nullable=False)  # Auto-cleanup threshold
    
    __table_args__ = (
        Index("ix_working_user_session", "user_id", "session_id"),
        Index("ix_working_user_session_slot", "user_id", "session_id", "slot"),
        Index("ix_working_expires", "expires_at"),
    )
```

**Key Design Decisions:**
- `session_id` is a client-generated UUID. The backend never creates sessions — it stores context for a given session.
- `expires_at` is required (not nullable) to ensure cleanup. Default TTL is 1 hour.
- The triple-column index `(user_id, session_id, slot)` optimizes the most common query: "get active items for this session."
- `priority` enables ranking within a slot. Higher priority items are promoted first.

**Risk Notes:**
- Risk: Orphaned working memory entries accumulate if cleanup doesn't run. Mitigation: Background task runs `cleanup_expired` every 5 minutes.
- Risk: Session ID collision. Mitigation: UUID4 has 2^122 collision probability. Acceptable.

### Task 4: Create Memory Graph Models

**Architecture:** The memory graph uses an adjacency list pattern (source_id → target_id) stored in PostgreSQL. This is simpler than a dedicated graph database (Neo4j) but sufficient for v1.03. The `MemoryNode` model is polymorphic — it can point to either an episodic or semantic memory via `memory_type` + `memory_id`. This avoids a single FK constraint but requires application-level validation.

**File:** `backend/app/models/memory/graph.py`

```python
from sqlalchemy import Column, Integer, String, DateTime, Float, ForeignKey, Index, UniqueConstraint
from sqlalchemy.orm import relationship
from datetime import datetime
from backend.app.db.base import Base


class MemoryNode(Base):
    """A node in the memory graph, pointing to an episodic or semantic memory."""
    
    __tablename__ = "memory_nodes"
    
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey("users.id"), nullable=False, index=True)
    memory_type = Column(String(50), nullable=False)  # "episodic", "semantic"
    memory_id = Column(Integer, nullable=False)  # FK to episodic_memories.id or semantic_memories.id
    label = Column(String(200), nullable=False)  # Short human-readable description
    embedding_id = Column(String(100))  # Vector DB reference (for future Qdrant integration)
    created_at = Column(DateTime, default=datetime.utcnow, nullable=False)
    
    # Relationships
    episodic_memory = relationship(
        "EpisodicMemory", back_populates="nodes",
        foreign_keys="MemoryNode.memory_id",
        primaryjoin="and_(MemoryNode.memory_type=='episodic', MemoryNode.memory_id==EpisodicMemory.id)",
        lazy="selectin"
    )
    semantic_memory = relationship(
        "SemanticMemory", back_populates="nodes",
        foreign_keys="MemoryNode.memory_id",
        primaryjoin="and_(MemoryNode.memory_type=='semantic', MemoryNode.memory_id==SemanticMemory.id)",
        lazy="selectin"
    )
    outgoing_edges = relationship("MemoryEdge", foreign_keys="MemoryEdge.source_id", back_populates="source")
    incoming_edges = relationship("MemoryEdge", foreign_keys="MemoryEdge.target_id", back_populates="target")
    
    __table_args__ = (
        UniqueConstraint("user_id", "memory_type", "memory_id", name="uq_memory_node_target"),
        Index("ix_memory_node_user_type", "user_id", "memory_type"),
    )


class MemoryEdge(Base):
    """A weighted, directed edge between two memory nodes."""
    
    __tablename__ = "memory_edges"
    
    id = Column(Integer, primary_key=True)
    source_id = Column(Integer, ForeignKey("memory_nodes.id"), nullable=False, index=True)
    target_id = Column(Integer, ForeignKey("memory_nodes.id"), nullable=False, index=True)
    relationship = Column(String(100), nullable=False)  # "related_to", "caused_by", "part_of", "contradicts"
    weight = Column(Float, default=0.5, nullable=False)  # 0.0-1.0, strengthened/weakened over time
    created_at = Column(DateTime, default=datetime.utcnow, nullable=False)
    
    # Relationships
    source = relationship("MemoryNode", foreign_keys=[source_id], back_populates="outgoing_edges")
    target = relationship("MemoryNode", foreign_keys=[target_id], back_populates="incoming_edges")
    
    __table_args__ = (
        UniqueConstraint("source_id", "target_id", "relationship", name="uq_memory_edge"),
        Index("ix_memory_edge_source", "source_id"),
        Index("ix_memory_edge_target", "target_id"),
        Index("ix_memory_edge_weight", "weight"),
    )
```

**Key Design Decisions:**
- **Polymorphic pointing:** `memory_type` + `memory_id` instead of separate FK columns. Simpler schema, easier to extend to new memory types.
- **Unique constraints:** `(user_id, memory_type, memory_id)` prevents duplicate nodes. `(source_id, target_id, relationship)` prevents duplicate edges.
- **Directed edges:** The graph is directed. `related_to` is bidirectional (create edges both ways). `caused_by` is unidirectional.
- **Weight range 0.0-1.0:** Weights are normalized. `strengthen` adds 0.1 (capped at 1.0). `weaken` subtracts 0.1 (floored at 0.0). Edges below 0.1 are garbage-collected.
- **`embedding_id`:** Placeholder for future vector search integration. Not populated in v1.03.

**Risk Notes:**
- Risk: Polymorphic relationships don't enforce FK at DB level. Mitigation: Application-level validation in `MemoryGraphService`. Check `memory_type` matches actual model existence.
- Risk: Graph traversal performance degrades with many edges. Mitigation: Index on `(source_id)` and `(target_id)`. Limit traversal depth to 3 hops in v1.03.
- Risk: Circular edges create infinite traversal loops. Mitigation: Track visited nodes in traversal. Max depth limit.

```python
from pydantic import BaseModel, Field, field_validator
from datetime import datetime
from typing import Optional, List
import re


class EpisodicMemoryCreate(BaseModel):
    """Schema for creating a new episodic memory."""
    content: str = Field(..., min_length=1, max_length=10000, description="What happened")
    context: Optional[dict] = Field(None, description="Provenance: source, trigger, environment")
    emotion: Optional[str] = Field(None, max_length=50, description="Emotional state tag")
    importance: float = Field(0.5, ge=0.0, le=1.0, description="Intrinsic importance 0.0-1.0")
    
    @field_validator("content")
    @classmethod
    def content_must_not_contain_secrets(cls, v: str) -> str:
        """Reject content that looks like secrets."""
        secret_patterns = [
            r"(?i)api[_-]?key\s*[:=]\s*\S+",
            r"(?i)password\s*[:=]\s*\S+",
            r"(?i)token\s*[:=]\s*\S+",
            r"sk-[a-zA-Z0-9]{20,}",
        ]
        for pattern in secret_patterns:
            if re.search(pattern, v):
                raise ValueError("Content must not contain API keys, passwords, or tokens")
        return v


class EpisodicMemoryUpdate(BaseModel):
    """Schema for updating an episodic memory."""
    content: Optional[str] = Field(None, min_length=1, max_length=10000)
    context: Optional[dict] = None
    emotion: Optional[str] = Field(None, max_length=50)
    importance: Optional[float] = Field(None, ge=0.0, le=1.0)


class EpisodicMemoryResponse(BaseModel):
    """Schema for returning an episodic memory."""
    id: int
    user_id: int
    content: str
    context: Optional[dict]
    emotion: Optional[str]
    importance: float
    confidence: float
    access_count: int
    last_accessed: Optional[datetime]
    created_at: datetime
    updated_at: datetime
    recency_score: float
    
    class Config:
        from_attributes = True


class EpisodicMemoryList(BaseModel):
    """Paginated list of episodic memories."""
    memories: List[EpisodicMemoryResponse]
    total: int
    page: int = 1
    page_size: int = 10
```

**Security Validation:** The `content_must_not_contain_secrets` validator scans for common secret patterns and rejects content containing API keys, passwords, or tokens. This prevents accidental memory storage of sensitive credentials.

## Cross-Domain Integration

- **Auth Domain:** All models reference `users.id` via FK. The `get_current_user` dependency provides `user_id` for all queries.

- **Frontend (v1.03 P05):** Schemas directly map to API response models. Frontend types are generated from OpenAPI spec.
