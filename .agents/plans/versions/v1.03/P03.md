## Objective

Implement working memory (M4: session-scoped context with slot management) and memory graph (M6: nodes, edges, traversal, auto-connection). These two services complete the structural memory system — working memory provides the "right now" context buffer, and the graph provides the "how things relate" knowledge structure.

---

## Purpose

Working memory provides fast access to current conversation/task context. It implements a cognitive architecture's short-term buffer: "active" items are in focus, "buffer" items are ready for promotion, "archive" items are retained but dormant. Items auto-expire to prevent stale context accumulation.

The memory graph connects related memories into a knowledge network. When a new memory is created, the auto-connection service finds related existing memories and creates edges. This builds an associative memory structure that enables "remind me of related things" queries and supports future reasoning capabilities.

## Implementation Tasks

### Task 1: Implement Working Memory Service

**Architecture:** Working memory is a session-scoped, volatile context buffer. It implements three slots:
- **active:** Items in current cognitive focus (e.g., current task, active conversation topic)
- **buffer:** Items ready for promotion to active (e.g., related context, pending clarification)
- **archive:** Items retained but not active (e.g., completed subtasks, resolved questions)

The service manages slot transitions (promote, archive, demote) and automatic cleanup of expired items. The `expires_at` field ensures stale context is garbage-collected.

**File:** `backend/app/services/memory/working.py`

```python
from datetime import datetime, timedelta
from typing import List, Optional, Tuple
from sqlalchemy.orm import Session
from sqlalchemy import desc
from backend.app.models.memory.working import WorkingMemory

# Default working memory TTL: 1 hour
DEFAULT_TTL_HOURS = 1
# Maximum active items per session
MAX_ACTIVE_ITEMS = 20
# Maximum buffer items per session
MAX_BUFFER_ITEMS = 10


class WorkingMemoryService:
    """Service for managing session-scoped working memory.
    
    Working memory is a volatile, session-scoped context buffer.
    Items auto-expire after configurable TTL (default: 1 hour).
    """
    
    def __init__(self, db: Session):
        self.db = db
    
    async def add(
        self,
        user_id: int,
        session_id: str,
        content: str,
        slot: str = "active",
        priority: int = 0,
        ttl_hours: float = DEFAULT_TTL_HOURS
    ) -> WorkingMemory:
        """Add an item to working memory.
        
        Args:
            user_id: Owner's user ID
            session_id: Session UUID
            content: Context item content
            slot: Target slot ("active", "buffer", "archive")
            priority: Priority 0-100 (higher = more important)
            ttl_hours: Time-to-live in hours
            
        Returns:
            Created WorkingMemory item
        """
        memory = WorkingMemory(
            user_id=user_id,
            session_id=session_id,
            content=content,
            slot=slot,
            priority=priority,
            created_at=datetime.utcnow(),
            expires_at=datetime.utcnow() + timedelta(hours=ttl_hours)
        )
        self.db.add(memory)
        self.db.commit()
        self.db.refresh(memory)
        return memory
    
    async def get_active(
        self, user_id: int, session_id: str
    ) -> List[WorkingMemory]:
        """Get active items in working memory, ordered by priority."""
        return self.db.query(WorkingMemory).filter(
            WorkingMemory.user_id == user_id,
            WorkingMemory.session_id == session_id,
            WorkingMemory.slot == "active",
            WorkingMemory.expires_at > datetime.utcnow()
        ).order_by(desc(WorkingMemory.priority)).all()
    
    async def get_by_slot(
        self, user_id: int, session_id: str, slot: str
    ) -> List[WorkingMemory]:
        """Get items in a specific slot."""
        return self.db.query(WorkingMemory).filter(
            WorkingMemory.user_id == user_id,
            WorkingMemory.session_id == session_id,
            WorkingMemory.slot == slot,
            WorkingMemory.expires_at > datetime.utcnow()
        ).order_by(desc(WorkingMemory.priority)).all()
    
    async def promote(self, user_id: int, memory_id: int) -> bool:
        """Promote an item to the active slot."""
        memory = self.db.query(WorkingMemory).filter(
            WorkingMemory.id == memory_id,
            WorkingMemory.user_id == user_id
        ).first()
        if not memory:
            return False
        
        # Check active slot capacity
        active_count = self.db.query(WorkingMemory).filter(
            WorkingMemory.user_id == user_id,
            WorkingMemory.session_id == memory.session_id,
            WorkingMemory.slot == "active"
        ).count()
        
        if active_count >= MAX_ACTIVE_ITEMS:
            # Demote lowest-priority active item to buffer
            lowest = self.db.query(WorkingMemory).filter(
                WorkingMemory.user_id == user_id,
                WorkingMemory.session_id == memory.session_id,
                WorkingMemory.slot == "active"
            ).order_by(WorkingMemory.priority).first()
            if lowest:
                lowest.slot = "buffer"
        
        memory.slot = "active"
        self.db.commit()
        return True
    
    async def archive(self, user_id: int, memory_id: int) -> bool:
        """Archive an item from working memory."""
        memory = self.db.query(WorkingMemory).filter(
            WorkingMemory.id == memory_id,
            WorkingMemory.user_id == user_id
        ).first()
        if not memory:
            return False
        memory.slot = "archive"
        self.db.commit()
        return True
    
    async def demote(self, user_id: int, memory_id: int) -> bool:
        """Demote an item from active to buffer."""
        memory = self.db.query(WorkingMemory).filter(
            WorkingMemory.id == memory_id,
            WorkingMemory.user_id == user_id
        ).first()
        if not memory:
            return False
        memory.slot = "buffer"
        self.db.commit()
        return True
    
    async def remove(self, user_id: int, memory_id: int) -> bool:
        """Remove an item from working memory entirely."""
        memory = self.db.query(WorkingMemory).filter(
            WorkingMemory.id == memory_id,
            WorkingMemory.user_id == user_id
        ).first()
        if not memory:
            return False
        self.db.delete(memory)
        self.db.commit()
        return True
    
    async def cleanup_expired(self, user_id: int, session_id: str) -> int:
        """Remove expired items from working memory.
        
        Returns:
            Number of items removed
        """
        expired = self.db.query(WorkingMemory).filter(
            WorkingMemory.user_id == user_id,
            WorkingMemory.session_id == session_id,
            WorkingMemory.expires_at < datetime.utcnow()
        ).all()
        
        count = len(expired)
        for memory in expired:
            self.db.delete(memory)
        
        if count > 0:
            self.db.commit()
        return count
    
    async def clear_session(self, user_id: int, session_id: str) -> int:
        """Clear all items for a session. Used on session end."""
        items = self.db.query(WorkingMemory).filter(
            WorkingMemory.user_id == user_id,
            WorkingMemory.session_id == session_id
        ).all()
        
        count = len(items)
        for item in items:
            self.db.delete(item)
        
        if count > 0:
            self.db.commit()
        return count
    
    async def get_session_summary(self, user_id: int, session_id: str) -> dict:
        """Get a summary of working memory state for a session."""
        items = self.db.query(WorkingMemory).filter(
            WorkingMemory.user_id == user_id,
            WorkingMemory.session_id == session_id
        ).all()
        
        return {
            "total_items": len(items),
            "active": len([i for i in items if i.slot == "active"]),
            "buffer": len([i for i in items if i.slot == "buffer"]),
            "archive": len([i for i in items if i.slot == "archive"]),
            "expired": len([i for i in items if i.expires_at < datetime.utcnow()]),
        }
```

**Key Design Decisions:**
- **Slot capacity limits:** Active slot capped at 20 items. When full, lowest-priority active item is demoted to buffer. This prevents context flooding.
- **Auto-expiry:** Items have `expires_at` timestamps. `cleanup_expired` removes stale items. Can be called periodically or on-demand.
- **`clear_session`:** Provides a clean shutdown path when a session ends. Prevents orphaned working memory.
- **`get_session_summary`:** Returns slot distribution counts for monitoring/dashboard display.
- **Priority ordering:** Active items are returned sorted by priority (highest first). This enables "most important things first" retrieval.

**Risk Notes:**
- Risk: Concurrent access to same session from multiple requests could cause slot capacity race conditions. Mitigation: Acceptable for single-user local system. For multi-user, use database-level locking.
- Risk: `cleanup_expired` is O(n) for all items in session. Mitigation: Sessions typically have < 50 items. Index on `(user_id, session_id, expires_at)` optimizes this.

### Task 2: Implement Memory Graph Service

**Architecture:** The memory graph service manages nodes and edges. It provides:
1. **Node management:** Create, get, delete nodes
2. **Edge management:** Create, strengthen, weaken, delete edges
3. **Traversal:** Get connected nodes (1-hop), BFS traversal (multi-hop with depth limit)
4. **Path finding:** Find shortest path between two nodes (BFS-based)

**File:** `backend/app/services/memory/graph.py`

```python
from typing import List, Optional, Set
from collections import deque
from sqlalchemy.orm import Session
from sqlalchemy import desc
from backend.app.models.memory.graph import MemoryNode, MemoryEdge


class MemoryGraphService:
    """Service for managing the memory graph (nodes, edges, traversal)."""
    
    def __init__(self, db: Session):
        self.db = db
    
    # --- Node Operations ---
    
    async def add_node(
        self, user_id: int, memory_type: str, memory_id: int, label: str
    ) -> MemoryNode:
        """Add a node to the memory graph.
        
        Args:
            user_id: Owner's user ID
            memory_type: "episodic" or "semantic"
            memory_id: ID of the target memory
            label: Short human-readable description
        """
        # Check for duplicate
        existing = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id,
            MemoryNode.memory_type == memory_type,
            MemoryNode.memory_id == memory_id
        ).first()
        
        if existing:
            return existing  # Idempotent
        
        node = MemoryNode(
            user_id=user_id,
            memory_type=memory_type,
            memory_id=memory_id,
            label=label
        )
        self.db.add(node)
        self.db.commit()
        self.db.refresh(node)
        return node
    
    async def get_node(self, node_id: int) -> Optional[MemoryNode]:
        """Get a node by ID."""
        return self.db.query(MemoryNode).filter(
            MemoryNode.id == node_id
        ).first()
    
    async def get_user_nodes(
        self, user_id: int, memory_type: Optional[str] = None, limit: int = 100
    ) -> List[MemoryNode]:
        """Get all nodes for a user, optionally filtered by type."""
        query = self.db.query(MemoryNode).filter(MemoryNode.user_id == user_id)
        if memory_type:
            query = query.filter(MemoryNode.memory_type == memory_type)
        return query.limit(limit).all()
    
    async def delete_node(self, user_id: int, node_id: int) -> bool:
        """Delete a node and all its edges."""
        node = self.db.query(MemoryNode).filter(
            MemoryNode.id == node_id,
            MemoryNode.user_id == user_id
        ).first()
        if not node:
            return False
        
        # Delete all edges involving this node
        self.db.query(MemoryEdge).filter(
            (MemoryEdge.source_id == node_id) | (MemoryEdge.target_id == node_id)
        ).delete(synchronize_session="fetch")
        
        self.db.delete(node)
        self.db.commit()
        return True
    
    # --- Edge Operations ---
    
    async def add_edge(
        self,
        source_id: int,
        target_id: int,
        relationship: str,
        weight: float = 0.5,
        bidirectional: bool = False
    ) -> MemoryEdge:
        """Add an edge to the memory graph.
        
        Args:
            source_id: Source node ID
            target_id: Target node ID
            relationship: Edge type ("related_to", "caused_by", "part_of", "contradicts")
            weight: Edge weight 0.0-1.0
            bidirectional: If True, create reverse edge too
        """
        if source_id == target_id:
            raise ValueError("Self-loops are not allowed")
        
        # Check for existing edge
        existing = self.db.query(MemoryEdge).filter(
            MemoryEdge.source_id == source_id,
            MemoryEdge.target_id == target_id,
            MemoryEdge.relationship == relationship
        ).first()
        
        if existing:
            # Strengthen existing edge instead of duplicating
            existing.weight = min(1.0, existing.weight + 0.05)
            self.db.commit()
            return existing
        
        edge = MemoryEdge(
            source_id=source_id,
            target_id=target_id,
            relationship=relationship,
            weight=weight
        )
        self.db.add(edge)
        
        if bidirectional:
            reverse = MemoryEdge(
                source_id=target_id,
                target_id=source_id,
                relationship=relationship,
                weight=weight
            )
            self.db.add(reverse)
        
        self.db.commit()
        self.db.refresh(edge)
        return edge
    
    async def get_edges_for_node(self, node_id: int) -> List[MemoryEdge]:
        """Get all edges involving a node (incoming + outgoing)."""
        return self.db.query(MemoryEdge).filter(
            (MemoryEdge.source_id == node_id) | (MemoryEdge.target_id == node_id)
        ).order_by(desc(MemoryEdge.weight)).all()
    
    async def strengthen_edge(self, edge_id: int, amount: float = 0.1) -> Optional[MemoryEdge]:
        """Strengthen a connection between memories."""
        edge = self.db.query(MemoryEdge).filter(MemoryEdge.id == edge_id).first()
        if edge:
            edge.weight = min(1.0, edge.weight + amount)
            self.db.commit()
        return edge
    
    async def weaken_edge(self, edge_id: int, amount: float = 0.1) -> Optional[MemoryEdge]:
        """Weaken a connection between memories."""
        edge = self.db.query(MemoryEdge).filter(MemoryEdge.id == edge_id).first()
        if edge:
            edge.weight = max(0.0, edge.weight - amount)
            self.db.commit()
        return edge
    
    async def delete_edge(self, edge_id: int) -> bool:
        """Delete a specific edge."""
        edge = self.db.query(MemoryEdge).filter(MemoryEdge.id == edge_id).first()
        if not edge:
            return False
        self.db.delete(edge)
        self.db.commit()
        return True
    
    # --- Traversal Operations ---
    
    async def get_connections(self, node_id: int, depth: int = 1) -> List[MemoryNode]:
        """Get all connected nodes up to N hops away.
        
        Uses BFS traversal with depth limit to prevent runaway queries.
        """
        visited: Set[int] = {node_id}
        result: List[MemoryNode] = []
        queue = deque([(node_id, 0)])
        
        while queue:
            current_id, current_depth = queue.popleft()
            if current_depth >= depth:
                continue
            
            edges = self.db.query(MemoryEdge).filter(
                (MemoryEdge.source_id == current_id) | (MemoryEdge.target_id == current_id)
            ).all()
            
            for edge in edges:
                neighbor_id = edge.target_id if edge.source_id == current_id else edge.source_id
                if neighbor_id not in visited:
                    visited.add(neighbor_id)
                    node = await self.get_node(neighbor_id)
                    if node:
                        result.append(node)
                        queue.append((neighbor_id, current_depth + 1))
        
        return result
    
    async def find_path(
        self, source_id: int, target_id: int, max_depth: int = 5
    ) -> Optional[List[MemoryNode]]:
        """Find shortest path between two nodes using BFS.
        
        Returns:
            List of nodes from source to target, or None if no path.
        """
        if source_id == target_id:
            node = await self.get_node(source_id)
            return [node] if node else None
        
        visited: Set[int] = {source_id}
        queue = deque([(source_id, [source_id])])
        
        while queue:
            current_id, path = queue.popleft()
            if len(path) > max_depth:
                continue
            
            edges = self.db.query(MemoryEdge).filter(
                (MemoryEdge.source_id == current_id) | (MemoryEdge.target_id == current_id)
            ).all()
            
            for edge in edges:
                neighbor_id = edge.target_id if edge.source_id == current_id else edge.source_id
                
                if neighbor_id == target_id:
                    # Found path
                    full_path = path + [neighbor_id]
                    nodes = []
                    for nid in full_path:
                        node = await self.get_node(nid)
                        if node:
                            nodes.append(node)
                    return nodes
                
                if neighbor_id not in visited:
                    visited.add(neighbor_id)
                    queue.append((neighbor_id, path + [neighbor_id]))
        
        return None  # No path found
    
    async def get_strongest_connections(
        self, user_id: int, limit: int = 10
    ) -> List[MemoryEdge]:
        """Get the strongest edges in the user's graph."""
        return self.db.query(MemoryEdge).join(
            MemoryNode, MemoryEdge.source_id == MemoryNode.id
        ).filter(
            MemoryNode.user_id == user_id
        ).order_by(
            desc(MemoryEdge.weight)
        ).limit(limit).all()
    
    async def get_graph_stats(self, user_id: int) -> dict:
        """Get statistics about the user's memory graph."""
        from sqlalchemy import func
        
        total_nodes = self.db.query(MemoryNode).filter(
            MemoryNode.user_id == user_id
        ).count()
        
        # Count edges via join
        total_edges = self.db.query(MemoryEdge).join(
            MemoryNode, MemoryEdge.source_id == MemoryNode.id
        ).filter(MemoryNode.user_id == user_id).count()
        
        nodes_by_type = {}
        for memory_type in ["episodic", "semantic"]:
            count = self.db.query(MemoryNode).filter(
                MemoryNode.user_id == user_id,
                MemoryNode.memory_type == memory_type
            ).count()
            nodes_by_type[memory_type] = count
        
        avg_weight_result = self.db.query(func.avg(MemoryEdge.weight)).join(
            MemoryNode, MemoryEdge.source_id == MemoryNode.id
        ).filter(MemoryNode.user_id == user_id).scalar()
        
        return {
            "total_nodes": total_nodes,
            "total_edges": total_edges,
            "nodes_by_type": nodes_by_type,
            "avg_edge_weight": float(avg_weight_result or 0.0),
        }
```

**Key Design Decisions:**
- **Idempotent add_node:** Duplicate nodes (same memory_type + memory_id) are silently returned instead of failing. This makes the service safe to call multiple times.
- **Edge strengthening on duplicate:** Creating an existing edge strengthens it instead of duplicating. This is the "reinforcement" mechanism.
- **BFS traversal with depth limit:** Prevents runaway queries on large graphs. Default depth limit is 1 (direct connections only). Maximum is 5.
- **Self-loop prevention:** `add_edge` raises ValueError for source_id == target_id.
- **`find_path`:** BFS-based shortest path. Returns list of nodes. Useful for "how are these memories related?" queries.

**Risk Notes:**
- Risk: BFS traversal loads all edges into memory. Mitigation: Depth limit (5) bounds the search space. For large graphs (10K+ edges), consider cursor-based traversal in v1.07.
- Risk: `get_strongest_connections` joins across tables. Mitigation: Index on `MemoryEdge.weight` and `MemoryNode.user_id` support this query.
- Risk: Circular edges cause infinite traversal loops. Mitigation: `visited` set prevents revisiting nodes.

### Task 3: Implement Auto-Connection Service

**Architecture:** Auto-connection finds related memories and creates graph edges between them. In v1.03, it uses keyword-based matching: extract keywords from new memory content, search for existing memories containing those keywords, and create edges. In v1.07, this will be enhanced with embedding-based similarity.

**File:** `backend/app/services/memory/auto_connect.py`

```python
import re
from typing import List, Set
from sqlalchemy.orm import Session
from backend.app.models.memory.episodic import EpisodicMemory
from backend.app.models.memory.semantic import SemanticMemory
from backend.app.models.memory.graph import MemoryNode, MemoryEdge
from backend.app.services.memory.graph import MemoryGraphService


# Common stop words to exclude from keyword extraction
STOP_WORDS: Set[str] = {
    "the", "a", "an", "is", "are", "was", "were", "be", "been", "being",
    "have", "has", "had", "do", "does", "did", "will", "would", "could",
    "should", "may", "might", "shall", "can", "need", "dare", "ought",
    "used", "to", "of", "in", "for", "on", "with", "at", "by", "from",
    "as", "into", "through", "during", "before", "after", "above", "below",
    "between", "out", "off", "over", "under", "again", "further", "then",
    "once", "here", "there", "when", "where", "why", "how", "all", "both",
    "each", "few", "more", "most", "other", "some", "such", "no", "nor",
    "not", "only", "own", "same", "so", "than", "too", "very", "just",
    "because", "but", "and", "or", "if", "while", "about", "it", "its",
    "this", "that", "these", "those", "i", "me", "my", "we", "our", "you",
    "your", "he", "him", "his", "she", "her", "they", "them", "their",
}

# Minimum keyword length
MIN_KEYWORD_LENGTH = 3


class AutoConnectionService:
    """Automatically creates connections between related memories.
    
    Uses keyword-based matching in v1.03. Will be enhanced with
    embedding similarity in v1.07.
    """
    
    def __init__(self, db: Session):
        self.db = db
        self.graph = MemoryGraphService(db)
    
    def _extract_keywords(self, content: str) -> Set[str]:
        """Extract meaningful keywords from content."""
        # Lowercase and split on non-alphanumeric
        words = re.findall(r'[a-z0-9]+', content.lower())
        return {
            w for w in words
            if len(w) >= MIN_KEYWORD_LENGTH and w not in STOP_WORDS
        }
    
    async def connect_related(
        self,
        user_id: int,
        memory_type: str,
        memory_id: int,
        content: str,
        max_connections: int = 5
    ) -> List[MemoryEdge]:
        """Find and connect related memories.
        
        Args:
            user_id: Owner's user ID
            memory_type: "episodic" or "semantic"
            memory_id: ID of the new memory
            content: Content text to extract keywords from
            max_connections: Maximum edges to create
            
        Returns:
            List of created edges
        """
        # Get or create the node for this memory
        source_node = await self.graph.add_node(
            user_id=user_id,
            memory_type=memory_type,
            memory_id=memory_id,
            label=content[:100]  # First 100 chars as label
        )
        
        # Extract keywords
        keywords = self._extract_keywords(content)
        if not keywords:
            return []
        
        # Search for related memories (excluding this one)
        related_memories = []
        
        # Search episodic memories
        episodic = self.db.query(EpisodicMemory).filter(
            EpisodicMemory.user_id == user_id,
            EpisodicMemory.id != memory_id if memory_type == "episodic" else True
        ).all()
        
        for mem in episodic:
            mem_keywords = self._extract_keywords(mem.content)
            overlap = keywords & mem_keywords
            if overlap:
                related_memories.append(("episodic", mem.id, len(overlap), mem.content))
        
        # Search semantic memories
        semantic = self.db.query(SemanticMemory).filter(
            SemanticMemory.user_id == user_id,
            SemanticMemory.id != memory_id if memory_type == "semantic" else True
        ).all()
        
        for mem in semantic:
            mem_keywords = self._extract_keywords(mem.content)
            overlap = keywords & mem_keywords
            if overlap:
                related_memories.append(("semantic", mem.id, len(overlap), mem.content))
        
        # Sort by keyword overlap (most related first)
        related_memories.sort(key=lambda x: x[2], reverse=True)
        related_memories = related_memories[:max_connections]
        
        # Create edges
        created_edges = []
        for mem_type, mem_id, overlap_count, mem_content in related_memories:
            # Get or create target node
            target_node = await self.graph.add_node(
                user_id=user_id,
                memory_type=mem_type,
                memory_id=mem_id,
                label=mem_content[:100]
            )
            
            # Calculate weight based on keyword overlap
            weight = min(1.0, overlap_count / max(len(keywords), 1))
            
            # Create bidirectional edge
            edge = await self.graph.add_edge(
                source_id=source_node.id,
                target_id=target_node.id,
                relationship="related_to",
                weight=weight,
                bidirectional=True
            )
            created_edges.append(edge)
        
        return created_edges
```

**Key Design Decisions:**
- **Keyword-based matching:** Simple, fast, explainable. Good enough for v1.03. Embedding similarity in v1.07.
- **Stop word filtering:** Removes common words that don't carry meaning. Improves signal-to-noise.
- **Overlap-based weight:** Weight = |overlap| / |keywords|. More overlap = stronger connection.
- **Bidirectional edges:** "Related to" is inherently bidirectional. Both directions are created.
- **Max connections limit:** Prevents creating too many edges for highly-connected memories.

**Risk Notes:**
- Risk: Keyword matching creates noisy connections for common words. Mitigation: Stop words filter. Min keyword length of 3 chars.
- Risk: `connect_related` does N+1 queries for related memories. Mitigation: Batch query with keyword search. For v1.07, use vector similarity for O(1) lookup.

## Security Considerations

- **User isolation:** All graph queries scoped by `user_id`. Traversal cannot cross user boundaries.
- **Depth limit:** BFS traversal limited to 5 hops to prevent resource exhaustion.
- **Node count limit:** `get_user_nodes` limited to 100 results. Full scan requires pagination.
- **Auto-connect scope:** Only searches within the same user's memories.
