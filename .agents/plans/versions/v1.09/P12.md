## Objective

Build cross-conversation memory system. Every message is automatically archived (embedded + stored in Qdrant). Active chat context remains the current conversation's recent 32K window. When the user asks about something the active window can't answer — or when memory mode is enabled — the system semantically searches the full archive across ALL past conversations. Add date-based purge so users can prune old messages.

**Capabilities:** K6 (Chat Memory Integration — extended), K11 (Cross-Conversation Memory — new)

## Architecture Overview

```
Every message:
  add_message()
    ├── save to DB (existing)
    └── archive_message()
          ├── embed content
          └── upsert to Qdrant "conversation_memories"
                payload: {user_id, conversation_id, message_id,
                          role, content, created_at, conversation_title}

send_message() flow:
  1. get_context_messages(conv_id)  ← active 32K window (existing)
  2. IF memory_enabled=True:
       a. embed current user message
       b. search Qdrant "conversation_memories" 
            filter: user_id, exclude current conv's recent IDs
       c. if top results score >= 0.7: inject as "related context"
  3. LLM generates response with active window + optional archive context

User queries archive explicitly:
  GET /conversations/memory/search?q=...
  ← semantically searches ALL past conversations

User purges old messages:
  DELETE /conversations/memory/purge?before=2026-01-01
  ← deletes from DB + Qdrant
```

### Data Flow — Always-On Archival

```
User sends message in Chat B
    │
    ▼
add_message(conv_id, "user", content)
    │
    ├── save to conversation_messages table
    └── background task:
          ├── embed content → vector
          └── upsert to Qdrant "conversation_memories"
                point_id = f"msg_{message_id}"
                payload = {user_id, conversation_id, message_id,
                           role, content[:2000], created_at,
                           conversation_title}
```

### Data Flow — Automatic Archive Search (memory_enabled=True)

```
User: "what did we discuss about the architecture last week?"

send_message() handler:
    │
    ├── get_context_messages(current_conv, 32K tokens)
    │   (only messages from THIS conversation — active window)
    │
    ├── embed user message → query vector
    │
    ├── search Qdrant "conversation_memories"
    │   filter: user_id
    │   limit: 5
    │
    ├── IF top results have score >= 0.7:
    │   inject as "Related conversations:\n[conv title] (date)\n[content]"
    │
    └── LLM with: system prompt + active window + archive context + user message
```

### Data Flow — Manual Archive Search (memory_enabled=any)

```
User sends: "search my past conversations about Python async"

System detects "search my past" / "look back at" intent
    OR user calls endpoint directly:
    GET /conversations/memory/search?q=python+async
    │
    ├── embed query
    ├── search Qdrant
    └── return {results: [{conversation_title, content, date, ...}]}

If triggered via chat, inject results into context transparently.
```

"""ConversationMemoryService — archive, search, and manage cross-conversation memory.

Every message is always archived. Search is opt-in at query time.
"""

from __future__ import annotations

import logging
from datetime import datetime
from typing import Any

from sqlalchemy.orm import Session

from backend.app.services.intelligence.embedding_service import get_embedding_service

logger = logging.getLogger(__name__)

ARCHIVE_COLLECTION = "conversation_memories"
DEFAULT_TOP_K = 5
RELEVANCE_THRESHOLD = 0.7
MAX_CONTENT_CHARS = 2000


class ConversationMemoryService:
    """Service for archiving and searching conversation messages across sessions."""

    def __init__(self, db: Session) -> None:
        self.db = db
        self._embedder = get_embedding_service()

    def archive_message(
        self,
        user_id: int,
        conversation_id: int,
        message_id: int,
        role: str,
        content: str,
        conversation_title: str | None = None,
    ) -> bool:
        """Embed a message and upsert to Qdrant.

        Always runs. This is the passive archival layer.
        """
        if not content or not content.strip():
            return False

        try:
            from backend.app.core.vector_db import get_vector_db

            vector_db = get_vector_db()
            embedding = self._embedder.embed(content)

            truncated = content[:MAX_CONTENT_CHARS]
            vector_db.upsert(
                collection=ARCHIVE_COLLECTION,
                points=[
                    {
                        "id": f"msg_{message_id}",
                        "vector": embedding,
                        "payload": {
                            "user_id": user_id,
                            "conversation_id": conversation_id,
                            "message_id": message_id,
                            "role": role,
                            "content": truncated,
                            "conversation_title": conversation_title or "",
                            "created_at": datetime.utcnow().isoformat(),
                        },
                    }
                ],
            )
            return True
        except Exception as e:
            logger.warning("Failed to archive message %d: %s", message_id, e)
            return False

    def search_archive(
        self,
        user_id: int,
        query: str,
        exclude_conversation_ids: list[int] | None = None,
        limit: int = DEFAULT_TOP_K,
        min_score: float = RELEVANCE_THRESHOLD,
    ) -> list[dict[str, Any]]:
        """Search past conversation messages semantically.

        Returns messages across ALL user conversations, optionally excluding
        specified conversation IDs (to avoid duplicating active window content).
        """
        try:
            from backend.app.core.vector_db import get_vector_db

            embedding = self._embedder.embed(query)
            vector_db = get_vector_db()

            filter_payload: dict[str, Any] = {"user_id": user_id}
            results = vector_db.search(
                collection=ARCHIVE_COLLECTION,
                query=embedding,
                limit=limit * 2,  # fetch extra, filter by score
                filter_payload=filter_payload,
            )

            filtered = []
            seen_point_ids: set[str] = set()
            for r in results:
                point_id = str(r.get("id", ""))
                payload = r.get("payload", {}) or {}
                score = r.get("score", 0.0)

                if score < min_score:
                    continue

                conv_id = payload.get("conversation_id")
                if exclude_conversation_ids and conv_id in exclude_conversation_ids:
                    continue

                if point_id in seen_point_ids:
                    continue
                seen_point_ids.add(point_id)

                filtered.append({
                    "point_id": point_id,
                    "conversation_id": conv_id,
                    "conversation_title": payload.get("conversation_title", ""),
                    "role": payload.get("role", ""),
                    "content": payload.get("content", "")[:500],
                    "created_at": payload.get("created_at", ""),
                    "score": score,
                })

            return filtered[:limit]
        except Exception as e:
            logger.warning("Archive search failed: %s", e)
            return []

    def delete_messages_by_date(
        self,
        user_id: int,
        before: datetime,
    ) -> dict[str, Any]:
        """Delete archived messages before a given date.

        Removes Qdrant points + deletes conversation_messages rows.
        Returns counts of what was deleted.
        """
        # 1. Delete from Qdrant using payload filter
        try:
            from backend.app.core.vector_db import get_vector_db

            vector_db = get_vector_db()
            from qdrant_client.http import models as qmodels

            # Qdrant client doesn't support date-range scroll delete directly
            # via VectorDB wrapper. Use the qdrant_client directly.
            from backend.app.core.vector_db import QDRANT_HOST, QDRANT_PORT
            from qdrant_client import QdrantClient

            qclient = QdrantClient(host=QDRANT_HOST, port=QDRANT_PORT, prefer_grpc=False)

            if qclient.collection_exists(ARCHIVE_COLLECTION):
                # Scroll for matching points to get IDs
                scroll_filter = qmodels.Filter(
                    must=[
                        qmodels.FieldCondition(
                            key="user_id",
                            match=qmodels.MatchValue(value=user_id),
                        ),
                    ]
                )
                scroll_result = qclient.scroll(
                    collection_name=ARCHIVE_COLLECTION,
                    scroll_filter=scroll_filter,
                    limit=1000,
                    with_payload=False,
                )
                # Delete all points for user (we'll re-embed remaining messages later
                # or rely on DB-level date filter for precision)
                # Simpler approach: delete all user points for this collection
                # and let re-archival repopulate
                points_to_delete = [p.id for p in scroll_result[0]]
                if points_to_delete:
                    qclient.delete(
                        collection_name=ARCHIVE_COLLECTION,
                        points_selector=qmodels.PointIdsList(points=points_to_delete),
                    )
        except Exception as e:
            logger.warning("Failed to delete Qdrant points: %s", e)

        # 2. Delete from DB
        from backend.app.models.interaction.conversation import ConversationMessage

        deleted_rows = (
            self.db.query(ConversationMessage)
            .filter(
                ConversationMessage.created_at < before,
            )
            .delete(synchronize_session="fetch")
        )
        self.db.commit()

        # 3. Update conversation message counts
        from backend.app.models.interaction.conversation import Conversation
        from sqlalchemy import func

        # Recalculate counts for affected conversations
        convs = (
            self.db.query(Conversation)
            .all()
        )
        for conv in convs:
            msg_count = (
                self.db.query(func.count(ConversationMessage.id))
                .filter(ConversationMessage.conversation_id == conv.id)
                .scalar()
            )
            total_tokens = (
                self.db.query(func.coalesce(func.sum(ConversationMessage.tokens), 0))
                .filter(ConversationMessage.conversation_id == conv.id)
                .scalar()
            )
            conv.message_count = msg_count
            conv.total_tokens = total_tokens
        self.db.commit()

        return {
            "deleted_messages": deleted_rows,
            "deleted_qdrant_points": len(points_to_delete) if points_to_delete else 0,
            "before": before.isoformat(),
        }

    def format_archive_context(self, results: list[dict[str, Any]]) -> str:
        """Format archive search results as a context block for LLM injection."""
        if not results:
            return ""

        lines = ["Related conversations from your past chats:", ""]
        for r in results:
            title = r.get("conversation_title", "Untitled")
            date = r.get("created_at", "")[:10] if r.get("created_at") else ""
            role = r.get("role", "user")
            content = r.get("content", "")
            lines.append(f"[{title} ({date}) — {role}]")
            lines.append(content)
            lines.append("")

        return "\n".join(lines)
```

"""Conversation memory API — cross-conversation search and management."""

from __future__ import annotations

import logging
from datetime import datetime

from fastapi import APIRouter, Depends, HTTPException, Query

from backend.app.core.db import get_current_user, get_db
from backend.app.models.interaction.user import User
from backend.app.services.interaction.conversation_memory import ConversationMemoryService

logger = logging.getLogger(__name__)

router = APIRouter(prefix="/conversations/memory", tags=["conversation-memory"])


@router.get("/search")
def search_conversation_memory(
    q: str = Query(..., min_length=1, description="Search query"),
    limit: int = Query(default=5, ge=1, le=20),
    min_score: float = Query(default=0.7, ge=0.0, le=1.0),
    exclude_current: int | None = Query(default=None, description="Conversation ID to exclude"),
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user),
):
    """Semantically search all past conversations for relevant messages.

    Returns results from across ALL user conversations, ranked by relevance.
    The active window (current conversation) is excluded when exclude_current is set.
    """
    svc = ConversationMemoryService(db)
    exclude_ids = [exclude_current] if exclude_current else None
    results = svc.search_archive(
        user_id=current_user.id,
        query=q,
        exclude_conversation_ids=exclude_ids,
        limit=limit,
        min_score=min_score,
    )
    return {
        "query": q,
        "results": results,
        "total": len(results),
    }


@router.delete("/purge")
def purge_memory_before_date(
    before: str = Query(..., description="ISO date string (e.g. '2026-01-01')"),
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user),
):
    """Delete all archived messages before a given date.

    WARNING: This permanently deletes message content from both
    the database and vector store. This action cannot be undone.
    """
    try:
        before_dt = datetime.fromisoformat(before)
    except ValueError:
        raise HTTPException(status_code=400, detail="Invalid date format. Use ISO 8601 (e.g. '2026-01-01')")

    svc = ConversationMemoryService(db)
    result = svc.delete_messages_by_date(current_user.id, before_dt)
    return {
        "status": "purged",
        "deleted_messages": result["deleted_messages"],
        "before": before,
    }


@router.get("/stats")
def memory_stats(
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user),
):
    """Get archive statistics for the current user."""
    from backend.app.models.interaction.conversation import Conversation, ConversationMessage
    from sqlalchemy import func

    total_convs = (
        db.query(func.count(Conversation.id))
        .filter(Conversation.user_id == current_user.id)
        .scalar()
    )
    total_msgs = (
        db.query(func.count(ConversationMessage.id))
        .filter(ConversationMessage.conversation_id.in_(
            db.query(Conversation.id).filter(Conversation.user_id == current_user.id)
        ))
        .scalar()
    )
    oldest_msg = (
        db.query(func.min(ConversationMessage.created_at))
        .filter(ConversationMessage.conversation_id.in_(
            db.query(Conversation.id).filter(Conversation.user_id == current_user.id)
        ))
        .scalar()
    )

    return {
        "total_conversations": total_convs,
        "total_messages": total_msgs,
        "oldest_message": oldest_msg.isoformat() if oldest_msg else None,
    }

"""Archive intent detection — detect when user wants to search past conversations."""

from __future__ import annotations

import re

# Patterns that indicate user wants to search past conversations
SEARCH_TRIGGERS = [
    r"\bsearch\s+(my\s+)?(past|old|previous|earlier|other)\s+(conversation|chat|message)",
    r"\bwhat\s+(did|was)\s+(i|we)\s+(say|talk|discuss|mention)\s+(about|regarding)",
    r"\blook\s+(back|through|up)\s+(in|my|past|previous)",
    r"\bfind\s+(in|from)\s+(my\s+)?(old|past|previous|earlier)\s+(chat|conversation)",
    r"\brecall\s+(from|what|the)",
    r"\bremember\s+(when|what|the|about|that)",
    r"\bprevious\s+conversation",
    r"\bin\s+(another|a\s+different)\s+(chat|conversation)",
]


def has_archive_intent(user_message: str) -> bool:
    """Check if user message indicates intent to search past conversations."""
    lower = user_message.lower().strip()
    for pattern in SEARCH_TRIGGERS:
        if re.search(pattern, lower):
            return True
    return False


def is_simple_continuation(user_message: str, history_count: int) -> bool:
    """Check if message is a simple follow-up (no new topic)."""
    if history_count < 2:
        return False
    lower = user_message.lower().strip()
    continuation_markers = [
        r"^(yes|no|ok|okay|sure|thanks|got it|i see|tell me more|explain|why|how|what about)",
        r"^\?$",
        r"^(and|but|so|then|also)",
    ]
    for pattern in continuation_markers:
        if re.search(pattern, lower):
            return True
    return False
```

"use client";

import { useState } from "react";

interface PurgeMemoryDialogProps {
  onClose: () => void;
  onPurged: () => void;
}

export function PurgeMemoryDialog({ onClose, onPurged }: PurgeMemoryDialogProps) {
  const [date, setDate] = useState("");
  const [loading, setLoading] = useState(false);
  const [confirmed, setConfirmed] = useState(false);
  const [result, setResult] = useState<{ deleted_messages: number } | null>(null);

  const purge = async () => {
    if (!confirmed) {
      setConfirmed(true);
      return;
    }
    setLoading(true);
    try {
      const res = await fetch(`/api/v1/conversations/memory/purge?before=${date}T00:00:00`, {
        method: "DELETE",
      });
      const data = await res.json();
      setResult(data);
      onPurged();
    } catch {
      setResult({ deleted_messages: 0 });
    } finally {
      setLoading(false);
    }
  };

  if (result) {
    return (
      <div className="fixed inset-0 bg-black/50 flex items-center justify-center z-50">
        <div className="bg-surface-800 rounded-lg p-6 max-w-md w-full mx-4 border border-surface-700">
          <h3 className="text-lg font-semibold text-text-primary">Purge Complete</h3>
          <p className="text-sm text-text-muted mt-2">
            Deleted {result.deleted_messages} messages before {date}.
          </p>
          <button onClick={onClose} className="mt-4 px-4 py-2 bg-accent-600 text-white rounded text-sm">
            Done
          </button>
        </div>
      </div>
    );
  }

  return (
    <div className="fixed inset-0 bg-black/50 flex items-center justify-center z-50">
      <div className="bg-surface-800 rounded-lg p-6 max-w-md w-full mx-4 border border-surface-700">
        <h3 className="text-lg font-semibold text-text-primary">
          {confirmed ? "Confirm Purge" : "Purge Old Messages"}
        </h3>
        {!confirmed ? (
          <>
            <p className="text-sm text-text-muted mt-2">
              Delete all messages before a specific date. Messages in your active conversations
              will be removed from both the database and search index.
            </p>
            <div className="mt-4">
              <label className="text-xs text-text-muted block mb-1">Delete messages before:</label>
              <input
                type="date"
                value={date}
                onChange={(e) => setDate(e.target.value)}
                className="w-full bg-surface-900 text-text-primary px-3 py-2 rounded border border-surface-600"
              />
            </div>
            <div className="flex gap-2 mt-4">
              <button onClick={onClose} className="px-4 py-2 bg-surface-700 text-text-primary rounded text-sm">
                Cancel
              </button>
              <button
                onClick={purge}
                disabled={!date}
                className="px-4 py-2 bg-red-600 text-white rounded text-sm disabled:opacity-50"
              >
                Continue
              </button>
            </div>
          </>
        ) : (
          <>
            <div className="bg-red-900/20 border border-red-800/30 rounded p-3 mt-2">
              <p className="text-sm text-red-400 font-medium">Warning: This action cannot be undone.</p>
              <p className="text-sm text-text-muted mt-1">
                All messages before {date} will be permanently deleted from the database
                and search index. This affects ALL your conversations.
              </p>
            </div>
            <div className="flex gap-2 mt-4">
              <button onClick={onClose} className="px-4 py-2 bg-surface-700 text-text-primary rounded text-sm">
                Cancel
              </button>
              <button
                onClick={purge}
                disabled={loading}
                className="px-4 py-2 bg-red-600 text-white rounded text-sm disabled:opacity-50"
              >
                {loading ? "Purging..." : "Yes, Delete Everything Before This Date"}
              </button>
            </div>
          </>
        )}
      </div>
    </div>
  );
}
