### Task 1: Create UserPreference Model

**File:** `backend/app/models/learning/preference.py`
**Purpose:** Store user preferences with confidence tracking and source attribution. Preferences strengthen with repeated observation, weaken when contradicted. Source tracking: explicit (user said it), observed (user did it), inferred (behavior suggests it).

**Database Schema:**
```sql
CREATE TABLE user_preferences (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    category VARCHAR(100) NOT NULL,   -- 'response_style', 'ui_layout', 'notification', 'tool'
    key VARCHAR(200) NOT NULL,        -- 'length', 'sidebar', 'frequency', 'editor'
    value TEXT,                        -- JSON: preference value (string, number, boolean, object)
    confidence FLOAT DEFAULT 0.5,     -- 0.0 to 1.0, strengthens with observation
    source VARCHAR(50) NOT NULL,      -- 'explicit', 'observed', 'inferred'
    observation_count INTEGER DEFAULT 1,  -- How many times this preference was observed
    last_observed TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP,
    UNIQUE(user_id, category, key)
);
CREATE INDEX idx_user_preferences_user ON user_preferences(user_id);
CREATE INDEX idx_user_preferences_cat ON user_preferences(user_id, category);
CREATE INDEX idx_user_preferences_conf ON user_preferences(user_id, confidence);
```

**Implementation:**
```python
# backend/app/models/learning/preference.py

from sqlalchemy import Column, Integer, String, DateTime, Float, Text, UniqueConstraint, Index
from datetime import datetime
from backend.app.db.base import Base


class UserPreference(Base):
    """User preference with confidence tracking and source attribution.
    
    Sources:
    - 'explicit': User directly stated this preference
    - 'observed': User repeatedly chose this option
    - 'inferred': Behavior pattern suggests this preference
    
    Confidence grows with repeated observations (+0.1 per observation, capped at 1.0).
    Explicit preferences override observed/inferred.
    
    Architecture ref: 1.6 (Evidence Over Opinion) — preferences grounded in observations.
    """
    __tablename__ = "user_preferences"
    __table_args__ = (
        UniqueConstraint("user_id", "category", "key", name="uq_user_pref_cat_key"),
        Index("idx_user_preferences_user", "user_id"),
        Index("idx_user_preferences_cat", "user_id", "category"),
        Index("idx_user_preferences_conf", "user_id", "confidence"),
    )

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, nullable=False, index=True)
    category = Column(String(100), nullable=False)
    key = Column(String(200), nullable=False)
    value = Column(Text, nullable=True)  # JSON serialized
    confidence = Column(Float, nullable=False, default=0.5)
    source = Column(String(50), nullable=False, default="observed")
    observation_count = Column(Integer, nullable=False, default=1)
    last_observed = Column(DateTime, nullable=True)
    created_at = Column(DateTime, nullable=False, default=datetime.utcnow)
    updated_at = Column(DateTime, nullable=True, onupdate=datetime.utcnow)

    def __repr__(self) -> str:
        return f"<UserPreference(cat={self.category}, key={self.key}, val={self.value})>"

    def strengthen(self, amount: float = 0.1) -> None:
        """Strengthen preference confidence on repeated observation."""
        self.confidence = min(1.0, self.confidence + amount)
        self.observation_count += 1
        self.last_observed = datetime.utcnow()
        self.updated_at = datetime.utcnow()

    def weaken(self, amount: float = 0.1) -> None:
        """Weaken preference confidence when contradicted."""
        self.confidence = max(0.0, self.confidence - amount)
        self.updated_at = datetime.utcnow()

    @property
    def is_high_confidence(self) -> bool:
        """Check if preference has high enough confidence for adaptation."""
        return self.confidence >= 0.6

    @property
    def source_priority(self) -> int:
        """Get source priority (higher = more authoritative)."""
        return {"explicit": 3, "observed": 2, "inferred": 1}.get(self.source, 0)
```

# backend/app/models/learning/habit.py

from sqlalchemy import Column, Integer, String, DateTime, Text, Index
from datetime import datetime
from backend.app.db.base import Base


class Habit(Base):
    """Detected user habit — a trigger-action pair that occurs regularly.
    
    Habits require ≥5 occurrences to be classified as habits (not one-offs).
    Frequency classification:
    - <5 occurrences: not yet a habit
    - 5-29 occurrences: 'irregular'
    - 30+ occurrences: 'daily' (assuming daily observation window)
    - 7+ with weekly pattern: 'weekly'
    
    Architecture ref: 1.6 (Evidence Over Opinion) — habits require ≥5 occurrences.
    """
    __tablename__ = "habits"
    __table_args__ = (
        Index("idx_habits_user", "user_id"),
        Index("idx_habits_action", "user_id", "action"),
        Index("idx_habits_freq", "user_id", "frequency"),
    )

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, nullable=False, index=True)
    habit_name = Column(String(200), nullable=False)
    description = Column(Text, nullable=True)
    trigger = Column(String(200), nullable=True)
    action = Column(String(200), nullable=False)
    frequency = Column(String(50), nullable=True)  # 'daily', 'weekly', 'hourly', 'irregular'
    occurrences = Column(Integer, nullable=False, default=0)
    first_observed = Column(DateTime, nullable=True)
    last_observed = Column(DateTime, nullable=True)
    created_at = Column(DateTime, nullable=False, default=datetime.utcnow)

    def __repr__(self) -> str:
        return f"<Habit(action={self.action}, occ={self.occurrences})>"

    MIN_OCCURRENCES = 5  # Minimum to classify as habit

    def observe(self) -> None:
        """Record another observation of this action."""
        self.occurrences += 1
        self.last_observed = datetime.utcnow()
        if self.first_observed is None:
            self.first_observed = datetime.utcnow()
        if self.occurrences >= self.MIN_OCCURRENCES:
            self.frequency = self._classify_frequency()

    def _classify_frequency(self) -> str:
        """Classify frequency from occurrence count."""
        if self.occurrences >= 30:
            return "daily"
        elif self.occurrences >= 7:
            return "weekly"
        else:
            return "irregular"

    @property
    def is_confirmed_habit(self) -> bool:
        """Check if this is a confirmed habit (≥5 occurrences)."""
        return self.occurrences >= self.MIN_OCCURRENCES

    @property
    def confidence(self) -> float:
        """Calculate confidence from occurrences (0.0 to 1.0)."""
        return min(1.0, self.occurrences / 10.0)
```

from sqlalchemy import Column, Integer, String, DateTime, Float, Text, Index
from datetime import datetime
from backend.app.db.base import Base


class LearningEvent(Base):
    """Feedback event for learning — corrections, affirmations, implicit feedback.
    
    Event types:
    - 'affirmation': User approved/accepted a suggestion (+0.1 delta)
    - 'correction': User corrected/rejected a suggestion (-0.1 delta)
    - 'feedback': Explicit user feedback (delta varies)
    - 'implicit': Implicit signal from user behavior (delta varies)
    
    Architecture ref: 1.7 (Incremental Safety) — learning rate bounded (±0.1 max).
    """
    __tablename__ = "learning_events"
    __table_args__ = (
        Index("idx_learning_events_user", "user_id"),
        Index("idx_learning_events_type", "user_id", "event_type"),
        Index("idx_learning_events_applied", "user_id", "applied"),
    )

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, nullable=False, index=True)
    event_type = Column(String(50), nullable=False)
    context = Column(Text, nullable=True)   # JSON
    input_data = Column(Text, nullable=True)  # JSON: what Cortex did
    output_data = Column(Text, nullable=True)  # JSON: what user did
    delta = Column(Float, nullable=True)    # ±0.1 typically
    applied = Column(Integer, nullable=False, default=0)
    created_at = Column(DateTime, nullable=False, default=datetime.utcnow)

    def __repr__(self) -> str:
        return f"<LearningEvent(type={self.event_type}, delta={self.delta})>"

    MAX_DELTA = 0.1  # Maximum adjustment per event

    @property
    def is_positive(self) -> bool:
        """Check if this is a positive feedback event."""
        return self.event_type in ("affirmation", "positive")

    @property
    def is_negative(self) -> bool:
        """Check if this is a negative feedback event."""
        return self.event_type in ("correction", "negative")

# backend/app/models/learning/pattern.py

from sqlalchemy import Column, Integer, String, DateTime, Float, Text, Index
from datetime import datetime
from backend.app.db.base import Base


class Pattern(Base):
    """Detected behavioral pattern — temporal, behavioral, or preference-based.
    
    Pattern types:
    - 'temporal': Time-based patterns (codes in mornings, checks email at 9am)
    - 'behavioral': Action-based patterns (prefers vim, uses dark mode)
    - 'preference': Preference patterns (always chooses concise responses)
    
    Architecture ref: 1.6 (Evidence Over Opinion) — patterns require evidence lists.
    """
    __tablename__ = "patterns"
    __table_args__ = (
        Index("idx_patterns_user", "user_id"),
        Index("idx_patterns_type", "user_id", "pattern_type"),
        Index("idx_patterns_conf", "user_id", "confidence"),
    )

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, nullable=False, index=True)
    pattern_type = Column(String(50), nullable=True)
    description = Column(Text, nullable=True)
    evidence = Column(Text, nullable=True)  # JSON: list of evidence items
    confidence = Column(Float, nullable=False, default=0.5)
    first_seen = Column(DateTime, nullable=False, default=datetime.utcnow)
    last_seen = Column(DateTime, nullable=True)
    occurrences = Column(Integer, nullable=False, default=1)

    def __repr__(self) -> str:
        return f"<Pattern(type={self.pattern_type}, desc={self.description[:30]})>"

    MIN_EVIDENCE = 3  # Minimum evidence items for confidence

    def add_evidence(self) -> None:
        """Record another evidence point for this pattern."""
        self.occurrences += 1
        self.last_seen = datetime.utcnow()
        self.confidence = min(1.0, self.confidence + 0.1)

    @property
    def is_confident(self) -> bool:
        """Check if pattern has enough confidence to act on."""
        return self.confidence >= 0.5 and self.occurrences >= self.MIN_EVIDENCE
```

## Security Considerations

1. **User isolation** — All models filter by `user_id`. Never return cross-user learning data.
2. **Data sensitivity** — Learning data reveals user behavior. Store locally only, no external transmission.
3. **User reset** — Users must be able to delete all learning data. Provide reset endpoint.
4. **Confidence bounds** — All confidence values bounded 0.0-1.0. No unbounded growth.

---

## Performance Considerations

1. **Index strategy** — Composite indexes on (user_id, category) and (user_id, confidence) for common queries.
2. **JSON columns** — SQLite stores JSON as text. PostgreSQL uses JSONB. Test both.
3. **Query limits** — Default limit of 100 results. Pagination support.
4. **Event cleanup** — LearningEvent table grows unbounded. Plan for periodic cleanup (90-day retention).

## Per-Task Risk Analysis

| Task | Risk | Likelihood | Impact | Mitigation |
|------|------|-----------|--------|------------|
| Task 1 (Preference) | Unique constraint violation on existing data | Low | High | Migration checks duplicates first |
| Task 2 (Workflow) | JSON steps format inconsistency | Medium | Low | Validate JSON in Pydantic schema |
| Task 3 (Habit) | Frequency classification inaccurate | Medium | Low | Conservative thresholds; adjustable |
| Task 4 (LearningEvent) | Event table grows unbounded | Medium | Medium | Plan 90-day retention policy |
| Task 5 (Pattern) | Pattern confidence too noisy | Medium | Low | MIN_EVIDENCE=3 requirement |
| Task 6 (Schemas) | Pydantic v2 breaking changes | Low | Medium | Use from_attributes=True |
| Task 7 (Migration) | Migration fails on large DB | Medium | High | Idempotent migration; test on large DB |
| Task 8 (Registry) | Missing import breaks Alembic | Low | High | Verify autogenerate detects tables |
| Task 9 (Tests) | SQLite vs PostgreSQL JSON behavior | Medium | Low | Test with dict serialization |
